    第 51 章 冻土与寒冷地区文明重建版

    本章目标¶

    给出寒冷/冻土条件下的完整重建执行计划：冻土类型判定 → 五阶段路线 → 特别风险章节。本章不引入新技术，只做重排序与寒带化改造；核心命题是把"过冬"从生存问题变成生产节拍。

    能力边界¶

    能做到：过冬生存系统（保温/季储/CO 纪律）；地窨作坊冬季连续生产；沼铁-桦焦油本地冶金（年产量上限以沼泽再生速率为准）；双动力过冬与冰道运输；"冬季不减产"的排产体系。 明确做不到：永久冻土区大建筑（无路线，如实登记）；冬季大载荷润滑（无解，降速运行）；改变冰期长度（只能排产适应）。 外部依赖：燃料季储的劳动集约（秋季全员工程）；沼铁储量年账（两个冬季以上数据）。

    环境假设（评估表结论）¶

    项 寒冷/冻土典型答案 路线后果
    热 生存的第一资源 保温=第一"材料"
    燃料 木材带状分布、泥炭、（或有煤） 燃料季储定生死
    生长季 短，农业受限 渔猎/畜牧/仓储权重高
    矿产 常有（沼铁是冻土特色） 冶金路线独特
    动力 河流季节性冻结 动力要"过冬"
    维护 低温脆化、润滑失效 材料低温纪律

    最低前置条件¶

    第一至六部技术库 + 冬季实测数据（最低温、冰期、冻土深度——第 3 章测量制度的越冬档案）。

    51.1 第一阶段：热量与生存系统¶

    • 保温结构优先于产热：半地下地窨子/草皮屋（第13章的寒带版：地面挖深半米+圆木墙+草皮覆顶，入口弯道防风斗）；小空间高密度（人均容积压到最小）；兽皮门帘双层；
    • 供暖：石砌火炕式蓄热炉（烧一回热一夜——石头蓄热体是冻土的"电池"）；CO 纪律加倍（密闭+取暖=第 6 章红线的最危险组合，通风口常开制）；
    • 食物长期保存：天然冰窖（冬季采冰埋锯末窖藏——冻土自带"冷库"）；鱼脂与干肉（第10章+渔猎）；冬季热量口粮账：人均日耗燃料实测登记，秋储=冬耗×冰期天数×冗余三成（经验公式，需本地标定）；
    • 防冻供水：井口保温罩+深埋水管（冻土活动层以下）或冬用雪熔（熔雪燃料计入水账——冻土的水也要算能量成本）。

    51.2 第二阶段：建立稳定工作空间¶

    • 保温作坊=工业的先决条件：地窨式作坊（挖入冻土一半，靠地温缓冲），炉窑区与精工区分隔（一端要热一端要恒温）；
    • 原料与工具的干燥储存：冷凝与霜——进屋的冷物先在"过渡间"回温除霜再入库（金属件见霜即锈，冻土版防潮的重点其实是防霜）；
    • 低温材料纪律：铸铁件低温脆化（严禁冬季用铸铁做冲击工具——第17章红线寒带版）；润滑剂按温度分级（动物脂低温变硬，冬用稀油+石墨，第21章）；密封皮革硬化——入冬前全套换脂养护。

    51.3 第三阶段：矿产与冶金路线¶

    • 沼铁（冻土的天然馈赠）：湖沼河底的褐铁矿结核（铁细菌沉积）——冬天凿冰捞取、晒干焙烧（脱水去硫）后即第18章块炼炉的优质原料；斯堪的纳维亚数百年制铁史证明此路线可持续（产量上限中等——够工具，不够大工业，如实登记）；
    • 桦树全利用：桦焦油（树皮干馏，第23章路线）=万能胶与防腐剂（第 7 章工具柄、第15章皮革、船缝）；桦木=器物与燃料；
    • 皂石（如有）：免烧陶直接凿锅（冻土无柴区过渡方案）+炉衬材料；
    • 冶金季排产：鼓风冶炼集中夏季（燃料易干、露天作业），冬季锻打精饰（室内工序）；煤（如有露头）优先留给冶金与窑，民居烧柴与泥炭（第23章"好燃料优先高温"的寒带执行）。

    51.4 第四阶段：动力与机械¶

    • 河流冰封期=水力年账的一半盲区：双动力配置强制（第29章冗余律寒带版）：夏季水轮+冬季畜力/大气式蒸汽机（如燃料账允许）；
    • 冰对水工结构的破坏（流冰撞击、冰胀）：水轮闸门秋前提检修、春汛前清冰道（年检表加两行）；
    • 低温启动与密封：机械每年"入冬保养"（换油、间隙复查、皮带张紧——第21章周检年度化）；
    • 雪地运输（冻土的"高速公路"）：雪橇+雪鞋（第 7 章木工）、冬季冰面货运队——冬季反而是大宗运输季（冻土沼泽区夏季不可通行）。

    51.5 第五阶段：电气与精密工业¶

    • 低温电池管理：铅酸电池容量低温骤降且亏电冻损——电池室必须采暖（地窨电池间），冬充冬放参数单独成表（第32章密度表的寒带版）；
    • 导线覆冰与杆塔雪载：巡线制度冬季倍频；瓷瓶冷脆抽查（第32章季检加严）；
    • 精密车间恒温：地窨+炉温余热引入=天然恒温间（冻土的寒冷反而是免费的恒温资源——夏季也稳定，第34章直拉炉与第35章光刻对版都受益）；
    • 电子（33–36 章）：低温下硅器件特性漂移可测可控（第33章温度系数表服务于此）；封装以抗温差循环为主（树脂灌封+缓冲结构）。

    51.6 冻土版本的特别章节¶

    1. 冻土建筑风险：融沉（暖屋融化冻土地基下陷）——地板架空通风（冷气隔断）或桩基穿越活动层；越冬沉降观测制度化（第 3 章测量+第13章建筑的合体）；
    2. 冰雪融水排水：春季融水是洪峰——排水沟秋前疏通、物资垫高线标记；
    3. 季节储备：燃料/食物/备件三大季储账（冬季封路=外部补给归零，第29章停机冗余律的生活版）；
    4. 低温对金属/密封/润滑的影响表：逐工位列"冬季替代与保养项"（51.2 各条的汇总成表，上墙）；
    5. 冬季连续生产：白昼短——照明（第32章）在冻土版里是"生产资料"不是生活品；工时制度按光照重排（精工白班、炉窑夜班）。

    51.7 失效：寒冷地区哪条会先坏¶

    按先坏顺序。前兆写上值班牌。

    序 失效线 前兆 后果链
    ① 润滑与密封低温失效（21/28章） 黄油发硬发白、皮革密封硬化漏风 轴承干磨→轴毁；风箱漏风→炉温塌
    ② 铸铁与钢材冷脆（17/18章） 低温下敲击声发脆、断口平齐 冬季锤击铸铁件=当场碎裂伤人
    ③ 燃料失算（季储不足/湿柴） 柴堆内层结冰壳、火炕烧不透夜 失温→减员→全厂停摆——冻土的第一死因是冷不是饿
    ④ 水系统冻结（井/渠/水管） 夜间龙头断流、井口冰锥 全厂断水；冻裂管件
    ⑤ 电池容量骤降（32 章） 冬充冬放时间异常拉长 夜间照明与电报断
    ⑥ 融沉（暖屋融地基） 门槛下沉、墙面新斜裂（13 章沉降裂形态） 房屋倾斜→炉窑基座错位
    ⑦ 春汛与流冰 积雪反照率变化、河冰变酥发灰（结构性变白） 水工结构撞毁、低洼工坊淹

    51.8 维护：冬季倍频与入冬保养¶

    项 常规周期 冻土周期
    入冬保养（换油/间隙/皮带） 年检 强制年检+霜降前完成（第一场硬霜前）
    蓄热炉烟道 季清 月清（低温排烟易积焦油挂灰——烟囱火灾是冻土特有）
    冰面放行 — 每旬测冰厚（钻孔量厚：人行 ≥2 拳、橇载 ≥3 拳，经验值需标定；早春晚冬一律禁）
    融沉观测 — 每周（观察桩+门槛标线，13 章刻痕法）
    电池间温度 周检 日检（采暖间温度手感"不冷"档为下限）
    食品冻储库 月盘 旬盘（冻融循环=食物变质加速，化冻再冻即弃）

    【卡 51-02 入冬保养】（八字段）

    1. 输入材料：全队机械与工具（皮带、轴承、液压或水系统、皮革件）；黄油、稀油、石墨脂、皮革脂。霜降前必须完成——第一场硬霜之后再保养，等于在冻土上做无用功。
    2. 所需工具：扳手、注脂枪、张紧工具、排水或保温材料。校准来源：间隙与张紧用第 20 章量具复查，不凭手感。
    3. 操作顺序与控制点（逐项打勾，不许跳项）：①黄油换稀油／石墨脂（低温黏度）→ ②皮革件全套换脂 → ③间隙复查 → ④皮带张紧 → ⑤水系统排空或保温。控制点：必须逐项打勾签字（漏一项，冬天就停一台机）；霜降前完成（时间点本身就是判据）。
    4. 经验参数与标定法：常规年检在冻土升级为强制年检＋霜降前完成；蓄热炉烟道由季清升级为月清（低温排烟易积焦油挂灰，烟囱火灾是冻土特有）；电池间温度由周检升级为日检（采暖间手感"不冷"档为下限）；融沉观测每周（观察桩＋门槛标线，第 13 章刻痕法）。
    5. 过程观察记录项：逐台记 保养日期 / 每项完成签字 / 换油脂型号 / 间隙实测 / 水系统处置方式 / 入冬后首次启动情况。
    6. 合格／返工／报废判据：合格＝五项全部打勾且霜降前完成；返工＝漏项（补做，但已过霜降的要在室内回暖后做）；报废＝水系统未排空导致冻裂（换件）。
    7. 常见失败与排查顺序：①入冬第一周设备就卡死 → 黄油没换稀油，低温凝固；②皮带断裂 → 张紧度未复查；③水系统冻裂 → 排空没做或做了一半；④开春发现融沉裂缝 → 冬季没做每周观测，错过了早期征兆。
    8. L1／L2／L3 证据：L1＝一个冬季的逐台保养表（五项齐全）；L2＝连续两个冬季无因保养缺失导致的停机与冻裂；L3＝第二人照本卡独立主持一次入冬保养，两人的间隙复查读数一致。

    【卡 51-03 季储三账】（八字段）

    1. 输入材料：燃料（柴、炭、油）、食物（粮、干鱼、肉）、备件（皮带、刃具、绳、钉）。
    2. 所需工具：秤（第 3 章）、仓房与货位标记、盘点表。校准来源：称重与逐旬盘点，不用"看着还够"。
    3. 操作顺序与控制点：估冬耗 → 按公式算秋储目标 → 入秋逐项囤够 → 逐旬盘点 → 存量过半即限用。控制点：公式里的冰期天数要用本地实测值（不是平均值），冗余系数不能省。
    4. 经验参数与标定法：秋储 ＝ 冬耗 × 冰期天数 × 1.3（经验公式，冰期天数按本地实测）；逐旬盘查；红线：存量过半即限用（不是等到快没才省）。
    5. 过程观察记录项：三项各自记 目标量 / 实际囤入量 / 每旬存量 / 消耗速率 / 限用启动日期。
    6. 合格／返工／报废判据：合格＝三项均在入冬前达标且逐旬盘查不断；返工＝某项不足，秋末紧急补采或调整排产；报废＝冰期中途见底（该季配给制度失效，要复盘估算公式）。
    7. 常见失败与排查顺序：①开春前燃料见底 → 冰期天数按记忆估的，用实测重算；②食物冻储库化冻再冻 → 旬盘没做，冻融循环会让食物加速变质，化冻再冻即弃；③备件短缺停摆 → 只备了耗材没备易损件；④存量过半没限用 → 红线执行不到位。
    8. L1／L2／L3 证据：L1＝一季三账（目标、囤入、逐旬存量）；L2＝连续两季三账齐全且未中途见底；L3＝第二人照本卡独立估一季并囤够，两人估算的冬耗差在 10% 以内。

    51.11 火炕蓄热炉构造卡（卡 51-04）¶

    蓄热炉是冻土的"热电池"——烧一回热一夜的原理是石床蓄热+长烟道：

    • 构造：炉膛（石砌，内净约 2 尺见方）→ 石板炕面（3–5 层大平石板叠砌，板间以耐火泥浆坐浆——缝隙漏烟=CO 红线）→ 烟道沿炕内蛇形走 2–3 折（烟道总长 ≥4 m，经验值——太短热量随烟跑了，太长抽力不足倒烟）→ 出烟口高于屋檐（12.3 低进高出）；
    • 烧火制度：睡前一次猛烧 1–2 h（引火—旺火—封火三段），火床封灰后石床缓释整夜；晨起炕面"手背可久触"（40–50 ℃ 档）为合格；
    • 验收：新炕首烧必须"烤炕"三天空烧小火驱湿（湿石床首夜会凝水冒汽）；烟道每段接口以烟线检漏（点湿草于炉膛，看各缝冒烟即补泥）；
    • CO 红线重申：炕缝漏烟是无味的夜杀手——每月烟线检漏一次+室内火把观焰（焰变弱即通风排查）。

    【卡 51-04 火炕蓄热炉构造与烧火制度】（八字段）

    1. 输入材料：石砌炉膛料（内净约2 尺见方）、大平石板（3–5 层，炕面）、耐火泥浆、灰（封火用）、燃料。
    2. 所需工具：砌筑工具、烟线检漏用的湿草、室内火把（观焰用）。校准来源：CO 泄漏靠烟线检漏与火把观焰双法，不靠闻——CO 无味。
    3. 操作顺序与控制点：炉膛（石砌）→ 长烟道（蓄热主体）→ 石板炕面 3–5 层叠砌、板间耐火泥浆坐浆（缝隙漏烟即 CO 红线）→ 新炕首烧烤炕三天（空烧小火驱湿，湿石床首夜会凝水冒汽）→ 正常烧火制度。控制点：板缝坐浆与烤炕三天，这两处省的代价是命。
    4. 经验参数与标定法：炉膛内净约 2 尺见方；石板 3–5 层；烧火制度：睡前一次猛烧 1–2 h（引火—旺火—封火三段），火床封灰后石床缓释整夜；晨起炕面"手背可久触"（40–50 ℃）为正常档；每月烟线检漏一次＋室内火把观焰（焰变弱即通风排查）。
    5. 过程观察记录项：每次记 烧火起止时段 / 三段各自时长 / 封灰时间 / 晨起炕面手感（手背可久触为正常）/ 烟道月清日期 / 检漏结果。
    6. 合格／返工／报废判据：合格＝晨起炕面达"手背可久触"、烟线检漏无渗、室内火焰正常；返工＝炕面不热（石层薄或烟道短）、检漏有渗（拆板重坐浆）；报废＝炉膛开裂贯穿（重砌，不得补）。
    7. 常见失败与排查顺序：①夜里冻醒 → 烧火三段没做全（尤其封火没封住），或石床层数不够；②室内有人头痛恶心 → 立即开窗撤人，查烟道漏烟，这是 CO 中毒；③烟囱着火 → 烟道没月清，焦油积挂；④炕面局部不热 → 烟道走向有问题，气流失短。
    8. L1／L2／L3 证据：L1＝一座火炕建成＋烤炕与首月烧火记录；L2＝整个冬季按制度烧火，无 CO 事故，月检漏不断档；L3＝第二人照本卡独立砌一座并通过烟线检漏与烤炕验收。

    51.12 沼铁冬捞与焙烧（卡 51-05）¶

    • 冬捞：选湖沼铁富集段（夏标记：水面油膜色/岸边锈水泉），冰面按 51-01 冰厚放行后凿冰孔（1 尺见方，间隔 3 步一孔排成横线）；长杆捞斗（麻网兜+硬木杆）贴底拖捞——结核（褐铁矿球，直径 1–5 cm）沉底手感 distinct（◎拖感：沙软球硬，练半日可辨）；每孔捞 20–30 min，日产 30–80 kg 原矿（经验值，需现场标定）；
    • 分拣：结核投水——沉底为真（铁结核密度 3–4），浮起为泥蛋弃；
    • 焙烧（关键，去水去有机质）：摊石板床厚 3 指，文火→旺火 2–4 h 翻两次——判据：色转暗红、敲之清脆、断口无黑心（黑心=有机质未烧尽，入炉吸热产渣）；焙烧失重记录（失重三成上下为正常区间，经验值）；
    • 入炉：焙烧结核即第18章块炼炉的"精选矿"（品位约 40–55%，沼铁的优势是几乎无脉石，渣少炭省）；
    • 储量账：两个冬季的捞取数据 + 沼泽面积估算→"年产铁量"入 38 章账——沼铁是可持续的，但年产上限以沼泽再生速度为准（铁细菌沉积年增毫米级，透支即枯竭）。

    【卡 51-05 沼铁冬捞与焙烧】（八字段）

    1. 输入材料：湖沼铁结核（夏季标记——水面油膜色、岸边锈水泉，冬前就要探明富集段）；燃料（焙烧用）。冰面须先按卡 51-01 放行。
    2. 所需工具：冰镩（凿 1 尺见方冰孔）、捞具（长柄耙或筐）、石板床（焙烧用）、木槌（敲碎听声）。校准来源：品位与焙烧程度靠断口与敲声判，不靠仪器。
    3. 操作顺序与控制点：冰面放行 → 凿孔（1 尺见方，间隔 3 步一孔）→ 捞取结核 → 分拣（投水，沉底为真，浮起为泥蛋弃）→ 焙烧（摊石板床厚 3 指，文火→旺火 2–4 h 翻两次）→ 入炉。控制点：分拣的投水试验与焙烧的翻料次数。
    4. 经验参数与标定法：冰孔 1 尺见方、间隔 3 步；焙烧判据——色转暗红、敲之清脆、断口无黑心（黑心＝有机质未烧尽，入炉会多耗炭）；品位约 40%–55%；沼铁的优势是几乎无脉石，渣少炭省；冶炼季集中在夏季，冬季只锻（排产红线）。
    5. 过程观察记录项：每冬记 捞取段位置 / 冰孔数 / 结核总量 / 分拣淘汰比例 / 焙烧批次与翻料次数 / 断口判读 / 产铁量。
    6. 合格／返工／报废判据：合格＝焙烧后色暗红、敲声清脆、断口无黑心，入炉渣量正常；返工＝有黑心，重新摊开补烧；报废＝混入大量泥蛋（分拣没做投水试验）。
    7. 常见失败与排查顺序：①入炉后渣特别多 → 结核没焙烧透或分拣不净；②炉温上不去、耗炭大增 → 焙烧不足，有机质在炉内抢氧；③捞上来的大多是泥蛋 → 富集段标记错了，回夏季标记重定；④冰孔塌陷 → 冰厚不达标就上人，先回卡 51-01。
    8. L1／L2／L3 证据：L1＝一冬的捞取与焙烧记录＋一次合格入炉；L2＝连续两个冬季数据，年产铁量与沼泽面积估算入第 38 章账；L3＝第二人照本卡独立完成一冬作业并产出合格矿。

    【卡 51-01 冰厚测量与放行】（八字段）

    1. 输入材料：冰面（待测河段或湖面）；木杆或绳索（安全绳，一人测一人守）；参照物（岸标、已知水深点）。这张卡管的是人命，放行判据不商量。
    2. 所需工具：冰钻或冰镩（凿透用）、带刻度的量杆（第 3 章）、彩色标记旗。校准来源：厚度用刻度量杆实测，不用"看着挺厚"。
    3. 操作顺序与控制点：三点取样（近岸、中央、对有疑问处各钻一孔）→ 量冰厚 → 取最小值作为该段判据 → 按放行分档表定可通行类型 → 插旗标记 → 每旬复测。控制点：三点取最小（冰面厚薄不均，平均值会骗人）；气温骤升即加测，不等下一旬。
    4. 经验参数与标定法：人行 ≥2 拳冰厚、橇载 ≥3 拳（经验值，须按本地冰质标定）；红线：早春与晚冬一律禁行，不商量——这两个时段的冰是"白冰"结构，厚度够也不承重；每旬复测一次。
    5. 过程观察记录项：每次记 日期与气温 / 三个测点厚度 / 取用最小值 / 放行类型 / 插旗位置 / 复测间隔。
    6. 合格／返工／报废判据：合格＝最小值达档且不在禁行期；返工＝不达档，缩窄通行类型（人行改禁行）或绕行；报废＝冰面出现青灰色或水渗（结构已坏），该段全线封闭。
    7. 常见失败与排查顺序：①车掉了 → 用的是平均厚度或单点厚度；②同一段昨天能走今天塌 → 泉眼或温泉影响段，选线时未避开；③早春厚度还够却塌 → 禁行红线没执行；④测点读数差得大 → 冰下有流水或气腔，按最小值并加密测点。
    8. L1／L2／L3 证据：L1＝一次完整的三点测量与放行记录；L2＝整个冰期每旬复测不断档，且至少一次因读数下降而主动降档封路；L3＝第二人照本卡独立判定同一段，两人放行类型结论一致。

    51.13 冰道与雪橇运输规范¶

    • 冰道选线：直线河段、流速缓（冬季冻实）、避开泉眼与温泉影响段（局部薄冰）——选线勘验同卡 51-01 逐旬复测；
    • 雪橇规格：底板硬木（楢/桦）+底面泼水结冰壳（冰壳摩擦系数远低于木面——上冻夜泼水三次成壳，每次行前补泼）；载重 ≤1.5 倍旱季车载（冰面承载冗余）；
    • 编队纪律：单橇间距 ≥10 步（冰裂不连坐）；重橇走老辙（旧辙压实更安全）；春融期冰道全线关闭不以载重论（结构性劣化）；
    • 效率账：冰道载运效率为旱季土路的 1.5–2 倍（经验值）——冬季是冻土的大宗运输季，51.4 的结论在账本上的体现：运输工时的季节再分配。

    51.14 地窨作坊建造规格¶

    • 掘深：入冻土活动层一半（约 1–1.2 m，实测冻深后定）——掘入永久冻土层则夏融冬冻循环毁壁，只挖活动层；
    • 结构：圆木井干式壁（逐层咬缝苔藓塞缝）+地面圆木格栅+双层地板（下通风道防融沉——51.6 关口）+草皮坡顶（覆土 ≥1 尺）；
    • 分区：炉端（窑炉、锻打——烟道直出屋顶）与精工端（测量、装配——恒温端）隔一道保温墙，温差两端可达 20 ℃ 级（经验值）；
    • 门斗必设：双道门缓冲（防开门热丧+防霜直扑精工端）；
    • 验收：室外 −30 ℃ 级夜（本队历史极值档）精工端 ≥5 ℃ 且炉端可作业，燃料账在 37 章定额内。

    51.15 恒温资源的利用（免费精工间）¶

    冻土的寒冷是敌人也是资源：地下恒温层的温度全年几乎不变（活动层以下终年接近年均温，低温区 0–4 ℃ 级）—— - 地窨精工端的温度漂移远小于地面房（地面年漂 50 ℃，地窨 10 ℃ 内，经验值）——第22章千分尺校验、第35章光刻对版的"恒温纪律"在冻土天然达标一半； - 冬季精工排产：把最怕温度漂的工序（量具校准、晶圆测量、仪表装配）固定排在地窨端，且避开炉端烧火时段（烧火使地窨整体升温 2–3 ℃，校准件须与炉错时）； - 食品冰窖（51.1）与恒温精工间共用地温原理——一井两用的设计记账入 13 章建筑变体。

    51.16 冻土农渔：渔汛历、干鱼产线与窖藏蔬菜¶

    冻土的生长季养不活全队，渔与储才是冬季蛋白账的主干——本节把第10章的农储工艺做寒带重排，不引入新设备。

    渔汛历（开春靠岸窗口的预报制度）： - 原理：冰下越冬鱼群在融水期靠岸觅食，窗口短（首尾约 10–20 天，随冰情浮动，经验值需本地标定）——错过窗口=误一冬的蛋白账； - 建历三件套，连续记两年：①冰裂日（冰面出现结构性透水裂缝之日）②首捕日（岸捕单日产鱼首次 ≥10 kg）③水温信号（岸边水深 10 cm 处连续 3 日 ≥4 ℃）；三者逐年对照成历，第三年起可预报窗口（标定法：逐年回代检验，预报误差 ≤3 日为可用，超差则下一年加记气温项）； - 冰下冬捕配套：凿冰孔下网（凿孔工艺同卡 51-05，孔径与网幅配套）；起网纪律——网离水即抖、鱼离网即收（湿网低温 10 min 内冻硬，硬网一折即断丝）； - 排产联动：渔汛窗口=卡 51-07 干鱼产线的原料洪峰，加工人力提前半月排班（第29章冗余律的食物版：汛期减员=账本缺口）。

    干鱼产线（第10章干制与第53章鱼盐干制的寒带版，操作全文见卡 51-07）： - 寒带优势：冷凉阴干天然抑制细菌与蝇蛆，用盐可省至温带配方的一半以下（白日气温 <10 ℃ 档可免盐阴干）； - 寒带特有的反向风险：昼晒夜冻的反复冻融使鱼肉组织开裂吐水——脱水虽快但组织渣化、储期缩短、易招蛀；制度：昼出夜收，或主推通风棚阴干（不直晒、穿堂风）——阴干是寒带正路，晒干是替补； - 干度判据：单尾干重=鲜重的 30–35%（经验区间，首汛标定）；◎手感档：鱼体对折、脊骨断裂而肉面不出水为合格——练法：首汛取 10 尾全流程称重建档（档案存台账），此后以折断感对照档案练 2 汛；误判代偿：手感存疑一律上秤复称。

    窖藏蔬菜（第10章地窖的防冻改造）： - 唯一的硬改造：埋深过冻土线——窖底须在本地最大冻深以下（冻深实测入第 3 章越冬档案；无数据先挖探坑实测，禁照搬南方便宜深度）； - 冻土窖的风险是"过冷与冻融"而非"不够冷"（51.8 已列化冻再冻即弃）：目标窖温 0–4 ℃；◎控温判据（碗冰法）：窖口挂一碗水，晨起结满碗冰为偏冷（加秸秆封层）、无冰为偏热（扩通风口）、结一指冰壳不满碗为合格——练法：连续两旬碗象与开窖实查菜况对照标定；误判代偿：最低最高温度计（第 3 章测温件）一只入窖； - 码放与入窖安全：耐冻菜（白菜、芜菁）靠门侧，怕冻菜（土豆、萝卜）居中上层；土豆见光变绿有毒——窖内用罩灯弱光；入窖先灯试（第 6 章缺氧红线：提灯入窖，灯焰变弱或熄灭即人退通风），翻窖两人一组。

    短季作物选种（第10章三标准的寒带权重重排）： - 权重改为：早熟 > 抗寒 > 产量——生长期不够，产量标准无意义； - 硬判据：只留"生长期 ≤ 本地无霜期 × 0.8"的品种做种源（两成冗余防早霜）；头霜日仍青的田块登记"晚熟弃种田"，来年不入种源； - 正向驯化：每年把最早成熟的 10% 植株单收单储作种——连续 5–8 代可见明显早熟化（经验值，逐年登记成熟日与粒重入台账，断代即前功尽弃）。

    51.17 裘皮与皮革加工（第15章寒带版）¶

    皮毛在冻土是衣被原料兼贸易硬通货。第15章鞣制多以脱毛皮革为主线，寒带特化点是带毛鞣制——毛毡不上、绒不脱，皮板不腐。

    带毛皮鞣制两路线： - 脑鞣（贴身衣主选）：兽脑乳化液涂刷肉面——每张皮配 1–2 枚兽脑（与皮面积的配比起点为经验值，首季按皮张尺寸配脑量建档）；脑浆加温水捣乳（捻之无颗粒感为度），涂满肉面卷置半日，刮去余乳摊开；成败一半在拉伸：半干至全干全程反复抻拉揉搓，干后皮板发硬=拉伸不足，返工法：湿布闷皮板一夜回潮，重新涂乳拉伸；合格判据：揉之沙沙作响发软、对折无死折痕、绒面朝外抖之毛立； - 烟鞣（帐帘、鞋帮主选）：皮悬吊烟坑上方熏制，烟中醛类固皮兼驱虫防潮；皮面距烟源 30 cm 起（经验值，标定：手背伸皮板与烟源之间久触不烫为距准，烫则移高）；烟料用腐朽木与桦皮刨花（树脂多的明火烟发黏挂黑，弃用）；每 2 h 翻面一次，全程 4–8 h； - 叠加路线：先脑鞣后烟鞣最耐用，但工时翻倍——按用途记账选择，不许全队皮张一律叠加（工时纪律）。

    皮毛分级（三判，贸易统一口径）： - 一判绒厚：拨开毛峰看绒层——不见皮板为冬皮上等；针代法：细针插绒没入不见针尖为上等（此为二判的手感误判代偿）； - 二判皮板软：对折挤压松手，折痕即展=软板（可做贴身衣）；折痕停驻=硬板（降级做绑带、器物包件）； - 三判掉毛：掌面逆毛推三次——不落毛=完好；落毛 3–5 根以内=降级做内衬；成撮落毛=毛根受损（酸败或腐坏已深），剃毛留皮板另案处理； - ◎分档练习：取 20 张皮盲分三档，与熟手结果对照，错 ≤4 张出师；误判代偿即上三条的针测/折测/推毛计数——手感存疑一律以物证档为准，不许凭眼力定级。

    防蛀冬储： - 虫蛀窗口在回温期与夏季窖储，不在深冬：入储前烟熏一次（烟鞣同坑，兼防虫）；储间悬挂艾蒿或樟束（本地有则用）；每旬晴日抖晾一次（通风阴处，禁日光直晒——晒褪绒色且皮板变脆）； - 记账：分级结果按"档 × 张数"入队账本，贸易时统一口径——上等冬皮与等外皮差价数倍，混等出售=账面亏损。

    51.18 失温与冻伤防护（第44章接口）¶

    冻土的伤亡大头是冷伤不是工伤。本节是第44章医学总纲的寒带特化，处置纪律全队普训——冷伤急救等不到医护到场，第一处置人就是身边的工友。

    失温分级与复温规程： - 分级看行为，不看自我感觉（失温者的自我感觉不可信）：一级寒战期——寒战不止、动作笨拙、应答正常；二级迟钝期——寒战转弱、答话迟缓、出现"反常脱衣感"（自觉燥热要脱衣，极危险征）；三级僵木期——寒战停止、不能自主行走。寒战停止不是好转是恶化——冻土最致命的误判（值班牌原文上墙）； - 复温规程（一、二级现场处置）：移入暖间→脱湿衣换干衣→能咽者给温糖水→躯干隔衣置温水袋（袋温不超过 45 ℃，"手背久触不烫"档）；禁止快速加热（火烤、热水直浇、搓擦四肢）——原理：重度失温时肢体冷血骤然回流核心，核心体温先降后乱（复温休克），且冻僵皮肤感觉缺失，火烤必烫伤而不自知； - 三级现场只做一件事：阻止继续失热——干衣干毯包裹、平托搬运禁颠簸（粗暴搬动可诱发心律失常），复温交医护处置（第44章接口，转运观察记录按 44 章格式）； - 观察记录：每 10 min 记一次意识、寒战、呼吸（救援全程专人记录，不许事后凭记忆复盘）。

    冻伤四度判读与处置边界： - 一度冻红：苍白转红肿、发麻发痒——复温保暖后涂油脂，可留守轻岗位； - 二度水疱：复温后现清亮水疱——不挑破（完整水疱是无菌天然敷料）；水疱过大碍包扎者从疱缘穿刺引流、泡皮保留覆盖； - 三度（紫黑坏死累及全皮层）与四度（深及肌肉骨）：现场只保温送医，禁止一切清创、挑刮、涂药尝试（第44章处置边界，现场任何"处理"都在制造感染）； - 复温操作：冻肢浸 38–42 ℃ 温水 20–30 min——水温禁由伤者定（冻肢无感觉，必被烫伤），以健康人手肘试温合格为准；复温有效判据=皮肤转红、感觉沿"麻→痛→痒"顺序回归（痛是好消息）； - 红线：未复温的冻肢不许揉搓（冰晶正在切割组织，揉=机械损伤加倍）、不许火烤、不许行走（足部冻伤行走=每一步都在碾碎组织）。

    雪盲预防（护目烟熏片）： - 机理：雪面反射强光灼伤角膜，症状当晚才发（眼痛、流泪、畏光）——当天的雪原暴露极易漏记前因，误当"夜里起来着凉"； - 制具：桦皮或薄木片开横缝（缝长约 30 mm、缝宽约 5 mm，经验值；标定：戴上能辨清脚下三步内路面为缝宽合格），内面烟熏黑减眩，两侧系绳风镜式佩戴； - 处置：遮光静养 1–3 日、冷敷镇痛，可自愈；反复雪盲=角膜累积损伤——雪原作业护目是纪律不是选项（晨检单加一行"护目片随身"）。

    冬装分层穿着制： - 三层制：内层排汗（贴身细软织物，汗湿即换——湿内衣是失温第一帮凶）；中层蓄热（毛绒多薄层优于单层厚裹，按 −10/−20/−30 ℃ 三档配层数）；外层防风（皮毛或密织物，主旨挡风）； - 作业纪律：作业微汗先敞外层散热；静止岗（守夜、垂钓、哨卡）上岗前强制换干内层；冻伤史人员岗位登记在册（同一部位复冻风险加倍）； - 晨检互检：出工前两人对脸——颊、指尖发白（一度冻伤前兆）就地揉暖回暖后再上工，白斑不退即收工处置。

    51.19 冻伤处置卡（卡 51-06，八字段摘要）¶

    • ① 输入材料：温水 38–42 ℃（单次 ≥10 L，须浸没伤肢）、干衣干毯、隔衣温水袋、温糖水、清洁敷布；替代：一、二度轻症可用体温互暖（腋下、腹部）；禁酒精搓擦、禁雪搓。
    • ② 所需工具：水温计（第 3 章测温件，冰点法校准）；应急代偿：水内浮起碎冰渣即超温弃用。
    • ③ 操作顺序与控制点：脱冻鞋冻手套（粘皮处温水浇分离，禁硬撕）→ 38–42 ℃ 水浸 20–30 min → 取出以干敷布包裹、伤肢上抬 → 水疱不挑 → 保暖留观或送医。控制点：水温全程维持，换水加热时先取出伤肢再添热水。
    • ④ 经验参数与标定：水温 38–42 ℃——标定：健康人手肘浸 5 s "温而不烫"为合格档；复温时长判据优先于钟表（皮转红、感觉渐回即止）。
    • ⑤ 过程记录项：部位／初见颜色／水疱有无／水温与复温耗时／意识与寒战状态——按第44章病历格式逐项记。
    • ⑥ 合格／返工／移交：合格=转红、感觉回归；返工=仍苍白（复查水温再浸，至多两轮）；移交=紫黑、疱液浑浊、复温后剧痛不止（三度以上，保温送医）。
    • ⑦ 失败排查（同一症状按序验证）：复温 30 min 不转红——①水温不足（计测或手肘复测）→②浸泡不全（鞋袜手套未除尽）→③三度以上冻伤（即送医）。
    • ⑧ L1/L2/L3 证据：L1 一例处置记录；L2 全队普训考核（模拟处置人人过关，名单留档）；L3 冬季实际病例档案与复盘记录。

    【卡 51-06 冻伤处置】（八字段）

    1. 输入材料：温水 38–42 ℃（单次 ≥10 L，须能浸没伤肢）；干衣干毯；隔衣温水袋；温糖水；清洁敷布。一、二度可用替代法（体温暖复温），三度以上必须温水复温。
    2. 所需工具：水温计（第 3 章测温件，冰点法校准）；应急代偿——水中浮起碎冰渣即超温，弃用。没温度计不是不做的理由。
    3. 操作顺序与控制点：脱冻鞋冻手套（粘皮处用温水浇分离，禁硬撕） → 38–42 ℃ 水浸 20–30 min → 取出以干敷布包裹、抬高患肢 → 给温糖水 → 记录 → 判断是否移交。控制点：禁止揉搓、禁止火烤、禁止用雪搓（这三条是冻伤致残的主因）；水温宁低勿高。
    4. 经验参数与标定法：水温 38–42 ℃（标定法：健康人手肘浸 5 秒"温而不烫"为合格档）；复温时长 判据优先于钟表——皮色转红、感觉回归才算复温完成，看钟不算。
    5. 过程观察记录项：部位 / 初见颜色 / 水疱有无 / 水温与复温耗时 / 意识与寒战状态——按第 44 章病历格式逐项记。
    6. 合格／返工／移交判据：合格＝转红、感觉回归；返工＝仍苍白（复查水温再浸，至多两轮）；移交＝紫黑、疱液浑浊、复温后无感觉（转外科，见第 44 章清创与第 49 章截肢红线）。
    7. 常见失败与排查顺序：①复温 30 min 不转红 → ①水温不足（温度计测或手肘复测）→ ②浸泡不全（鞋袜手套未除干净）→ ③水深不够未浸没；②复温后起大水疱且发黑 → 已达三度，停止复温转移交；③病人寒战不停 → 全身失温，先复温躯干再处理肢端（第 44 章失温优先原则）。
    8. L1／L2／L3 证据：L1＝一例处置记录；L2＝全队普训考核（模拟处置人人过关，名单留档）；L3＝冬季实际病例档案与复盘记录。

    51.20 干鱼产线卡（卡 51-07，八字段摘要）¶

    • ① 输入材料：渔汛鲜鱼（离水 ≤2 h 入线，超时先盐渍再干制）、盐（有则用：鱼重的 5–10%，白日气温 <10 ℃ 档可免盐）、晾架木杆与绳网；单架挂 30–50 尾，鱼间距一拳、不贴背。
    • ② 所需工具：剖鱼刀（第 7 章刃具，全长开锋）、秤（第 3 章；汛期首日用标准石复核）、晾棚（通风不直晒）。
    • ③ 操作顺序与控制点：去脏（破胆即整尾降级，膛内胆汁污染段剔除）→ 背剖摊平、脊骨不断 → 盐渍 0.5–1 日（用盐档）→ 挂架阴干 → 每 2 日翻面 → 干度达标下架。控制点：昼出夜收或全程棚内阴干，防冻融循环。
    • ④ 经验参数与标定：干度=鲜重的 30–35%（标定：首汛取 10 尾全流程称重建档入台账）；晾期 5–10 日（以干度判据为准，不以日历为准）。
    • ⑤ 过程记录项：鲜重／盐量／下架干重／晾期天数／天气——逐架入账，算折率（干重÷鲜重）。
    • ⑥ 合格／返工／报废：合格=对折脊骨断、肉面无湿指印、无霉无蛆；返工=指印湿软（复挂 2–3 日）；报废=霉斑连片、蛆穴、冻融后灰败发臭（弃置或入肥田，禁食用）。
    • ⑦ 失败排查（同一症状按序验证）：鱼架批量发黏——①挂距过密不通风→②雨天回潮未收→③原料离水超时（下一批提前盐渍）。
    • ⑧ L1/L2/L3 证据：L1 首架合格干鱼留样一尾；L2 连续三架合格率 ≥8/10；L3 全汛折率表与冬季食用复盘。

    【卡 51-07 干鱼产线】（八字段）

    1. 输入材料：渔汛鲜鱼（离水 ≤2 h 入线，超时先盐渍再干制）；盐（有则用，鱼重的 5%–10%；白日气温 <10 ℃ 档可免盐）。原料离水时间是这条线的第一道判据，不是最后一道。
    2. 所需工具：剖鱼刀（第 7 章刃具，全长开锋）、秤（第 3 章，汛期首日用标准石复核）、晾棚（通风不直晒）。
    3. 操作顺序与控制点：去脏（破胆即整尾降级，膛内胆汁污染段必须剔除）→ 背剖摊平、脊骨不断 → 盐渍 0.5–1 日（用盐时）→ 上架晾制 → 收架称重。控制点：破胆剔除、背剖不断脊骨（断了摊不平，晾不透）。
    4. 经验参数与标定法：干度＝鲜重的 30%–35%（标定法：首汛取 10 尾全流程称重，建档）；晾期 5–10 日（以干度判据为准，不看天数）；盐 5%–10%（有盐时）；免盐档 白日 <10 ℃。
    5. 过程观察记录项：每架记 鲜重 / 盐量 / 下架干重 / 晾期天数 / 天气——逐架入账，算折率（干重÷鲜重）。
    6. 合格／返工／报废判据：合格＝对折脊骨断、肉面无湿指印、无霉无蛆；返工＝指印湿软（复挂 2–3 日）；报废＝霉斑连片或蛆（整架弃，不得混入）。
    7. 常见失败与排查顺序：①鱼架批量发黏 → ①挂距过密不通风 → ②雨天回潮未收 → ③原料离水超时（下一批改盐渍）；②干得太快外表硬内里湿 → 晾棚直晒，改通风阴干；③霉变 → 湿度高或晾期不足，查折率是否达标；④折率异常低 → 原料不新鲜失水（离水超时）。
    8. L1／L2／L3 证据：L1＝首架合格干鱼留样一尾；L2＝连续三架合格率 ≥8/10；L3＝全汛折率表与冬季食用复盘。
