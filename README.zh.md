## 这是什么

写给一种处境：某一代人手里只剩下土地、石头、木头、矿石和火，而没有人记得怎么把它们变成工具。

这本书不去论证崩塌会不会发生，只回答一个更窄的问题——*如果真的发生了，你手上只有这些，周一早上先做什么？*　答案写成工序，不写成历史，也不写成推演：怎么在没有任何标准工具时建立起测量体系，怎么把火管住，怎么从土到窑到玻璃、从矿到铁到刀，从水轮到发电机到电台。最后几部写的是通常被"生存书"漏掉的部分：留记录、教接班人、开诊所、把一群人组织起来，以及在沙漠、海岛、寒地和疫区怎么活。

每章同一个骨架：**这是干什么用的 → 要什么 → 怎么做 → 怎么知道做成了 → 出问题按什么顺序查 → 拿什么当证据**。

## 工艺卡

全书是围着这个东西写的。凡是"手把手才做得出来"的工序，都编成一张**工艺卡**：固定八项，一页，抄下来就能带到工位。

1. 输入材料
2. 所需工具
3. 操作顺序与控制点
4. 经验参数与标定法
5. 过程观察记录项
6. 合格／返工／报废判据
7. 常见失败与排查顺序（按发生频率排）
8. L1／L2／L3 证据

真卡节选——18-01，块炼炉一炉次：

> **输入材料**：精矿 20–40 kg（品位 ≥40%、粒度 5–20 mm、干燥）。
> **所需工具**：块炼炉（18-03 建炉七步已过首烘验收）；风箱，两人轮换鼓风；炉钩与钳。
> **操作顺序与控制点**：①点火装底炭——炉缸装炭至风口以上 200 mm，投入火种，缓风直到起火……
> **经验参数**：矿炭比 1:1.5–2；每炉炭 80–120 kg；稳态每千克致密铁耗炭 20–35 kg。
> **合格／返工／报废**：合格＝出致密可锻铁饼 1.5–3 kg、渣流顺畅；返工＝出铁量低但铁饼健全；报废＝点不着或炉缸冻渣。
> **常见失败（按频率）**：①点不着或升温慢 → 炭湿、底炭少、风不足……

凡是经验值，卡里都写明"须按本地材料标定"。不知道的地方就写不知道，并给出能把它定下来的那个试验——不为了表格好看而补数字。
