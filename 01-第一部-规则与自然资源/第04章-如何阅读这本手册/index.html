    第4章 如何使用这本手册：导航、工艺卡与现场作业组织¶

    本章目标¶

    • 掌握本手册的导航系统：前置章节编号规则、四种依赖核对、核心/替代路线选择、章节启动门槛、失败记录与版本管理、技术跳跃识别。
    • 掌握工艺卡的现场使用循环：从"开工前核验"到"归档誊抄"的一次完整作业怎么走。
    • 产出四件方法工具：四依赖核对表、章节启动三查表、读者版章节完成度自查清单、技术日志格式与版本命名规则。
    • 本章与总纲 G02（作者模板）互为镜像：总纲 G02 约束作者怎么写，本章约束读者怎么读、怎么判定"这一章我完成了没有"。第二版起总纲 G02 增至七条铁律与八字段工艺卡制度——本章与之同步。

    最低前置条件¶

    项 要求 来源
    知识 七条铁律 总纲 G01
    知识 章节模板与三级验收制度 总纲 G02
    知识 六大谱系与反馈环 总纲 G03

    4.1 依赖等级与前置章节编号¶

    编号即依赖：第 N 章只能引用编号小于 N 的成果。这是全书防止工具穿越的机械判据，也是读者的第一道核对。

    读者使用法（三个动作）：

    1. 读前扫前置：翻开任何一章，先读"最低前置条件"表，逐行核对"来源"列的章节号。任何一行不满足，先回去补，再回来。
    2. 读中盯引用：正文中每个工具首次出现时都标注来源（章节号或总纲文件号）。凡看到无标注的工具，记入"跳跃登记"（见 4.6）。
    3. 读后查清单：对照该章 A 清单（已有工具）与 B 清单（新增工具），核对自己实物是否对得上。A 清单里列出的实物，你应当已经拥有；缺了就是前置欠账。

    "预告"与"可用"的区别（全书最常被误读的一条）：手册允许写"该能力将在第 N 章建立"，这是预告；预告物不可当作已有使用。判定方法极简单：看它出现在哪一章的 B 清单里、该章你是否已验收到对应等级。例：第2章可以预告"煅烧验证将在第12章回填"，但第2章自己不能烧任何东西。

    读者自建内容同法：你为自己的聚落增补的任何工艺记录，也必须写来源章节号，接受同一套规则审计。这套规则保护的不是本手册的权威，是你自己依赖链的可追溯性。

    4.2 工具、材料、能源和知识四种依赖¶

    一切"卡住"都可以归入四类依赖之一。每类的核对动作与缺项处置：

    依赖类 核对动作（问什么） 核对对象 缺项处置
    工具依赖 需要的工具实物在场且完好？ 各章 A/B 清单＋你的工具档案 查该工具制造章节，先补造；无替代则该章未到启动条件
    材料依赖 需要的原料数量够这次＋试错两次？ 资源地图＋储备台账（第2章、3.6） 查该章替代路线节；储量不足先补采集
    能源依赖 需要的热/机械能，燃料与动力够？ 燃料条目＋能量条目（2.5） 查能源谱系上游（第6章火、21 章水力）
    知识依赖 不看手册能写出原理与关键参数窗口？ 该章正文＋你的复述测试（3.7） 重读＋口试；知识缺项禁止用"试一把"代替

    组合示例——第6章（生火）的四依赖预演：

    • 工具：无硬性前置（弓钻属 7.6，第6章摩擦取火用徒手可制的火弓板——以第6章正文为准）；
    • 材料：引火物（细干草、桦树皮内层）、火绒、燃料（2.5 的枯立木条目）；
    • 能源：人力；
    • 知识：燃烧三要素、引火物分级、通风原理。

    四栏齐了，第6章达到启动条件。任何一章都可以照此填出一张启动卡。

    4.3 核心路线与替代路线¶

    核心路线 = 手册主线默认顺序，骨架是五条关键链（引自总纲 G04）：

    1. 石器 → 木工工具 → 简易机械（第5、7、9章）
    2. 火 → 炉窑 → 耐火材料 → 金属冶炼（第6、12、16–18章）
    3. 金属工具 → 测量 → 精密加工 → 机床（第19–22章）
    4. 机械动力 → 电磁学 → 发电机 → 电力系统（第21、28–32章）
    5. 玻璃与化学 → 材料提纯 → 半导体加工 → 集成电路（第14、23–26、33–35章）

    替代路线的固定标注格式（铁律五，缺一不可）：性能损失 / 资源成本 / 适用边界 / 最终瓶颈。示例（预告）：无燧石地区走石英岩/黑曜石石器路线（第5章）——性能损失：边缘保持性差或材料过脆；资源成本：需更远距离采集；适用边界：只覆盖砍砸-刮削类工具；最终瓶颈：无法提供细加工刃口，必须尽早进入金属路线（第16–18章）。

    路线选择三步法：

    1. 用环境评估表（总纲 G04四，十行）逐行填自己的现状；
    2. 对照资源地图（第2章）核对每行；
    3. 两表交叉后确定本聚落的主线与需提前/延后的章节。原则：环境差异不仅改变材料来源，还会改变发展顺序（例：水力丰富的地区可让部分机械章节提前；缺燃料地区玻璃与冶金章节必须后移并先解决能源）。

    替代路线使用规则：替代品上线后，该章验收判据必须重新验证，不得沿用核心路线的验收值。替代材料的行为几乎总是不同（收缩率、热稳定性、强度），沿用旧判据会漏掉真实缺陷。

    4.4 如何判断一个章节是否可以开始¶

    启动三查（每查一栏，填启动卡）：

    1. 前置完备查：按 4.2 四依赖逐项核对，来源章节全部达到其自身验收标准（至少 L1，涉及安全的章节按其自身要求加严）。
    2. 资源余量查：按该章"资源成本"估算本次＋两次失败所需材料与燃料。余量低于两倍计划消耗不启动（经验值：试错率在 L1 阶段普遍高于五成，需现场按失败记录修订）。
    3. 人力时间查：该章工时估算 ÷ 可投人数 = 日程；超过一个连续工季的章节要拆段。

    "可以做但不应做"：三查通过≠应该立刻做。用优先级框架（总纲 G04三）复算一遍：不制造它会卡住什么？有无更廉价替代？此时投入人力的机会成本是什么？第1章 1.5 的五问逐条回答后再开工。

    暂停判据：同一失败模式连续出现 3 次（经验值）→ 强制暂停，回查前置（材料批次变了？工具磨损了？知识缺项？）。连续同模式失败几乎总是前置问题，不是手艺问题。

    读者版章节完成度自查清单（核心交付，逐项打勾，缺一项即未完成）：

    （甲）开始前 - [ ] 已填本章启动卡（四依赖核对＋资源余量＋人力时间） - [ ] 前置章节全部达到其验收标准，等级已记录 - [ ] 本章的安全边界已读，危险操作的禁止条件已摘录到现场可见处

    （乙）过程中 - [ ] 每次操作按技术日志格式留痕（日期/参数/结果/失败模式） - [ ] 失败按五分类归档（见 4.5），未归档的失败不算发生也不许再犯 - [ ] 参数按窗口法记录（最小可用/常用/最大可用）

    （丙）完成后 - [ ] 本章验收判据逐条实测，未以"看起来做出来了"代替 - [ ] 达到的等级（L1/L2/L3）如实判定并记录，L2 需连续 3 次合格品证据 - [ ] 本章 B 清单新增工具已编号入工具档案，损坏可修复/重造的途径已写明 - [ ] C 清单（尚未解决的依赖）已抄入自己的依赖图，标注目标章节 - [ ] 资源地图相关条目已回填验证状态（第2章回填规则） - [ ] 下一章的启动卡可以据此开填

    4.5 失败记录、工艺改进与版本管理¶

    技术日志格式（每章一册，泥板或刻木，逐列刻记）：

    列 内容
    日期/操作人 日名＋人名
    目标 本条操作想达成什么
    前置核对 启动卡四栏是否全绿（若此刻才发现缺项，如实记）
    操作记录 实用参数（长度/质量/时间/温度锚读数）——按第3章四类基准记录
    结果 成品尺寸、现象、验收判据逐条通过情况
    失败归类 五分类之一（见下）
    改进假设 下一条要改什么变量（只许一个）

    失败五分类（排查按此顺序，逐类排除）：

    1. 前置缺失：工具不在状态、材料批次不同、能源不足——回启动卡；
    2. 参数越界：操作参数跑出工艺卡窗口——回 3.7 参数窗口，窗口没建立的先做窗口试验；
    3. 材料差异：同名材料不同产地行为不同——回第2章重测，条目分立；
    4. 操作失误：工序顺序、手法偏离工艺卡——复述测试补工序描述；
    5. 判据错误：验收判据本身不对应真实用途——改工艺卡的判据栏并升版本。

    改进循环（单变量法）：假设 → 只改一个变量 → 记录 → 有效则出工艺卡新版，无效则变量回退、假设作废记录在案。

    版本命名规则：工艺名＋第几版＋日期编号（例：步测标定 v2 / 第45日）。新版卡与旧卡之间以"取代"双向链接，旧卡存档不毁。禁止口头改工艺（3.7 已定，此处为执行位）。

    三个反模式（自查）：

    • 同时改多个变量——无法归因，等于把实验变成赌博；
    • 无记录重试——同方法重复失败 3 次即触发 4.4 暂停判据；
    • 把偶成当工艺——未复现 3 次的不出卡，不进清单 B。

    4.6 如何识别不合理的技术跳跃¶

    跳跃 = 某环节调用了不存在的东西。读者用以下六信号审计任何技术资料——包括本手册、外部口传知识、其他聚落的工艺——发现即登记：

    信号 判问
    1 无来源的工具 出现的工具在清单 A/B 与章节号里查无此项？
    2 精度无来源 写"精确到××"，但基准、量具、检验方法在哪章建立？
    3 材料链条断 直接"用钢/用玻璃/用试剂"，制造章节在哪？（铁律三）
    4 单件当体系 有成品、无维修、无备件、无补给计划即宣称"已掌握"
    5 验收靠外观 成功判据是"看起来像"，无功能与可重复测试（铁律四）
    6 替代无代价 替代品被说成与原物等价，无性能损失与边界说明（铁律五）

    审计练习（两条，读者自答）：

    • 例 1："用铁锅烧石灰。"——铁锅从哪章来？（信号 1＋3：铁器第18章之后，且锅类铸件另有前置；烧石灰的正确容器路线在第12–13章。）
    • 例 2："按图纸精确截取等长木料六根。"——"精确"的基准与量具在哪章建立？（信号 2：长度基准第3章，复制尺寸靠标准杆与刻痕比对，不是一句"精确"。）

    处理流程：发现跳跃 → 写入"跳跃登记"泥板（日期/出处/信号类型/所缺依赖）→ 判定补链（回所缺章节）或改线（走替代路线）→ 若登记条目指向本手册，按总纲 G01开头的冲突规则处理：以铁律与前置编号为准修订。

    登记制度的意义：跳跃登记是聚落的技术免疫系统。无人维护它，三个月后口传经验会悄悄混入"听起来合理"的穿越项，而那时已经没人记得它们从哪来。

    4.7 工艺卡的现场使用循环¶

    第二版起，全书关键工序以工艺卡（编号如 20-01）交付，卡可单页抄出带到工位。现场一次完整作业按五步走：

    1. 开工前核验：不念正文，先过本章"开工前核验"表逐条打勾——判据不合格不开工。缺哪条回哪章补，不带病开工；
    2. 按卡操作：照卡的字段顺序走（输入材料→工具→操作与控制点→参数）。卡上标 ◎ 的步骤是手感步骤——按卡上给的练习法与代偿判据执行，不凭感觉发挥；
    3. 过程记录：卡上"过程观察记录项"每档记一笔（颜色/声音/读数），当时记、记原文——收工后补记的观察一律注明"补记"；
    4. 判据三分：结果按"合格/返工/报废"三分处理，不许"差不多就过"；返工按卡的返工路径走，报废件按卡说明处置（多数是留样入失败样品库）；
    5. 归档誊抄：本批实测参数与卡上默认值不同的，标定后誊入台账（第43章）——下一批人只查台账不凭记忆。卡纸用旧归档。

    这一循环就是铁律六（凡验收必存证据）的现场形态。 跳过第 5 步的作业只是"干完了活"，不是"建立了能力"——下一批人还得从你的起点重新摸索。

    4.8 最小制图法（三视图、基准与公差的工地板载版）¶

    本节是第 42 章（工程制图与版本控制）的临时载体版：纸要到第 41 章才有，但从第 5 章起你就需要画图——画在木板、树皮、黏土板上。规则与正式制图完全一致，只是载体不同。

    三视图（正面/平面/侧面）：对同一物件从三个方向画轮廓，"对正、平齐、等宽"三口诀——正面图与平面图上下对正，正面与侧面左右平齐，平面与侧面宽度相等。黏土板上用刻针（第 5 章尖状器）刻画；木板上用炭条打底、刻刀定型。

    基准面优先：图上第一笔永远画基准（一个面或一条边），其余尺寸全部从基准量起，不许链式接力——链式累积误差，从基准出发误差不叠加（第 22 章公差思想的前身）。

    名义尺寸＋上下偏差：每个尺寸写"目标值＋允差"，如"轴径 20，可 19.8–20.2"。黏土板写不下时用刻点计数（五点一杠，第 3 章法）。只写目标值不写允差的图，按第 4.6 信号 5 判为不合格图。

    比例与图号：比例只用整数倍（1:1、2:1、1:2，第 3 章纪律）；每张图右下角刻图号（日期＋序号，第 3 章档案法）与绘制人记号。木板图在角部烙印（火锥烫号）防抹。

    ◎画图手感：直线以绷紧的麻线压印打底（长线），短线用直尺边（第 20 章三尺互检后的尺）；练法：同一物件画三遍，三张图互相叠对——轮廓重合者合格。

    4.10 最小档案制度（编号、双份、借阅三件事）¶

    完整档案体系在第 43 章；从第 5 章起只要求三件事，这三件是第 43 章制度的种子：

    1. 编号：一切记录件刻"日期＋序号"（第 3 章法）＋归属（哪章哪卡）。无编号的记录件视同废纸；
    2. 双份异地：永存级记录一律两份，分放两处（两栋建筑或一屋一窖）——单份记录等于没有记录；
    3. 借阅登记：记录件不外带。需在现场用，抄工作副本带走，母件留柜并刻"借出中"标记——母件丢失的记录视同该工艺降回第一档（无证据的合格叫印象，铁律六）。

    与后续章节的接口：第 41 章纸与墨兑现"耐久可复制"的载体；第 42 章把本节"允差写法"升级为完整公差标注与版本控制；第 43 章把本节"三件事"扩为分级档案、负结果库与师徒传承。本节是它们的根——写进第 4 章，是因为从第 5 章起每一次验收都要用到它们。

    失败模式与诊断【方法章】¶

    本章失败模式：①只查前置不查判据（核验表逐条打勾才开工）；②预告当已有（B清单核对）；③口头改工艺未开新版（版本纪律）；④台账抄了不誊抄（4.7 循环第 5 步）。

    工艺卡索引【方法章】¶

    本章不设工艺卡——交付物为方法件（清单/表格/循环），见 B 清单；各工艺章的卡以本章 4.7 的循环使用。

    安全边界¶

    • 本章为方法章，无物理操作。唯一硬条款：自查清单（甲）未通过的章节，涉及火、高温、重物、深水、坠落的操作禁止启动——阅读可以，动手不行。
    • 任何人（包括有现代知识的读者）不得以"我了解原理"豁免启动三查；知识依赖的核对方式恰恰是复述测试（4.2）。

    验收标准¶

    • L1 原理验证：对任一已读章节，能口述其四依赖、当前等级与下一级差什么；能对一条外部建议说出它命中六信号中的哪几条。
    • L2 可重复制造：用启动三查＋完成度自查清单实际走完一个后续章节（建议第5或第6章），技术日志与工艺卡留痕完整，并由第二人按清单逐项复核通过。
    • L3 可持续生产：聚落形成制度——所有工艺有版本号与取代链；跳跃登记有人维护且每季度复核；一名新成员仅凭档案（工艺卡＋日志＋符号表）复现一项一级工艺（如步测标定或黏土沉降试验）并验收合格。

    下一步依赖¶

    • 第一部（第1–4章）至此闭合：规则（1）、资源（2）、测量（3）、方法（4）四件套就位。这是全书唯一不需要实物制造的一部，也是唯一一部以"制度"为产出的一部。
    • 第5章起进入实物制造：其启动卡将引用第2章资源地图（石料条目）、第1章边界规则（捡拾天然石）与第3章标准杆（尺寸记录）。
    • 信息谱系（谱系六）自本章成型：口头经验→判定规则→图形记录→统一计量→工艺记录已建立；技术图纸与标准化在第四部（第20–22章）升级，生产记录与自动控制在第六部之后。
    • 四依赖核对与跳跃登记将喂入全书各章的"安全边界"块与附录的审计工具（附录 A 重编总图时收录本清单）。

    能力边界与参数说明¶

    能力边界：本章交付的是方法工具（四依赖核对表、启动三查表、自查清单、日志格式、工艺卡使用循环），全部为制度件——不制造实物、无工艺参数。方法章的"验收"是使用证据：表格被实际用过且留下记录（见验收标准），不是纸面齐备。 参数表：本章无工艺参数，不设参数总表；全书一切参数随其工艺章交付，本章只规定"参数必须带标定法"的检查规则（4.6 信号 2）。
