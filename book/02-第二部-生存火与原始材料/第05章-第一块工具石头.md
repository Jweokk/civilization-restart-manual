### 5.1 如何识别适合打制的石料

打制石料五判据，全部满足才进入试打：

1. **均质**：新鲜断口各处颜色、粒度一致，无条带、斑块与夹层。
2. **细粒**：肉眼与指腹均察觉不到晶体颗粒。断面观感应是"凝固的糖浆"，而非"砂糖"。
3. **贝壳状断口**：敲落的新鲜断口呈弯曲曲面，常见同心波纹，边缘自然锋利。
4. **各向同性**：从任意方向打击都出现同样的贝壳状断口；没有固定开裂面（区别于板岩、页岩的层理和长石类晶体的解理面）。
5. **新鲜**：风化面发白、指甲能刮下粉末的"朽石"内部多有微裂，禁用。

野外四步流程：

* 第一步**找**：优先河滩砾石（水流已完成分选，软弱石被搬运磨淘汰）；其次石灰岩山体的结核（沿灰岩层面呈团块状）；再次砾岩胶结带、火山坡积。

* 第二步**敲**：用一块手中石敲掉一角，观察新鲜断口；同时听声：清脆"叮"声为致密无裂，闷哑声提示内裂或多孔。

* 第三步**划**：互刻划试验分级（参照莫氏硬度：指甲≈2.5，骨片≈3，石英≈7）。合格刃材应被石英划动、且能划伤骨片，即约莫氏6—7的硅质岩。

* 第四步**记**：位置、岩性、断口描述、试打结果，登记入资源地图（第2章格式）。

排除清单：

| 排除对象             | 特征         | 原因             |
| ---------------- | ---------- | -------------- |
| 页岩、板岩、片岩         | 一敲成片、层面平直  | 层理控制开裂，做不出受控刃缘 |
| 粗粒花岗岩类           | 颗粒肉眼可见     | 晶界处崩落，刃缘不连续    |
| 强风化石             | 表面白化、指甲刮出粉 | 内部微裂发育，打击时整体崩碎 |
| 多孔火山岩（浮岩除外，另有用途） | 气孔多        | 无法形成连续刃缘       |

### 5.2 燧石、燧石质岩石与其他可打制石材

| 石料       | 常见产出       | 断口品质     | 刃缘水平               | 主要局限         | 优先级  |
| -------- | ---------- | -------- | ------------------ | ------------ | ---- |
| 燧石/玉髓/碧玉 | 灰岩结核、砾石    | 贝壳状，平整   | 最优，刃缘厚约0.01—0.05mm | 仅沉积岩区有       | 首选   |
| 黑曜石      | 火山玻璃坡积     | 最平整光亮    | 比燧石薄约一个数量级，锋利第一    | 极脆，砍砸即崩，仅限切割 | 有则用  |
| 石英岩      | 变质砂岩、河砾    | 受晶粒干扰，粗糙 | 刃缘锯齿偏大、寿命短         | 只能做加厚刃       | 次选   |
| 硅质灰岩结核   | 灰岩区        | 接近燧石     | 良                  | 常夹方解石白脉，沿脉崩裂 | 逐块试  |
| 角岩、致密玄武岩 | 接触变质带、火成岩区 | 韧而不脆     | 不适打薄刃              | 走磨制路线（5.5）   | 磨制首选 |
| 流纹岩/霏细岩  | 火山碎屑区      | 中等       | 中                  | 产地局限         | 备选   |
| 石英晶体     | 脉石英        | 沿愈合裂隙与晶粒界走裂（无解理，断口不连续，常见乳白/烟色包裹体） | 不可控 | 只作砸击锤用 | 排除刃材 |

寻找策略：河滩第一，灰岩结核第二，火山区找黑曜石坡积第三。古采石场识别标志——坡地上出现大量无法用自然搬运解释的锐利碎石屑堆。

**替代路线边界（铁律五）**：无燧石环境的现实顺序为：石英岩/硅质灰岩（打制）＋角岩/玄武岩（磨制）。性能损失必须写明：刃角需加厚10°—20°；同任务切割寿命约减半（经验值，需现场标定）；打制废品率上升、长薄石片难获得。结论：替代路线不影响后续章节的技术链成立，只降低效率与成品率。

### 5.3 石片、石核与锋利边缘

**原理——赫兹锥**：硬物冲击石面，应力以锥形向下传播（锥角约136°，经验常数）。当打击点落在石核台面边缘、且台面角（台面与待剥侧面的夹角）小于90°时，锥面与核边相交，裂纹沿"台面缘—石核侧面"预定路径扩展，剥下一枚带锋利边缘的石片。台面角≥90°时，冲击能转为局部压碎，得到的是碎屑而非石片。

三个几何参数（用第3章角度板测量）：

| 参数  | 定义       | 控制范围               |
| --- | -------- | ------------------ |
| 台面角 | 台面与剥片面夹角 | 剥片要求<90°，理想70°—85° |
| 刃角  | 石片刃缘两面夹角 | 由用途定（见5.5）         |
| 长厚比 | 石片长/厚    | 硬锤剥片约2:1，软锤可达3:1以上 |

剥片流程：

1. **选核**：拳头至两拳大，无可见裂纹，至少一个可作台面的平整面。
2. **修台面（硬锤）**：以300—600g致密砾石锤沿核缘敲出连续平整带，宽10—20mm。
3. **剥片（硬锤）**：左手握核（必垫兽皮或厚树皮），右手锤以短促弹击（挥幅30—40cm）打击距台面缘5—10mm处。落点准确优先于力量大。
4. **细剥（软锤）**：换鹿角段或硬木棒（200—400g），贴近台面缘"擦击"，可剥更长更薄的石片。
5. **石叶（升级项）**：将核修成棱柱状，沿棱顺序剥下平行长石叶，用料最省、刃缘最直。

失败排查：①全是碎屑→打击点离台面缘太远或台面角过大，重修台面；②石片纵向劈裂→石料内裂，弃料；③锤打滑→台面缘过圆，再敲出锐棱；④**台阶（hinge）**——石片中途折断在核上留下阶梯坎→打击能不足或落点过深，下一击从坎的外缘重新起剥，不要直接从坎底硬打；⑤**崩边过半**——刃缘剥落超半圈→捶击代替压剥，改软锤轻剥。

**石斧绑缚三绳结与受力测试**：

| 结       | 打法                        | 用在        | 特点       |
| ------- | ------------------------- | --------- | -------- |
| 活套结（滑结） | 绳绕一圈抽紧即锁                  | 刃部与柄的首道定位 | 快，受力后要再紧 |
| 十字缠绕结   | 绳在"刃—柄"交叉处 8 字绕 6–10 道收平结 | 主受力绑      | 抗剪切      |
| 撑棍绞紧结   | 绑好后插短棍绞绳 2–3 圈、余端压入       | 柄尾防脱      | 最紧，可松可调  |

**受力测试（每件装柄后必做；绑缚材料现状=藤/湿皮条临时绑，绳与绳结为第 7 章预告，7 章解锁后回填正式绑缚）**：斧头挥砍空木 20 次——绑绳位移 <2 mm、无咯吱声为合格；再做 1.5 倍冲击（全力砍硬木 5 次）复检。位移超标的先绞紧复测，仍松则换更长绑段重绑。绑缚件是消耗品：**淋雨或浸泡后的绑绳必须复测**（湿胀干缩改变绑力）。

【卡 05-01 台面修整与硬锤剥片】（八字段）

1. **输入材料**：拳头至两拳大石核（无可见裂纹，至少一面可作台面）；致密砾石锤 300–600 g；兽皮或厚树皮护手垫一块。**不满足"无可见裂纹"的料直接弃，不试打**——内裂料打十次碎十次，浪费工时。
2. **所需工具**：硬锤（锤击面每半日用一次检查，出现饼状崩疤即换面或换锤）、角度板（第 3 章，测台面角用）、木砧（垫核防滚）。校准来源：锤重以第 3 章天平配平到 300–600 g 区间；角度板以 3-4-5 绳法自校。
3. **操作顺序与控制点**：选核 → 修台面（沿核缘敲出宽 10–20 mm 的连续平整带）→ 剥片（打击点距台面缘 5–10 mm，挥幅 30–40 cm，短促弹击）→ 检片。**控制点两个：台面角必须 <90°（角度板实测，理想 70–85°）；落点必须在距缘 5–10 mm，落点准优先于力量大。**
4. **经验参数与标定法**：台面角 70–85°（目测不可靠，一律用角度板；无角度板时按 3-4-5 绳法定一块 75° 样板比对）；锤重 300–600 g（天平配平）；挥幅 30–40 cm（以臂长为参照，约臂长三分之一）；长厚比目标 2:1（卡尺未出现前用"两指夹持看厚度"比对，第 20 章量具出现后改实测）。
5. **过程观察记录项**：每核记 台面角实测值 / 锤重 / 落点是否偏移 / 成功片数 / 碎屑比例 / 失败形态编号（见字段 7）。
6. **合格／返工／报废判据**：合格＝同一核连续剥出 5 片以上、长厚比 ≥1.8:1、刃缘平整无台阶；返工＝出现台阶，从坎外缘重新起剥（**不许从坎底硬打**）；报废＝石料纵向劈裂（内裂）或连续三次全碎屑（料性不对）。
7. **常见失败与排查顺序**：①全是碎屑 → 先查落点是否离缘太远，再查台面角是否 ≥90°；②石片纵向劈裂 → 料内有裂，弃料，别归因于手法；③锤打滑 → 台面缘过圆，补敲出锐棱；④台阶（hinge）→ 打击能不足或落点过深；⑤崩边过半 → 硬锤改软锤（转卡 05-02）。
8. **L1／L2／L3 证据**：L1＝一枚合格石片＋一张记录；L2＝连续 10 核出片率 ≥60%＋逐核记录；L3＝第二人照本卡独立达到 L2，且两批石片的台面角实测值分布可对照。

【卡 05-03 石斧绑缚与受力测试】（八字段）

1. **输入材料**：打制好的石斧头（双面打制，15 cm 以上韧性石）；干直木柄（直径与斧头绑槽匹配，过细会转、过粗绑不紧）；藤条或湿皮条（**本章只作临时绑缚，正式绳与绳结在第 7 章解锁后回填**）；短棍一段（绞紧用）；木牍（记录）。
2. **所需工具**：石刀（修藤条端头）、木楔（撑开绑槽用）、刻线木牍（记录位移基准）。校准来源：无专用量具，位移用刻线比对，精度到 1 mm 级。
3. **操作顺序与控制点**：活套结定位（刃部与柄首道）→ 十字缠绕（刃—柄交叉处 8 字绕 6–10 道，收平结）→ 撑棍绞紧（插短棍绞 2–3 圈，余端压入）→ **受力测试（每件装柄后必做，不许跳）**。控制点：缠绕道数与绞紧圈数按记录写死，不许"看着差不多"。
4. **经验参数与标定法**：十字缠绕 6–10 道（少则抗剪不足）；绞紧 2–3 圈（再多会压断藤条）；测试标准＝挥砍空木 20 次，绑绳位移 <2 mm、无咯吱声；复检＝全力砍硬木 5 次（1.5 倍冲击）。位移判据用刻线比对，不合格即返工。
5. **过程观察记录项**：每件记 缠绕道数 / 绞紧圈数 / 20 次后位移实测 / 有无咯吱 / 是否淋过雨。
6. **合格／返工／报废判据**：合格＝20 次后位移 <2 mm 且无咯吱；返工＝位移超标，先绞紧复测，仍松则加长绑段重绑；报废＝绑段木材开裂或斧头绑槽崩口（换头）。
7. **常见失败与排查顺序**：①位移大 → 先查缠绕道数够不够，再查绞紧；②咯吱 → 结未收紧或藤条太干（换湿皮条）；③**淋雨或浸泡后必须复测**——湿胀干缩会改变绑力，这条是石斧飞头伤人的主因；④砍几次就松 → 绑段太短，受力集中。
8. **L1／L2／L3 证据**：L1＝一件装柄斧＋测试记录；L2＝5 件合格＋其中至少 1 件的淋雨复测记录；L3＝第二人照本卡独立装柄并通过测试，且两批的位移数据可对照。

### 5.4 石锤、骨质工具与木质辅助工具

**石锤两类**：

* 硬锤（直接打击）：致密岩（石英岩、燧石结核），300—600g，卵形，一端略收窄便于瞄准。每使用半日检查锤击面，出现饼状崩疤即换面或更换。

* 软锤（细剥）：鹿角段或硬木棒，200—400g。软锤有效的原因：接触面局部变形吸收冲击尖峰，裂纹起始于石核内部而非锤印处，故剥片更薄更长；代价是磨损快。

**骨器**（原料来自拾取的自然死亡兽骨与食腐残余）：

| 骨器  | 制作                                 | 用途                   |
| --- | ---------------------------------- | -------------------- |
| 压剥器 | 鹿角尖磨圆钝                             | 压剥修整刃缘（5.5）          |
| 骨锥  | 长骨纵劈成条，砂岩板湿磨出尖                     | 皮具孔、编结辅助             |
| 骨针  | 细骨条在细砂岩板上加水研磨成形，1—3小时/根（经验值，需现场标定） | 缝合与编网（待第7章纤维、第15章纺织） |
| 骨刮片 | 肩胛骨边缘磨刃                            | 刮皮上残肉（比石刃耐用）         |

骨料处理：新骨晾至半干再加工，过湿粘磨石、过干易脆断；带油脂骨久放有味但不影响使用。

**木质辅助**：木砧（垫石核防滚动的短粗段）、树皮或兽皮护手垫（握核手必垫）、备用楔段（配合5.7占位）。

本节全部工具均可由"拾取＋石锤＋磨石"重造，谱系自持达标。

### 5.5 如何制作切割、刮削和钻孔工具

四类工具规格表：

| 工具        | 选料/形制                  | 刃角        | 用途边界                         |
| --------- | ---------------------- | --------- | ---------------------------- |
| 石片刀       | 8—15cm直刃石片，手握区棱角敲钝防割手  | 20°—40°   | 切肉、皮、草茎；不可砍                  |
| 刮削器       | 厚石片端部或侧缘修钝刃            | 45°—70°   | 刮皮、刮木表皮；刃角大才扛得住垂直刮削力，钝刃是设计要求 |
| 尖状器（钻头毛坯） | 两侧对称压剥出短粗尖             | 尖角60°—80° | 钻孔与刻划；第7、9章钻孔钻头              |
| 手斧/砍砸器    | 双面打制，15cm以上韧性石（石英岩、角岩） | 60°—90°   | 砍木、砸骨；不得用于撬                  |

**压剥修整**（把"能切"变成"好用"）：鹿角压剥器顶住刃缘上方2—3mm处，与石面约成45°（经验值），以臂胸合力下压，每次剥落2—5mm宽的小片；沿刃缘逐段推进一圈，修出深度小于1mm的均匀锯齿。锯齿均匀=受力均匀=不发生局部崩刃。修整后刃缘呈规则波纹而非凹凸缺口，此为合格外观判据。

**锯齿石片（锯的雏形）**：选长直石片，沿一边压剥出齿距2—3mm的连续锯齿。本章只做手持往复锯的毛坯；装弓的正式弓锯见第9.2。

**磨制占位**：角岩、玄武岩毛坯在砂岩板上加水研磨可得刃口，耗时长（数小时级）但刃体坚韧，是砍伐工具的正路。完整磨制工艺在第9.2工装化后展开。

本节产出物统一编号，登记入工具档案（木牍，第3章记录格式）。

【卡 05-02 压制剥片与刃缘修整】（八字段）

1. **输入材料**：已剥下的石片毛坯（刃缘能切但毛糙）；鹿角段或硬木棒 200–400 g 作软锤；鹿角尖端磨圆钝作压剥器；粗/细砂岩板各一块；护手垫。
2. **所需工具**：软锤、压剥器、砂岩磨板、角度板。校准来源：软锤重量用第 3 章天平配平；压剥点位置靠目测＋标记（第 20 章后改实测）。
3. **操作顺序与控制点**：软锤沿台面缘"擦击"（贴缘不走空，剥更长更薄）→ 压剥器顶住刃缘上方 2–3 mm、与石面约 45°、以臂胸合力下压、每次剥落 2–5 mm 宽小片 → 沿刃缘逐段推进一圈。控制点：压剥点距刃缘 2–3 mm、角度约 45°，两点偏差都直接导致崩刃。
4. **经验参数与标定法**：软锤 200–400 g；压剥点距缘 2–3 mm（经验值，需按当地石料标定）；压剥角约 45°（经验值）；每次剥片宽 2–5 mm；修成锯齿深 <1 mm。**判定"45°"的办法**：用第 3 章 3-4-5 绳法裁一块 45° 角样板，压在刃面上比对，不靠手感。
5. **过程观察记录项**：每圈记 剥片宽度 / 锯齿深度 / 崩刃位置与个数 / 推进步距是否均匀。
6. **合格／返工／报废判据**：合格＝刃缘呈规则波纹（非凹凸缺口）、锯齿深 <1 mm、能连续切 20 刀不顿；返工＝局部崩刃，从崩口两侧向中间修、不许只补崩口一处；报废＝刃体磨到 <3 mm 无法再修（改作刮削器或弃）。
7. **常见失败与排查顺序**：①崩边 → 先查压剥角是否过陡，再查下压力是否过大；②剥不下片 → 压剥器太钝或顶得太靠里（>3 mm）；③锯齿不匀 → 推进步距不稳，改用"数着步子走"；④刃缘越修越薄 → 每次剥片过宽，收到 2 mm。
8. **L1／L2／L3 证据**：L1＝一片修整合格的石片刀＋刃缘照（或拓片）；L2＝连续 5 件合格＋锯齿深度记录；L3＝第二人照本卡独立达成，且废品率 <20%。

【卡 05-04 刃缘修磨与刃角复核】（八字段）

1. **输入材料**：钝化石片或磨制毛坯（角岩、玄武岩等韧性石）；粗砂岩板、细砂岩板各一块；水；护手。
2. **所需工具**：砂岩磨板（粗磨定形／细磨出刃，两块不混用）、压剥器、角度板、木牍。校准来源：刃角用第 3 章角度板实测；磨板平整度以两块互研对光无缝为准（第 20 章三平板思想的粗版）。
3. **操作顺序与控制点**：粗砂岩定形（去缺口、找平刃线）→ 细砂岩加水研磨（出刃口）→ 压剥修锯齿（转卡 05-02）→ 刃角复核。控制点：**刃角必须落在用途区间内**——石片刀 20–40°、刮削器 45–70°、尖状器 60–80°、手斧 60–90°，超出区间一律返工。
4. **经验参数与标定法**：四类工具的刃角区间见上（来自 5.5 规格表）；磨制耗时数小时级（经验值，随石料硬度浮动，需按本地石料标定）；磨削方向单向推、不回拉（回拉会把刃口磨圆）。
5. **过程观察记录项**：每次记 刃角实测 / 刃线直线度（对光看有无透光缝）/ 磨削时长 / 是否出现单侧偏磨。
6. **合格／返工／报废判据**：合格＝刃角落在用途区间、刃线对光无缝、连续切 20 刀不顿；返工＝刃角超差或单侧偏磨，重新找平再磨；报废＝刃体过薄（<3 mm）或刃线出现贯穿裂纹。
7. **常见失败与排查顺序**：①切不动 → 刃角过大（钝），回粗磨收角；②一用就崩 → 刃角过小（脆），加大刃角或改压剥；③越磨越不对称 → 单侧磨削时间过长，两侧交替计数；④刃口发亮不咬料 → 磨过头成"圆刃"，回压剥修出锯齿。
8. **L1／L2／L3 证据**：L1＝一件合格刃＋刃角实测记录；L2＝四类工具各一件＋逐件刃角记录；L3＝第二人照本卡独立达成，且两人磨出的同用途刃角实测值差 <5°。

### 5.6 如何检查石器是否适合预定用途

**目检（全数检验）**：

1. 刃缘锯齿均匀，锯齿深<1mm。
2. 对光缓慢转动，刃缘反光连续；反光中断处即微裂或崩口。
3. 指弹石背，声音清脆为无内裂；哑声即有裂，降级或报废。
4. 无贯穿性裂纹，打击泡附近无放射状隐裂。

**功能测试（抽样，用标准化工件）**：

| 测试 | 标准                    | 合格线（经验值，需现场标定）  |
| -- | --------------------- | --------------- |
| 切割 | 连续切兽皮或鲜肉50刀，单程10cm计1刀 | 崩口≤1处且≤2mm      |
| 刮削 | 湿皮往复刮30次，每次行程5cm      | 无>2mm崩口，刃角增大<5° |
| 钻孔 | 尖状器在硬木上磨转20分钟         | 尖不断、不出环形裂纹      |
| 砍砸 | 手斧砍硬木20次              | 崩碎区<刃长的10%      |

**钝化与崩刃必须区分**：钝化是刃缘均匀变圆，属正常磨损，可压剥复修，计入寿命；崩刃是局部崩落，指向材料内裂、台面角错误或超用途使用（如拿切割刀去砍），必须先查原因再重修。

**报废判据**：累计重修3—5次后刃体过薄；刃长损失超过1/3；出现贯穿裂纹。报废件改作砸击锤芯或压剥原料。

每次测试与重修记入工具档案：编号、石料、日期、测试数据、重修次数、报废原因。此档案格式即全书工具谱系的记录模板（第4章）。

### 5.7 如何从石器发展到复合工具

**为什么要装柄**：力臂放大（同样挥力，刃端速度约等于臂速×(臂长+柄长)/臂长）；手离开冲击区；打击动能集中于刃线。

**本章边界**：绳（7.4）、胶（8.5）、弓钻（7.6）均未出现，本章只做两项"占位验证"：

* 方案一（半复合）：短木柄一端顺纹劈口，垫入石片刃，用鲜树皮条或生皮条临时缠绕。缺点：干燥后松弛，每次使用前须重缠。此方案仅用于验证刃材与柄形匹配，不作正式工具。

* 方案二（火烧槽，待第6章稳定火堆后实施）：木柄预定槽线先烧焦成炭线，再用石片刮深。用热加工替代精加工，把开槽的精度要求降一个等级。

**占位验收**：装柄手斧空挥20次→轻砍木墩20次，绑扎位移<2mm、刃体不移位为占位合格。

**正式复合工具的依赖预登记**（防止后续章节工具穿越）：

| 环节  | 依赖         | 解决章节    |
| --- | ---------- | ------- |
| 开柄槽 | 烧灼＋刮削；弓钻排孔 | 6.5；7.6 |
| 绑扎  | 绳索、生皮条、筋腱  | 7.3、7.4 |
| 黏结  | 桦皮焦油/松脂胶   | 8.5     |
| 锁紧  | 木楔         | 7.5     |

完整装柄流程在9.1集中给出。

## 能力边界

**能做到**：锤击与压制两种剥片、六类石器（砍砸/刮削/尖状/石叶/石钻/石斧毛坯）功能级验收；台面角与打击点的现场判读；绑缚复合柄的受力测试（见 5.4 补块）。

## 安全边界

* 打制时打击点前方3m扇形区禁入；观察者只能站打制者侧后方。

* 握核手必垫兽皮或厚树皮；小石核禁止徒手紧握硬打，一律上木砧。

* 检查刃缘用手背轻掠，禁止指腹沿刃抚摸。

* 黑曜石碎屑极锋利且难看见，收工时必须清扫收集。

* 有裂纹的石料禁止用作锤具——打击中会整体爆裂崩飞。

## 验收标准

* **L1 原理验证**：敲出至少一枚具贝壳状断口的锋利石片，能割断草茎、剥除树皮。

* **L2 可重复制造**：按档案记录的选料—剥片—修整工艺，在3个不同采集日各制成1套（刀＋刮＋尖＋锤），全部通过5.6功能测试；单件用时与废品率已记录。

* **L3 可持续生产**：石料来源在资源地图登记≥2处；硬锤/软锤损耗率已知且有替换来源；工具档案在册≥20件；重修流程执行≥5次；新手按档案复现的成功率≥50%（经验判据，团队内考核）。
