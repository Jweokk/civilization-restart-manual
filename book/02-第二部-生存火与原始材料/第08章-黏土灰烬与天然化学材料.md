# 第8章 黏土、灰烬与天然化学材料

> 第二部·生存、火与原始材料。本章建立第一批"化学能力"：黏土评价、灰碱、颜料、黏结剂，以及——更重要的——小规模材料试验与配方记录的方法论。无陶器、无玻璃器：一切液态操作使用葫芦、贝壳、木槽、兽皮袋。

## 本章目标

- 建立黏土寻找—识别—性能评价的完整流程（为第11章制陶预研并备料）。
- 建立草木灰浸出碱液、石灰石登记、天然颜料、树脂与焦油胶、皮胶的采集制备工艺。
- 建立"标准试件＋单变量试验＋记录表"的材料试验制度——这是化学谱系（谱系五）与信息谱系（谱系六）的共同起点。
- 产出物：黏土试验档案、第一批焦油胶与粘结强度数据、配方记录制度。

### 8.1 如何寻找和识别黏土

**找矿位置**（按优先序）：河湾内侧凸岸（水流减速沉积细粒）；洪泛区；湖沼边缘；泉眼下方坡积；滑坡新切面；蚁丘与兽洞翻出的底土（细粒、湿时粘）。

**露头外观判据**：湿时粘鞋粘手、捏得出指印；干后表面收缩成多边形裂纹块；断口细腻无砂感；土色灰、黄褐、红褐、蓝灰均可（色泽只作编号不作取舍）。

**野外三试（按序执行，每试都记录）**：

| 试验 | 方法 | 合格判据 | 淘汰判据 |
|---|---|---|---|
| 舔试 | 黄豆大土粒**舌尖舔后立即吐出漱口**（不咀嚼不吞咽——防病原与砂粒磨牙） | 细腻滑腻、无砂感 | 明显砂粒感——含砂过高，需淘洗或换点 |
| 条试 | 加水搓成直径6mm泥条，搓至15—20cm长 | 不断、无横向裂纹；进一步搓至3mm仍能弯成环不断者为高塑性 | 一搓即断——塑性不足 |
| 缩试 | 搓4cm泥球，阴干24小时 | 收缩明显但表面仅细纹 | 深裂——收缩率过大，需掺羼料 |

**沉降法测含砂（无玻璃器方案）**：葫芦、大贝壳或烧凿木槽盛水，投入等体积土样搅匀，静置1—2小时。分层读数：底层粗砂、中层粉、顶层悬浮细泥。泥层厚度占比>50%为优（经验值，需现场标定）。上层泥浆小心倾出——倾出的就是初步淘洗的细泥。

**登记**：每处矿点按第2章资源地图格式记录位置、描述、三试结果、估计可采量、试块编号。取 representative 样1—2kg 带回作8.2与8.6试验。

### 8.2 黏土的塑性、收缩与开裂

**含水量手感阶梯**：干粉→潮（捏不成团）→**塑性区**（成团不粘手、不裂，触感如耳垂）→软泥→泥浆。塑性区含水约18%—28%（经验值，需现场标定）。一切成形操作只在塑性区进行。

**练泥**：使用前反复揉压（螺旋揉）10—15分钟，目的：均质化＋排出气泡。气泡在后续干燥与烧成中会鼓泡开裂。

**收缩率测定**：制标准泥棒（12×2×2cm），表面刻10cm标准线（第3章刻线尺），阴干后量线长。干缩=（10－实测长）/10。常见范围5%—10%（经验值，需现场标定）。同一批泥的收缩率是后续制陶放样的依据。

**羼料（抗收缩开裂的掺料）**：

| 羼料 | 粒径 | 首掺比例（体积） | 说明 |
|---|---|---|---|
| 洗净石英砂 | 0.5—1mm | 10%—20% | 通用 |
| 碎贝壳粉 | 过粗砂级 | 10%—20% | 耐热震好 |
| 碎旧陶 | — | — | 无陶时期暂缺，第11章后启用 |

掺量梯度试验：0%、10%、20%、30%各做一组试棒（8.6制度），以"干后无裂纹＋强度最高"择优。

**开裂四因排查**：干燥过快（阳晒、风口）→缓干；不均质（气泡、干湿团块）→回炉重揉；羼料过量或过粗→降比；厚度突变→厚薄比≤2:1并做过渡。

**干燥规程**：阴凉处覆草或大叶缓干；全干判据：试棒颜色变浅、贴唇无凉感、重量不再下降。全部数据记入试验表。

【卡 08-02 黏土三试与沉降分级】（八字段）

1. **输入材料**：候选矿点土样 1–2 kg（取 representative 样，避开表层浮土）；水；对照样一块（已知可用黏土，仅作手感参照）。**同一矿点至少取三个点位的样**——河湾沉积在一处之内也会分层。
2. **所需工具**：石片（划划面）、木槽或葫芦或大贝壳（沉降用，需透明或可看清分层）、刻线尺（第 3 章）、记录表。校准来源：刻线尺按第 3 章标准杆刻；沉降分层靠目视读比例，无仪器。
3. **操作顺序与控制点**：舔试 → 条试 → 缩试 → 沉降法测含砂，四步按序做、每步记结果。控制点：**舔试后立即吐出漱口，不咀嚼不吞咽**（防病原与砂粒磨牙）；**缩试必须满 24 小时**，早看会把"未干透"误判成"不裂"。
4. **经验参数与标定法**：舔试合格＝细腻滑腻无砂感；条试＝搓成直径 6 mm 泥条、搓到 15–20 cm 不断无横裂，进一步搓到 3 mm 仍能弯成环不断者为高塑性；缩试＝4 cm 泥球阴干 24 小时，仅表面细纹为合格，深裂即收缩过大需掺羼料；沉降＝等体积土样入水搅匀、静置 1–2 小时读分层（底层粗砂、中层粉、顶层细黏）。
5. **过程观察记录项**：每样记 矿点编号与点位 / 三试逐项结果 / 沉降分层比例 / 估计可采量 / 取样日期。
6. **合格／返工／报废判据**：合格＝三试全过（细腻、不断、仅细纹）；返工＝含砂感明显，淘洗后复测三试；报废＝缩试深裂且按 10%–20% 掺羼料后仍裂（该点只宜作粗陶或砖瓦）。
7. **常见失败与排查顺序**：①条试一搓即断 → 塑性不足，先查是否含砂过高（看沉降分层），再考虑掺入高塑性土；②缩试深裂 → 收缩过大，按 10%、20% 两档掺洗净石英砂（0.5–1 mm）复测；③沉降分层看不清 → 静置不足或水太浑，延长静置；④舔试砂感重 → 该点含砂高，只作羼料或砖瓦料。
8. **L1／L2／L3 证据**：L1＝一个矿点的完整三试＋沉降记录；L2＝三个矿点各一份记录，且能按数据排出优先级；L3＝第二人照本卡独立复测同一样，三试结论一致（不一致说明判据写法还不够硬，回改本卡）。

### 8.3 草木灰、石灰石和其他基础原料

**草木灰成分（定性描述＋工程用途）**：主要含碳酸钾、钙镁碳酸盐、磷酸盐、硅酸盐及微量钠。硬木灰与软木灰的钾钙比例不同，禾草灰含硅高。灰是本阶段唯一可规模获取的碱源。

**碱液（灰水）浸出**：

- 配比：灰:水＝1:3至1:5（体积，用第3章标准木斗量取）。
- 工艺：灰入木槽/兽皮袋悬浸2—4小时（经验值，需现场标定），搅拌2次，静置，倾出上清液；可二次浸出提高浓度。
- 判据：滑腻手感＝碱性强（手感试验为定性级，只判有无，不判浓度）。
- **浮蛋法浓度档**：鲜蛋放入碱液——**沉底=淡（约 5% 级以下）；半悬浮直立=中（约 5–10%）；浮起露顶约拇指大=浓（约 10–15% 级）**（对碳酸钾液的经验对应，需现场标定：自配已知档位液实测本蛋的对应姿态——蛋的大小影响姿态，本队用本队蛋标定）。制皂用中浓档、浸出再生用淡档，逐批记录蛋的姿态与用途成对，形成本队"蛋姿—用途"表。蛋用后洗净仍可食用（碱液短时浸泡无害）。
- 用途（现阶段）：清洗油污工具与兽皮脱脂；沤麻助脱胶的小试；后续皂化制皂的碱源（正式皂化在第23章）。
- 警示：碱液腐蚀皮肤与眼，操作后冲洗；不与伤口接触；容器专用并标记（8.4颜料标记）。

**石灰石识别（本章只识别与备料，烧制在第13章）**：

- 外观：灰白色，细粒致密，常呈层状；硬度约3（骨片勉强可划，石英轻易划动）。
- 酸试（天然酸源）：酸模叶汁或变酸果浆滴于新鲜划面，冒泡=碳酸盐（方解石）。粉末冒泡缓慢者可能是白云石，登记时区分。
- 与石英岩区分：石英岩硬度7，石英划不动；石灰岩会被石英划出白痕且冒泡。
- 登记：矿点位置、估计量、纯度外观（杂质脉线多少），入资源地图。

**其他基础原料登记清单**（位置、估计量、验证试验、用途指向）：盐（盐泉、盐土、海盐——味试与蒸发残量）；硫（火山区结晶黄块，燃烧蓝焰与刺鼻气——登记不开采，第23章处理）；天然碱（碱湖白霜）；沥青/石油露头（黑粘、可燃）；石英砂（磨料与第14章玻璃原料，颗粒判据：圆粒、无泥、粒径0.1—0.5mm）；赭石矿（8.4）；石墨（划痕黑亮，登记）。

【卡 08-01 灰碱浸出与浮蛋法】（八字段）

1. **输入材料**：草木灰（**优先硬木灰**——硬木灰钾钙比高，碱性强；软木灰碱弱，两者不可混记）；水；鲜蛋一枚（浮蛋法用，可用完洗净复用）。灰须干燥存放，受潮结块后浸出率下降。
2. **所需工具**：标准木斗（第 3 章，量体积比）、木槽或兽皮袋（悬浸用）、搅拌棍、**专用并标记的碱液容器**（红条标记，见 8.4）。校准来源：配比以体积计，用同一只木斗量；浓度以浮蛋法判档，不用仪器。
3. **操作顺序与控制点**：灰入容器 → 按体积比加水 → 悬浸 2–4 小时 → 中途搅拌 2 次 → 静置 → 倾出上清液 → 需要更浓时二次浸出。控制点：**浸出时间与搅拌次数**；上清液必须静置后再倾，带渣的碱液堵不住也蚀不均。
4. **经验参数与标定法**：灰水体积比 1:3 至 1:5；浸出 2–4 小时（经验值，须现场按灰种标定）；搅拌 2 次。**浮蛋法浓度档**（把"滑腻手感"升级为可比档）：鲜蛋放入碱液——沉底＝淡（约 5% 级以下）；半悬浮直立＝中（约 5–10%）；浮起＝浓。**手感试验只判有无，不判浓度，不能替代浮蛋法。**
5. **过程观察记录项**：每批记 灰种（硬木／软木／混） / 体积配比 / 浸出时长 / 搅拌次数 / 浮蛋档位 / 用途（清洗、脱脂、沤麻、皂化原料）。
6. **合格／返工／报废判据**：合格＝浮蛋档达到该用途要求的档位；返工＝档位偏低，二次浸出或延长浸时后复测；报废＝无滑腻感且浮蛋全沉（灰已失效或非草木灰，换灰重做）。
7. **常见失败与排查顺序**：①碱太弱 → 先查灰种（软木灰钾少），再查浸时是否不足；②液体浑浊 → 静置不够或未滤渣；③同一批两次浸出浓度差别大 → 记录不全，补记灰种与时长；④**腐蚀伤害** → 碱液伤皮肤与眼，操作后冲洗、不与伤口接触——这一条写在卡首，不是附注。
8. **L1／L2／L3 证据**：L1＝一批碱液＋浮蛋档记录；L2＝硬木灰与软木灰各一批，档位差异有数据；L3＝第二人照本卡独立做出同档碱液，两人浮蛋判档一致。

【卡 08-04 天然酸制取与酸试用法】（八字段）

> **边界说明**：本卡只做"取酸液用于石灰石酸试"这一段，全部内容有正文支撑。原索引名里的"果浆醋化"在正文中未建立工艺，本卡不写，宁缺不编；如需正式制醋，应另立章节。

1. **输入材料**：酸模叶（或其他带明显酸味的植物叶）、变酸的果浆（两者任一即可）；待测石料的新鲜划面（**必须是新划的，风化面不冒泡，会把石灰石误判成石英岩**）。
2. **所需工具**：石臼（捣碎）、布片（包挤）、芦苇管或细竹管（滴液用，比手指涂抹可控）、记录木牍。
3. **操作顺序与控制点**：采叶 → 石臼捣碎 → 布包挤汁入小容器 → 用管滴一滴于新鲜划面 → 观察冒泡。控制点：划面新鲜度；滴液量以能挂住不流走为准。
4. **经验参数与标定法**：冒泡＝碳酸盐（方解石类，即石灰石）；**冒泡缓慢**者可能是白云石，登记时须区分；不冒泡＝非碳酸盐。与石英岩的区分要同时看两条：石英岩硬度 7，石英划不动它；石灰岩会被石英划出白痕**且**冒泡。
5. **过程观察记录项**：每点记 酸源种类（酸模汁／果浆）/ 划面位置 / 冒泡快慢 / 与硬度试验的结论是否一致。
6. **合格／返工／报废判据**：合格＝酸试与硬度试验结论一致且能明确区分石灰石与石英岩；返工＝酸液太淡（换个酸源或浓缩）或划面已风化（重划）；报废＝两法结论矛盾且无法判定，该点暂不列入石灰石矿点。
7. **常见失败与排查顺序**：①全都不冒泡 → 先查酸液是否太淡，再查划面是否风化；②冒泡但很慢 → 可能白云石，登记为"待定"不要当纯石灰石用；③把石英岩判成石灰石 → 只看了冒泡没做硬度，两法必须同做。
8. **L1／L2／L3 证据**：L1＝一个矿点的酸试＋硬度记录；L2＝三个矿点，其中至少一个被判为"非碳酸盐"，记录能复现判断；L3＝第二人照本卡独立判定同批矿点，结论一致。

### 8.4 天然颜料与表面处理

**颜料矿源与色系**：

| 色 | 来源 | 备注 |
|---|---|---|
| 红 | 赤铁矿（红褐色条痕） | 条痕在粗石板上划试 |
| 黄褐 | 褐铁矿/针铁矿 | — |
| 黑 | 锰矿；炭黑（松脂柴烟灰收集） | 炭黑最易得、最稳定 |
| 白 | 白垩、高岭土 | 与石灰石区分：高岭土遇酸不冒泡 |
| 白（代） | 贝壳粉 | 烧后碾细 |

**加工流程**：砸碎→石砧上干研→**水飞分级**：细粉入水槽搅浑，静置片刻倾出上层悬浮液到第二槽，沉淀后取底——得到细粒级颜料；重复2—3次得更细。水飞后细度以"指捻无粒感"为合格。

**调配**：颜料细浆＋黏结剂（树胶液8.5、兽脂或蛋清），体积从2:1试起（经验值，需现场标定）。每批在样品板（刨平木板或石板）上涂条并编号，记录配方与日期。

**用途**（现阶段的三项正式用途）：

1. 工具与容器标记：归属、编号、危险品（碱液容器红条）——信息谱系的第一个载体。
2. 试验样品编号：与8.6记录表一一对应。
3. 木材表面处理：兽脂薄擦多遍（防水）；蜂蜡（有蜂地区）热熔涂覆；松脂涂层（8.5）；烟熏黑化（防虫、装饰）。

### 8.5 树脂、植物胶和天然黏结材料

**松脂采集**：

- 活树切口：石片刀在树干斜向下切V形口，深至形成层下1—2cm即止，**严禁环剥**（环剥即死树）。每树每季切口≤3个。
- 集脂：切口下端嵌桦皮槽，1—2周收集一次；另拾老树疤的干脂块。
- 处理：生脂温热变稀即用；久存挥发变硬，可加热复原（小火，勿沸，近火有燃焰风险）。

**桦皮焦油（第一种高强度胶，无陶器制法）**：

1. 桦树皮（外硬皮刮去，取内层）卷紧成直径5—8cm的实心筒。
2. 土坑内竖埋树皮筒，筒周填土压实，顶部留一小孔，坑周堆炭火。
3. 闷热解1—2小时（经验值，需现场标定）后撤火，冷却后取出，筒内壁与筒芯刮取黑亮焦油。
4. 合格判据：温热时可拉丝、冷后仍微粘可塑；脆硬不粘=过烧，稀淌=欠烧。

原理：缺氧热解使桦皮中的桦木醇等转化为粘性焦油；土坑即"无陶干馏釜"。此法产率低（每筒数克至数十克），但每次成本极低，可反复烧制。

**装柄胶配方（体积份）**：焦油2＋细炭粉1＋干草纤维或碎苔藓0.5。温热态涂于刃柄结合面，趁热装配绑扎，冷却固化。

**植物胶**：金合欢、桃李类树干渗出的干胶块，水溶成浆——强度低，用于颜料黏结与轻件粘接；根茎淀粉热水糊化成浆糊——纸前时代的轻粘接。

**皮胶（明胶前体，石煮法绕开容器瓶颈）**：

- 原料：兽皮边角碎块、筋膜碎。
- 工艺：兽皮袋盛水投料，投入烧烫的拳大卵石（石煮法），换石保温于60—80°C（手感"烫但不能久触"级）维持4—8小时（经验值，需现场标定），液体浓缩至挂勺，冷却成冻状即成。
- 局限：现制现用，湿热天易腐；干凝胶块可存、复水再用（经验法，登记验证）。规模化待第11章陶器（可直接熬煮）。

**粘结强度测试（粗定量）**：标准搭接试件——两块刨平木片搭接3×3cm，胶固化24小时后：先手掰（三档力：轻掰开/大力掰开/掰不开），再悬重分级加载至脱开，记录脱开载荷与破坏面（胶层开=胶弱；木材撕裂=胶强于木）。每配方n≥3。

**保存**：焦油团裹叶存阴凉处；树胶块干燥存放；碱液与胶分区。

【卡 08-03 桦皮焦油与装柄胶】（八字段）

1. **输入材料**：桦树皮内层（外硬皮刮去，只取内层）；细炭粉（第 6 章炭床筛出）；干草纤维或碎苔藓（切到 5 mm 以下）；土（封坑用）。**树皮要现剥现卷**，晾干的内层变脆、卷不紧，产率显著下降。
2. **所需工具**：石片刀（刮外皮）、土坑（或旧陶罐，第 11 章后）、接油容器（桦皮卷或阔叶）。校准来源：无温度计，靠"筒壁渗油的颜色与稠度"判火候；热解时长按筒径与天气现场标定。
3. **操作顺序与控制点**：树皮卷紧成直径 5–8 cm 实心筒 → 土坑内竖埋、筒周填土压实 → 顶部留一小孔 → 坑周堆炭火 → 闷热解 1–2 小时 → 撤火冷却 → 刮取筒内壁与筒芯的黑亮焦油。控制点：**填土必须压实**（漏气就烧成灰）、**顶部小孔不可省**（排气口，堵死会炸筒）。
4. **经验参数与标定法**：筒径 5–8 cm；闷热解 1–2 小时（经验值，须现场标定）；**判据三条**——温热时可拉丝、冷后仍微粘可塑为合格；脆硬不粘＝过烧；稀淌＝欠烧。**装柄胶配方（体积份）**：焦油 2 ＋ 细炭粉 1 ＋ 干草纤维 0.5，温热态涂于刃柄结合面，趁热装配绑扎、冷却固化。
5. **过程观察记录项**：每筒记 树皮用量 / 筒径 / 热解时长 / 产出克数 / 稠度判档（拉丝／脆硬／稀淌）/ 天气。
6. **合格／返工／报废判据**：合格＝可拉丝且冷后微粘可塑；返工＝欠烧稀淌，回坑续热解（每次 20 分钟量级，边热边看）；报废＝过烧脆硬无粘性（只能当炭粉用，不算废料）。
7. **常见失败与排查顺序**：①产出极少 → 先查树皮卷是否紧实，再查封土是否漏气；②焦油发脆 → 火太旺或时间太长（过烧）；③焦油稀淌不成胶 → 热解不足，续热；④胶接后开裂 → 配比中炭粉或纤维过多，或涂胶时未趁热装配；⑤**引燃** → 焦油近火可燃，熬制区须清出明火半径，这条与 6.8 的防火纪律同源。
8. **L1／L2／L3 证据**：L1＝一筒合格焦油＋稠度记录；L2＝连续 5 筒，产出与稠度可对照，且至少做出一件用装柄胶固定的工具并通过受力测试；L3＝第二人照本卡独立产出同档焦油，两人产出率差在 50% 以内（差距过大说明手法或树皮来源不同）。

### 8.6 如何进行小规模材料试验

**试验五原则**：

1. 单变量：一次只改一个因素（配比、含水量、干燥方式、烧温）。
2. 对照：每组必有基准组（不改变量者）。
3. 重复：每组n≥3，取中位结果。
4. 标准试件：统一尺寸——泥棒12×2×2cm、泥球4cm、胶搭接3×3cm、绳样50cm。
5. 全记录：失败样同样保留与记录，失败数据与成功数据同价。

**标准试件库**：制好的试件刻痕编号（弓钻尖或石片刻号）＋颜料点色标（8.4），置于离地木架干燥存放；每月复检一次（吸潮变形、开裂、霉斑）。

**记录表模板（木牍）**：

| 字段 | 例 |
|---|---|
| 编号/日期 | T-011 / 重启第3年雨季前 |
| 目的 | 比较东坡黏土掺砂20%的干裂率 |
| 原料 | 东坡黏土批2、河砂筛0.5—1mm |
| 配比 | 泥4:砂1（体积斗量） |
| 工序参数 | 练泥12分钟；阴干48小时 |
| 环境 | 阴，湿度手感"潮" |
| 结果 | 3件中1件细纹，干缩7%（10cm线→9.3cm） |
| 结论 | 细纹可接受，进入焙烧试 |
| 下一步 | 同配比做火烤试片 |

**完整示例——"当地最佳制陶配比"预研设计**：3个黏土源×3个掺砂比（0/10/20%）＝9组×3件＝27件，统一干燥与烤试（炭床上15分钟），评级（无裂/细纹/裂/碎）。此设计产出第11章的起点配方。

### 8.7 如何记录配方和工艺参数

**记录载体（无纸阶段）**：

| 载体 | 制法 | 用途 |
|---|---|---|
| 木牍 | 刨平软木板＋炭笔（烧尖炭条） | 日常试验记录，可刮写复用 |
| 桦皮 | 大张剥取压平，炭笔书写 | 抄送副本、携带 |
| 刻痕石/木 | 石片刻符 | 永久关键数据（基准、配方编号） |
| 绳结＋颜料标记 | — | 辅助记忆，不作主档 |

存放：干燥离地、防鼠；**双份异地存放**（一场火不毁全部档案）。

**计量统一（铁律：禁用"适量"）**：

- 一切配比用体积标准器：自制木斗（第3章基准校验）、蚌壳（标定容量后专用）、标准捧（以第3章长度单位为准）。
- 含水量以"手感阶梯＋泥条判据"描述（8.2），不用"加水若干"。
- 温度以火位＋标准试样状态描述（6.7），不用"烧一会儿"。

**记录字段规范**：日期、目的、原料（来源＋批号）、配比、工序、环境、结果、结论、下一步——缺项即废档。

**版本管理（第4章规则落地）**：配方修改必须新编号（T-011→T-011b），不覆盖旧版；失败配方保留并注明失败原因。

**传承检验**：新手按记录独立复现一次，尺寸级偏差>15%即视为记录有缺项，回查工艺漏洞后补记。档案的最终验收不是"写全了"，而是"别人照做能成"。

## 安全边界

- 碱液操作戴干叶手套垫、防溅入眼；容器一律红条标记，绝不与食器混用。
- 黄铁矿与硫的矿区样品不在火边处理（燃烧产生刺激气体）。
- 焦油坑闷烧时人不得俯身对着出气孔；撤火冷却前不开坑。
- 石煮袋换石用木夹或垫皮，湿手不抓热石。
- 试件库远离火源与鼠道；霉变样品废弃并记录。

## 验收标准

- **L1 原理验证**：完成三试合格的黏土试棒；一次成功的桦皮焦油制取并粘牢一件搭接木片。
- **L2 可重复制造**：2处以上黏土矿点完成三试并建档；焦油连续3次成功且粘结强度测试数据在册（木材撕裂级≥1例）；灰液浸出可复现；"最佳配比"9组预研试验完成且结论明确。
- **L3 可持续生产**：焦油原料（桦树）登记并按切口限额采集；胶、颜料、碱液有月产与损耗账；记录制度被第二人复现验证≥1项；试件库月检执行中。
