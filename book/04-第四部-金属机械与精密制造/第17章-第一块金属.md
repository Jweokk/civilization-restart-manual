# 第17章 第一块金属

> 第四部·金属、机械与精密制造。本章从第16章的精矿出发，取得第一批金属：自然铜冷锻 → 孔雀石碳还原 → 熔融铸造 → 锻造与退火 → 铜工具体系 → 合金方向。铁在此章只预告（第18章）。铜是主线，但不是所有环境的必经阶段——替代路线在17.1与17.8写明。

## 能力边界

**能做到：** 坩埚还原出铜并铸造（母工艺，第18章直接继承）；冷锻—退火循环；青铜/砷铜/铅铜三合金方向。铜料完整回收循环（第一种可无限重熔的材料）。

**明确做不到：** 合金成分定量（第 23、26 章）；铁钳铁砧铁锤（第18章自举前的过渡工装）；铸锭一致性支撑的互换性（第22章前一律单件配作）；硬岩重负荷工具（铜的强度上限——17.7 局限表）。

**外部依赖：** 木炭 ≥50 kg 储备、品位 ≥20% 氧化矿（16.7 经济性判据）。

### 17.1 为什么某些金属比另一些更容易获得

**三个物理化学事实决定顺序：**

1. **氧化物稳定性**。金属越不活泼，其氧化物越容易被碳夺走氧。氧化铜约700—800°C即开始被CO还原，氧化铁要到更高温度且反应慢得多，锡石则既难还原又难熔成液态（需熔剂）。
2. **熔点**。铜1083°C——第12章强风箱高温炉可达；铁1538°C——本阶段炉子远不能熔化铁，因此炼铁走固态还原路线（第18章），炼铜走液态路线。
3. **自然金属存在**。铜、金、铂可以以单质形态存在于地表（地质原因：不活泼）。自然铜可直接冷锻成器，**跳过冶炼全流程**——这是"第一块金属"最便宜的入口。

**环境路线决策表（按本地资源对号入座）：**

| 本地条件 | 推荐路线 | 本章对应小节 | 边界 |
|---|---|---|---|
| 有自然铜 | 先冷锻自然铜，同时练坩埚还原 | 17.2＋17.3 | 自然铜多为零星块，难成产能，只作入口 |
| 有氧化铜矿 | 坩埚还原主线 | 17.3—17.7 | 品位≥20%才有经济性（16.7） |
| 有硫化铜矿 | 焙烧→还原 | 17.3 | 烟气SO₂，安全边界从严 |
| 只有铁矿 | 直接走第18章，本章只读不练 | 17.1 | 代价：无铸造成形阶段，全靠锻打 |
| 有铜有锡 | 冶铜＋炼锡→青铜 | 17.8 | 锡需淘洗精矿＋更高炉温 |
| 什么矿都没有 | 石器体系延续，金属靠交换 | 16.7 | 如实登记，不硬上 |

### 17.2 自然铜与早期金属加工

**自然铜识别（三判据全过）：**

1. 铜红色或褐红（氧化后表面绿锈——绿锈恰是指示，刮开见铜色金属）。
2. **延展性**：锤击变扁不开裂——与一切脆性矿物相反；这是金属独有判据，比颜色可靠。
3. 密度8.9：同块大小为石英3.4倍坠手；条痕板划出**亮铜色金属条痕**（矿物条痕是粉末色，金属条痕是光泽本身）。

**冷锻试验（正式开工前的小样验证）**：取拇指大一块，石砧上以石锤轻锤。变扁、边缘起裂纹即止——自然铜纯度越高裂纹越晚。记录"起裂前的减薄量"，作为该矿点铜料的质量初判。

**冷锻—退火循环（本章第一工艺）**：

原理：锤打使金属内部结构畸变，越来越硬、越来越脆（加工硬化）；加热到足够温度后结构重组、恢复柔软（退火＝再结晶）。铜冷锻到硬化后必须退火，否则开裂。

操作规程：

1. 冷锻：室温下轻锤匀击，从中心向外推进，单轮减薄≤20%（经验值，需现场标定）。
2. 硬化判据（何时停锤退火）：锤击回弹声变清脆尖高；边缘出现细裂纹征兆（对光可见发丝纹）；锤面开始打滑。三者任一出现即停。
3. 退火：把工件埋入炭火红热区（或炉口高温区）加热至**表面氧化色由紫转蓝再转灰、初现暗红**（约450—600°C，经验值，需现场标定；暗红初现约600°C，火色判温只作辅助分级，第6章规则）。
4. 冷却：铜退火**不怕快冷**——直接投入水中完全可行，且便于拿取。这点与第19章钢的淬火完全不同，切勿混淆：铜入水是退火软化，钢入水是淬火硬化。
5. 循环：退火后继续冷锻。每循环记一次减薄量与起裂情况，建立本批铜料的锻性档案。

**第一件制品**：选铜片——自然铜块冷锻成1—2mm薄板（3—5轮循环），剪裁（锤击＋反复弯折断料）成小刀、锥、鱼钩毛坯，第9章磨台开刃。功能定位：切割软材料、钻孔、刮削——立即替代骨锥与部分石片刀。

【卡 17-01 自然铜冷锻—退火循环】（八字段）

1. **输入材料**：自然铜块（三判据全过：铜红或褐红、表面绿锈但刮开见铜色；**锤击变扁不开裂**——这是金属独有的判据，比颜色可靠；同体积坠手约石英的 2.6 倍、条痕板划出亮铜色金属条痕）。三判据缺一，就不是自然铜，别往下做。
2. **所需工具**：石砧、石锤（第 5 章）、炭火（第 6 章）、水盆（冷却用）。校准来源：减薄量用刻线尺量厚度；退火温度无温度计，靠氧化色。
3. **操作顺序与控制点**：小样验证（拇指大一块轻锤，变扁、边缘起裂即止）→ 冷锻（室温轻锤匀击，从中心向外推进）→ 判硬化 → 退火 → 冷却 → 继续冷锻，循环。控制点：**单轮减薄 ≤20%**；**硬化三征兆任一出现就停锤退火**——锤击回弹声变清脆尖高、边缘出现对光可见的发丝纹、锤面开始打滑。
4. **经验参数与标定法**：单轮减薄 ≤20%（经验值，须按本批铜料标定）；退火判据＝表面氧化色由紫转蓝再转灰、初现暗红（约 450–600 ℃）；薄板目标 1–2 mm，需 3–5 轮循环。**铜退火不怕快冷**，直接入水可行——这点与第 19 章钢的淬火完全相反，切勿混淆。
5. **过程观察记录项**：每循环记 减薄量 / 是否起裂 / 退火时的氧化色 / 入水后的软硬手感 / 累计循环数。逐批建立"本批铜料的锻性档案"。
6. **合格／返工／报废判据**：合格＝达到目标厚度且无贯穿裂；返工＝边缘起细裂，提前退火后继续；报废＝贯穿裂（改做小件，料不废）。
7. **常见失败与排查顺序**：①一锤就碎 → 不是自然铜（脆性矿物），回 17.2 三判据复核；②越锤越硬、锤面打滑 → 已到极限，该退火了，不是料坏了；③退火后仍脆 → 温度不够（氧化色没到灰）或保温太短；④反复在同一位置开裂 → 锤击落点没移动，改从中心向外匀推。
8. **L1／L2／L3 证据**：L1＝一片 1–2 mm 薄板＋循环记录；L2＝三批不同来源铜料，锻性档案可对照；L3＝第二人照本卡独立锻出同厚度薄板，两人循环次数差 ≤1 轮。

### 17.3 铜矿的处理与冶炼

**矿石预处理（接第16章流程）**：

1. 氧化矿（孔雀石、赤铜矿）：破碎至5—15mm，手选富集，直接入炉——**不需焙烧**。
2. 硫化矿（黄铜矿等）：先焙烧脱硫（16.5规程），焙烧1—2遍，矿色转暗多孔；硫酸盐化的绿色粉末洗净。
3. 碳酸盐矿里的蓝铜矿：入炉前在炉口高温区预烘1小时以上分解（经验值），不与还原区直接接触。

**还原化学（一段话说清）**：木炭燃烧生成CO，CO夺走氧化铜中的氧：CuO＋CO→Cu＋CO₂；孔雀石受热先分解为CuO＋CO₂＋H₂O，随后同样被还原。总效果：绿色石头＋黑炭＋高温→红色金属。无需理解更深即可操作，但必须记住两点：①需要**过量木炭**维持还原气氛；②温度越高反应越快，1083°C以上产品为液态铜，便于铸成一块。

**坩埚炉操作规程（母工艺，逐条执行）**：

1. **配料**（体积比，经验值，需现场标定）：碎矿2份＋木炭粒（5—15mm，勿用粉末）1份，交替分层装入坩埚。矿石与炭不混装、分层装——还原界面稳定。加入炉料总重1%—3%的砂（石英砂）作熔剂造渣（经验值）。
2. **坩埚**：第11章陶坩埚，容量1—2L起步。装料至八分满（受热后矿粉塌落、铜液汇底，过满会溢）。坩埚使用前检查裂纹——敲声哑者禁用（受热炸裂会泼铜）。
3. **入炉**：高温炉（第12章）预热至亮红（约900°C，火色辅助判据），坩埚置炉膛中心，四周炭围满至坩埚口。
4. **升温鼓风**：风箱（第12章）连续送风，约15—30分钟炉膛达亮橙（约1000—1100°C，经验值，需现场标定；以第12章标准试样法复核——铜屑试样熔化即达1100°C级）。
5. **保温还原**：持续鼓风与补炭，维持亮橙约30—60分钟（经验值，需现场标定）。中途用干木棍（耐火端）轻搅一次，让矿粒换位接触炭。
6. **判完成**：炉口冒出的火焰呈橙黄色CO焰、坩埚内平静无沸腾声；木棍探入搅动时阻力小、无硬块感——矿已还原完毕。
7. **出炉**：停风后立即进行（见17.4浇注，或直接浇成铜锭）。铜液在坩埚内停留过久会再氧化。
8. **清坩埚**：冷后倾出余渣，检查坩埚内壁侵蚀。侵蚀深度达壁厚1/3的坩埚报废。

**首炉验收**：1kg孔雀石精矿应得铜350—500g（理论58%，实收60%—85%，经验值，需现场标定）。铜锭断面致密、玫瑰红色、可锤扁不裂为合格。断口有大量黑点孔洞＝渣未分离或温度不足，回炉重炼。

**失败排查表**：

| 现象 | 原因 | 处置 |
|---|---|---|
| 出炉是烧结矿团而非铜 | 温度不足／炭不够 | 增加风量与炭比，延长保温 |
| 铜珠分散嵌在渣里 | 渣太黏（缺熔剂） | 增砂至3%，提高出炉温度 |
| 铜锭多孔发黑 | 还原不足／出炉后二次氧化 | 延长保温；出炉前木棍搅动汇聚铜液；立即浇注 |
| 坩埚开裂漏炉 | 坩埚劣质／升温过猛 | 换坩埚；升温分段（先预热15分钟） |

【卡 17-02 坩埚还原一炉】（八字段）

1. **输入材料**：碎铜矿（孔雀石、蓝铜矿，先按 17.1 判过）；木炭粒；石英砂熔剂，占炉料总重 1%–3%。矿要碎到豆粒大小，粉太细会堵风道。
2. **所需工具**：坩埚（装料**八分满**，留塌落余量）、风箱（第 12 章）、炉（第 12 章竖炉）、夹钳、记录板。校准来源：温度判据不用温度计——**投一小块铜屑作试样，试样熔了就是达标**。
3. **操作顺序与控制点**：矿与炭分层装（碎矿 2 : 木炭粒 1，体积比）→ 升温 → 保温还原 → 中途搅拌一次 → 出炉倒锭。控制点：**装料八分满**（满装沸腾溢出）、**温度以铜屑试样熔为准**（亮橙 1000–1100 ℃ 只是辅助观察）。
4. **经验参数与标定法**：矿炭比 2:1（体积，分层装）；熔剂 1%–3%（炉料总重）；升温目标亮橙 1000–1100 ℃；保温还原 30–60 min，中途搅一次；首炉实收率 60%–85%（1 kg 精矿得铜 350–500 g）。
5. **过程观察记录项**：每炉记 矿种与品位判断 / 矿炭比 / 熔剂量 / 温度观察（铜屑试样是否熔）/ 保温时长 / 产出克数 / 渣的颜色与量。
6. **合格／返工／报废判据**：合格＝产出铜珠或铜饼、实收率 ≥60%；返工＝未熔或半熔，延长保温或补炭后重来；报废＝渣量过大且铜粒分散在渣中（矿种或熔剂判断错，换料）。
7. **常见失败与排查顺序**：①不熔 → 先查温度（铜屑试样熔没熔），再查炭量；②铜粒散在渣里收不回来 → 熔剂不足或中途没搅拌；③收率低 → 矿品位低（回 17.1 复核）或还原不充分；④坩埚开裂漏液 → 预热不够或装料过满。
8. **L1／L2／L3 证据**：L1＝一炉出铜＋实收率记录；L2＝三炉不同矿源，实收率与渣况可对照；L3＝第二人照本卡独立炼出一炉，两人实收率差 ≤10 个百分点。

### 17.4 熔融金属与简单铸造

**本阶段没有铁钳。**夹持坩埚的方案（按优先序）：

- 方案A·抬杠坩埚：坩埚烧制时预留两耳或腰槽，两根长硬木杠穿抬，二人抬行浇注。木杠绑扎点缠湿黏土条隔热（湿泥受热失水会开裂，备泥桶随时补糊）。
- 方案B·陶勺舀浇：小件用第11章陶勺舀铜液浇入模——勺柄接长木柄，柄长≥80cm，操作者距浇口一个臂展。
浇注区及抬杠路线**半径 ≥3 m 内不得有水洼、湿土、冰雪**（无法满足先铺干沙并清场）。

**铸模两型**：

| 模型 | 材料 | 适用 | 制作 |
|---|---|---|---|
| 敞开石模 | 滑石质软岩、细砂岩（刻得动的致密岩） | 铜锭、条料、简单板件 | 石片刀＋石英砂刻槽，槽深为件厚1.2倍（留打磨量），槽口外扩成浇口喇叭 |
| 组合陶范 | 耐火黏土（第11章配方） | 有形状要求的件（斧、凿毛坯） | 实物（木模或原有铜件）压入两块泥坯取型，阴干、窑烧硬化，合范绑扎（第7章绳），预留浇口与**排气细槽**（截面为麦秆细，2—4条） |

**浇注规程**：

1. 模具预热：铸模入炉口旁烘至100—200°C（手感烫、水滴即沸）。**冷模湿模遇铜液会瞬间汽化爆溅**——预热是防爆第一关。
2. 撇渣：浇注前沿浇口用预热木片刮去铜液表面浮渣。
3. 浇注姿态：坩埚口贴近浇口（落差≤10cm），细流连续、不断流、不满溢。断流再续必成冷隔。
4. 凝固：静置冷却。薄件15分钟、厚件1小时以上方可脱模（经验值，需现场标定）。**严禁向热铸件泼水催冷**——铜件激冷开裂＋蒸汽烫伤。
5. 落砂清理：脱模后锤击浇口毛刺，磨台去飞边。

【卡 17-03 浇注规程】（八字段）

1. **输入材料**：熔好的铜液；陶范（17.5 制，**必须先预热**）；挡渣用具。
2. **所需工具**：坩埚夹钳（长柄，隔热）、浇口杯、预热用炭火。校准来源：模具温度用水滴判断——**水滴落上即沸（100–200 ℃）**，不沸则不够热。
3. **操作顺序与控制点**：模具预热 → 铜液出炉撇渣 → 细流连续浇注 → 静置冷却 → 脱模检查。控制点两个：**落差 ≤10 cm**（落差大＝冲击卷气＋飞溅）、**细流连续**（断流＝冷隔）。
4. **经验参数与标定法**：模具预热 100–200 ℃（水滴即沸）；浇注落差 ≤10 cm；重熔损耗每次 2%–5%（算料时要加进去，不然越做越小）。
5. **过程观察记录项**：每件记 预热判断（水滴反应）/ 落差实测 / 浇注是否断流 / 缺陷类型与位置（冷隔、气孔、夹渣、缩孔）。
6. **合格／返工／报废判据**：合格＝轮廓完整、无冷隔、无大面积气孔；返工＝缺肉或局部冷隔，补浇或重熔；报废＝大面积气孔或夹渣贯穿受力部位。
7. **常见失败与排查顺序**：①冷隔（两股金属没熔合）→ 先查模温，再查落差与浇注速度；②气孔密布 → 模具有湿气（预热不透）或铜液未除气；③夹渣 → 浇口杯没挡渣；④缩孔集中在厚处 → 冒口不足（转卡 17-06）。
8. **L1／L2／L3 证据**：L1＝一件合格铸件＋缺陷记录；L2＝连续 5 件，缺陷率与工艺参数可对照；L3＝第二人照本卡独立浇出合格件，两人对"水滴即沸"的判断一致。

### 17.5 模具、浇注和缺陷检查

**四大缺陷排查表（按出现频率排序）**：

| 缺陷 | 外观 | 原因 | 对策 |
|---|---|---|---|
| 气孔 | 表面或断面成群小孔，内壁光滑圆亮 | 模湿／排气槽堵／浇注卷气 | 模具彻底烘干；排气槽加粗加多；降低浇注落差 |
| 缩孔 | 厚大部位中心空洞，内壁粗糙树枝状 | 局部厚处最后凝固、补缩断流 | 浇口设在最厚处上方；厚薄过渡区厚薄比≤2:1；浇注后浇口杯多留铜液补缩 |
| 冷隔 | 表面流痕、对接缝，两层皮 | 铜液温度低／浇注断续 | 提高出炉温度（铜液亮橙泛白）；一次连续浇足 |
| 夹渣 | 断面黑灰色斑块、易剥落 | 撇渣不净／浇口冲渣入腔 | 浇口杯加深；浇注前再撇一次 |

**检查规程（每炉抽样）**：

1. 全数目检：表面气孔、冷隔直接判。
2. 敲击声检（**辅助手段**，局限如第6章火色——受件厚与形状影响，不作唯一依据）：清脆长音＝致密；哑声短促＝内部孔洞或裂纹。哑声件单独放置。
3. 破坏抽检：每炉取1件于台钳（绳勒夹）夹持，凿断，看断面：致密玫瑰色＋细晶＝优；孔洞、渣斑、粗亮大晶（过热）记录等级。
4. 全部结果入炉号档案：炉号、配料、风时、缺陷、抽检断面评级。这个档案是调参数的唯一依据（第3章制度）。

### 17.6 锻造、退火与加工硬化

**热锻（铜的正式成形法）**：铜在400—700°C间塑性最好。把铜件埋入炭火红热区加热至**暗红可见**（约600—700°C，经验值，需现场标定；火色辅助判据），取出至砧上快速锤打——热锻硬化慢，可连续变形而无需频繁退火。火色褪至暗不可见（约450°C以下）即回炉复热，**低温硬打是开裂主因**。

锻打手法四则：

1. 轻快连击优于重击慢打（重击把渣与气孔震裂）。
2. 顺序推进：从一端向另一端，从中心向边缘（展宽时）。
3. 勤翻转：两面交替，防单面过薄卷边。
4. 随时对样板（第9章样板法）：锻一件对一次，透光缝<1mm。

**退火在锻件上的应用**：复杂件冷修（弯折、修直、卷边）时，硬化即退火（17.2规程同用）。

**加工硬化的工程用途**：冷锻终了不再退火的铜件保持冷作硬度——铜凿、铜刀刃部的唯一强化手段。终锻规程：退火后最后冷锻两轮（减薄共≤30%），立即磨刃交付。冷作硬化铜的刃口保持性显著优于退火铜，但仍不及石器耐久、远不及铁（17.7）。

**铜工具制作规范**：

| 工具 | 工艺路线 | 规格 |
|---|---|---|
| 铜凿 | 铸条→热锻方杆→冷锻端部→磨刃 | 断面12×12mm，刃角40°—50° |
| 铜斧 | 陶范铸坯→热锻整形→冷锻刃部→磨刃 | 刃宽60—90mm，装柄走9.1四重连接 |
| 铜锥、锥刀 | 铜条冷锻＋退火循环→磨尖 | 全长80—120mm |
| 铜锤 | 陶范实心铸造→装柄 | 头重500—800g（天平配重） |

【卡 17-04 热锻四则】（八字段）

1. **输入材料**：铸坯或铜条（17.3 产出）；炭火。坯料表面的氧化皮要先敲掉，否则会被锻进金属里。
2. **所需工具**：锤（重量按件定）、砧、样板（第 9 章样板法）、夹钳。校准来源：温度靠颜色（暗红可见起、450 ℃ 止）；尺寸靠样板对缝，**透光缝 <1 mm**。
3. **操作顺序与控制点（四则）**：①**轻快连击优于重击慢打**（重击把渣与气孔震裂）；②**顺序推进**：从一端向另一端、从中心向边缘；③**勤翻转**：两面交替，防单面过薄卷边；④**随时对样板**：锻一件对一次。控制点：温度窗口与样板对缝两项都不许省。
4. **经验参数与标定法**：热锻窗口＝暗红可见（600–700 ℃）起，到 450 ℃ 止（低于此温度继续打就裂）；样板透光缝 <1 mm；**终锻冷作量**——最后两轮冷锻合计 ≤30%，超过就裂。冷锻终了不再退火的件保持冷作硬度，这是铜凿、铜刀刃部唯一的强化手段。
5. **过程观察记录项**：每件记 加热次数 / 每次出炉的颜色 / 样板对缝读数 / 是否出现叠裂 / 终锻冷作轮次。
6. **合格／返工／报废判据**：合格＝尺寸合样板、无叠裂、刃部有冷作硬度；返工＝温度低导致浅裂，磨掉后回炉重锻；报废＝过烧（表面起泡、晶粒粗大、一打就碎）。
7. **常见失败与排查顺序**：①锻打开裂 → 温度低于 450 ℃ 还在打；②表面起皮起泡 → 过烧，火太旺或加热太久；③尺寸越锻越超差 → 没对样板，凭眼看；④刃口卷边 → 单面锻打太久，没翻转。
8. **L1／L2／L3 证据**：L1＝一件合样板的锻件＋记录；L2＝铜凿、铜斧、铜锥三类各一件，尺寸与硬度均达标；L3＝第二人照本卡独立锻出合样板件，两人对同一样板的透光缝判读一致。

### 17.7 金属工具的维修和再利用

**铜的第一特性：报废≠终点。**铜可无限次重熔（每次重熔氧化损耗约2%—5%，经验值），旧件、浇口毛刺、飞边、屑末全部回收入坩埚。建立**铜料账**：入库（新炼/回收）、出库（制件）、在制、损耗四栏，月结。这是第一种建立完整物料循环的材料——制度从此章开始，第18–19章沿用。

**维修分级表**：

| 损伤 | 处置 | 工序来源 |
|---|---|---|
| 刃钝 | 磨台重磨，角度不变 | 第9章 |
| 刃卷 | 冷锻轻敲复原＋重磨 | 17.6 |
| 弯曲变形 | 退火后矫直 | 17.2/17.6 |
| 小裂纹（<1/3断面） | 退火→锻合（加热至暗红锤击闭合）→修磨；不再用于冲击工具 | 17.6 |
| 大裂纹/崩块 | 回炉重熔重铸 | 17.3—17.4 |
| 装柄松 | 重走四重连接 | 9.1 |

**铜工具局限表（写给使用者，防止错误使用）**：

| 任务 | 铜工具 | 原因 |
|---|---|---|
| 木工细作、刮削、软木切削 | 可用，优于石器 | 保持性好、可修磨 |
| 凿软岩（灰岩、页岩）、刻石 | 可用（低速） | 冷作硬化刃部够用 |
| 凿硬岩（花岗、石英岩）、砍硬木 | **禁用** | 刃卷裂，寿命低于石器 |
| 冲击工具（当凿锤打） | **禁用** | 铜韧但强度上限低 |
| 高温工具（拨火、夹炭） | 可用 | 熔点1083°C，炉口环境安全 |

**结论：铜替代的是"精细加工"环节，不是"重负荷"环节。**重负荷在铁出现前仍由石器承担（第5章体系保持备用，9.6工具箱制度不变）。

### 17.8 从软金属工具到更强韧的合金

**纯铜的天花板**：冷作硬化也只到软钢的几分之一硬度（相对手感与磨耗判据；定量硬度对照待第19章手段）。突破天花板有两条合金路线：

**路线一·锡青铜（正路）**：

- 配比：铜88—92份＋锡8—12份（质量比，用天平配，第3章）。经验最优窗口约90:10，需现场标定（试铸3炉：88:12、90:10、92:8，硬度与韧性对比入档）。
- 操作：铜先熔化（坩埚亮橙），锡块分批压入铜液搅匀——锡熔点232°C，最后加入避免氧化蒸发损耗。
- 效果：铸态硬度约为纯铜铸态2—3倍（经验值，划痕与磨耗对比可感）；热锻性能良好；**浇注收缩小、充型好，铸造性优于纯铜**——青铜是铸造的最佳选择。
- 边界：锡石资源分布极不均（16.1）。缺锡地区的硬刃具不能指望青铜，直走第18–19章铁钢路线。

**路线二·砷铜（替代路，剧毒）**：

- 原理：毒砂或砷铜矿与铜矿同炉还原，砷溶入铜，3%—7%砷即显著硬化（经验值）。
- 边界与代价（必须全文宣读执行）：砷化合物剧毒且累积性——**本阶段直接禁止含砷矿焙烧与砷铜冶炼**（70–100 步下风向对砷氧化物远不足，且无密闭窑、尾气净化与呼吸防护）。砷铜列入解锁条件：专址 ≥500 m＋密闭窑＋碱液洗涤＋呼吸防护＋尿砷监测，四条件齐前砷铜线冻结，青铜缺位期直走铁钢路线（18–19 章）

**路线三·铅铜（功能合金）**：加铅5%—10%改善铸造充型与耐磨，用于未来的滑动件（第20–21章轴承预研）。铅不提高硬度。铅蒸气与粉尘有毒，操作同砷防护级。

**方向结论**：本章结束时，你拥有"可熔、可铸、可锻、可回收、可合金化"的金属工艺全套母法。第18章把同一套炉—风—炭—坩埚—锻体系推到更高温度，目标换成一个分布更广、性能上限高得多的金属：铁。

【卡 17-05 青铜配比梯度试验】（八字段）

1. **输入材料**：纯铜（17.2 或 17.3 产出）、锡（来源按 17.1 登记）。**砷铜另计**——砷量 3%–7% 属剧毒红线，见 17.8，必须有通风与防护才做。
2. **所需工具**：坩埚、天平（第 3 章，称铜与锡）、铸样模（同尺寸小条若干）、弯折试验台（固定钳＋角度参照）。校准来源：配比靠天平称重，不靠目测；性能靠弯折角与痕宽判，不靠敲打听声。
3. **操作顺序与控制点**：按三种配比各熔一炉（8%、10%、12% 锡）→ 同模浇成等尺寸试样 → 逐条弯折 30°–90° → 量弯折处痕宽 → 定优。控制点：**三炉必须同条件**（同模、同温、同冷却），否则比不出来。
4. **经验参数与标定法**：配比区间 铜 88–92 : 锡 8–12（体积或重量按天平统一口径，三炉梯度定优）；**Q 分级**——Q3＝弯折 30°–90° 且痕宽 0.2–0.5 mm，是工具用青铜的目标档；过硬（弯折即断）减锡，过软（弯而不硬）加锡。砷铜砷量 3%–7%，剧毒红线。
5. **过程观察记录项**：每炉记 铜锡称重 / 熔炼温度 / 浇注温度 / 试样弯折角 / 痕宽实测 / 断口形貌。
6. **合格／返工／报废判据**：合格＝试样达到 Q3 档；返工＝偏离 Q3，按梯度方向重配一炉；报废＝试样脆断（锡过高）或软塌（锡过低），整炉回炉重配。
7. **常见失败与排查顺序**：①一弯就断 → 锡偏高，往低配比方向再试；②弯而不断但软 → 锡偏低；③同一配比两炉结果差别大 → 熔炼温度或冷却条件不一致，不是配比问题；④**砷铜试验后不适** → 立即停止、通风、就医，砷化氢是这条工艺最危险的东西。
8. **L1／L2／L3 证据**：L1＝三炉梯度试样＋Q 分级记录；L2＝定出本聚落的最优配比并复现一炉；L3＝第二人照本卡独立复现最优配比，两人试样痕宽差 ≤0.1 mm。

### 17.9 铸型工装细化：泥芯、冒口与浇注系统

17.4—17.5 解决"浇得进、判得出"；本节解决"浇得准"：带孔腔的件（斧銎、环、管套）需要泥芯，厚薄不匀的件（斧刃薄、斧肩厚）需要冒口，这两者又都要求浇注系统成体系。

**泥芯与芯盒（造空腔）**

- 芯砂：耐火黏土 3 份＋河砂 6 份＋碎炭末 1 份（体积比，经验值，需现场标定：手捏成团不粘手、掰开断面无干粉为合格；过黏产气、过砂掉角）。
- 芯盒：泥芯的"模具"。最简制法＝按空腔形状做实心母模，两块石板/木板（第 7、16 章工装）对合夹住母模，四周以芯砂夯实，开盒取出母模，即得对合芯盒。芯盒内腔刷水修光，阴干后与陶范同窑烘透（水滴即沸级，17.4 同判据）。
- 芯骨（防断芯）：细长泥芯在铜液浮力与冲击下会断。芯骨用烧透的硬木炭枝（强度够、浇后可掏出、不产气；生木条禁用——炭化产气成孔）。芯骨距芯表面 ≥3 mm，贴皮处浇后必成气孔。
- 芯头与芯撑（防漂移——本节头号沉默失败，壁厚不均浇完剖开才知道）：
  - 芯头：泥芯两端各做出凸台，插进范壁预留的芯座。芯头长 ≥ 泥芯悬空段长度的 1/3 且 ≥10 mm（经验值，需现场标定：验壁环剖量，对向壁厚差 >1.5 mm 即加长芯头重试）。
  - 芯撑：悬臂芯（单端芯头，如杯形件的芯）必须加芯撑——小铜钉或小铜片垫，浇注后被铜液焊死在件内。铜撑 Ø3—5 mm，每 30×30 mm 芯面布 1 个（经验值）。芯撑材质与铸件同合金、表面刮亮无锈——脏撑焊不牢，日后成为穿孔渗漏点。
- 验证（发现沉默失败的手段）：每副新芯先浇一件**验壁环**——只测壁厚的环形试件，剖开量四面壁厚，极差 ≤1.5 mm 方许浇正件；验壁环记录入炉号档案。

**冒口（补缩）三原则**

1. 设在最后凝固处：铜凝固收缩约 4%—6%（体积，经验值，需现场标定：同一石模先量模腔容积、后量铜锭体积，二者之差即收缩量）。厚处冷得慢、最后凝固，缩孔必然落在厚处——冒口要压在厚处正上方或紧贴，把缩孔引到冒口里去。
2. 冒口尺寸经验比：明冒口直径 ≥ 该处热节厚度的 1.2—1.5 倍，冒口高 ≥ 直径的 1.5 倍（经验值，需现场标定：剖检冒口根部——缩孔整体缩在冒口内上半段、根部致密为合格下限；根部见孔即加大一号重试）。冒口必须比它所补的厚处更迟凝固，比热节还小的冒口会先冻住，反成缩孔源。
3. 补浇：浇满后隔 20—40 s 向冒口补热铜液 1—2 次（经验值，标定法：盯冒口液面——表面刚起暗色结膜即补；膜厚发黑再补就迟了，补进去的是冷铜）。

**浇注系统三区（截面递减）**

| 区 | 功能 | 规格要点 |
|---|---|---|
| 浇口杯 | 承接铜液、撇渣、缓冲 | 口径 ≥ 直浇道 2 倍、深 ≥30 mm；可浮一片干木片挡初渣（必须干，湿木片产气） |
| 直浇道 | 垂直送液 | 锥形上粗下细，底端最小截面为基准 S；S 取 80—120 mm² 每公斤铜液（约 Ø10—12 mm，经验值，需现场标定：充不满或冷隔→加大；冲砂、飞边过厚→减小） |
| 内浇口 | 进入型腔 | 总截面 0.6—0.8 S；位置开在件最厚处（兼作补缩通道）；与型腔交接处倒圆 |

递减的用处：杯大渣浮在杯里；直浇道到内浇口截面递减，浇道始终被铜液充满下落，渣不回流、卷气少。三区截面开完后用样板（第 9 章）逐一核对——浇口开小了充不满，开大了冲砂带渣，没有"差不多"。

◎ 内浇口方位手感：厚薄交界件的内浇口开在厚侧、使铜液沿壁由厚向薄推进，充型平稳少涡。练习法：先以干砂盒试开 10 副，注水看冲坑与涡痕，10 副建立"方位—充型"直觉；误判代偿：正件浇注前先浇同壁厚试件一件，按 17.5 检查规程剖检涡痕与夹渣，试件合格再上正件。

### 17.10 铜合金谱系扩展

17.8 给出三条路线的配比；本节把合金研究改造成"试件可比、结果可累积"的制度（锡青铜），并划定三条**只登记、不解锁**的方向（黄铜、白铜、铅锡焊料）的边界。

**锡青铜 Q 值分级试件制（硬度/延性对照阶梯）**

动机：17.8 三炉梯度（88:12、90:10、92:8）靠手感比优劣，换人就换结论。把手感换成试件与等级。

- 标准试件：每炉随炉浇 3 根阶梯条，单根 80×15×4 mm（约 40 g，天平复核 ±2 g），同模同炉浇出，锭面刻炉号。
- 两项可观察测试：
  1. **弯折角（延性档）**：试条一端夹入绳勒夹（第 9 章），绕 Ø20 mm 圆杆匀速弯折，记首条可见裂纹出现时的弯角。>90°＝高延；30°—90°＝中；<30°＝脆。
  2. **定载划痕（硬度档）**：标准铜刃装于杠杆一端，杠杆另侧挂 500 g 砝码（第 3 章砝码），刃尖在试条上匀速拖 20 mm，以标准杆比对读痕宽。<0.2 mm＝细；0.2—0.5 mm＝中；>0.5 mm＝粗。
- Q 阶梯（本阶段相对标定；绝对硬度在定量手段出现前不承诺）：

| Q 档 | 弯折角 | 划痕宽 | 判读 |
|---|---|---|---|
| Q1 | >90° | 细 | 过软（近纯铜），只宜延展件 |
| Q2 | >90° | 中 | 软，器皿与装饰 |
| Q3 | 30°—90° | 中 | **工具目标档**（凿、斧、锥） |
| Q4 | 30°—90° | 细 | 硬韧，刃部优选 |
| Q5 | <30° | 不计 | 脆，仅限不受冲击件 |

- 测法制度：3 根同测取众数；出现 Q3 及以上的炉次，其配比誊入台账，登记为"本矿、本炭条件下的工作配比"；同炉 3 根波动跨 2 档以上者重测一遍（多为弯折速度不匀所致）。
- Q 阶梯自身的标定：取已验收纯铜锭（Q1 锚点）与已验收青铜凿（Q3 锚点）随每批试件同台同载复测；锚点越档即全套重测——测试手段本身也要被测试。

**黄铜（铜锌）——只登记，不解锁**

- 方向：炉甘石/菱锌矿（锌的碳酸盐矿）与铜同炉共热，锌以蒸气溶入铜面成黄铜（历史闷炼法路线）。
- 不解锁的硬理由：锌约 907 ℃ 沸腾，而还原锌矿所需的温度恰好高到令锌成蒸气逃逸——铜、锡、铅还原后留在坩埚里，锌还原后跑了，这是它与其他可熔金属的本质区别。坩埚加盖密封与锌蒸气冷凝两项手段皆无时，硬上＝矿石白费＋锌蒸气中毒，双重亏损。
- 登记动作：矿样编号留档（产地、外观、条痕），在矿点台账（第16章格式）记一行"闷炼黄铜：待密封炉与冷凝工装在案后试"。**禁试**，直至上述两项工装在档。

**白铜（铜镍）——登记产地**：个别铜矿伴镍，炼出的锭色白、硬而韧，与玫瑰红铜锭一眼可辨。遇之单独成炉、单独记账、锭面刻"W"标记，不并入铜料账（性能不同、用途不同）。镍矿常伴砷，全程按 17.8 砷级防护执行。

**铅锡焊料——登记＋小样试焊**

- 配比：锡 2 : 铅 1（质量比，经验值，需现场标定：焊料熔后涂铜片，冷后敲弯不起皮、断面亮为合格；脆则加锡，流淌不成珠则加铅）。熔程约 180—250 ℃（经验值）。
- 小样规程：铜件接面刮亮→烧热至暗处微红初现即停（约 500–550 ℃——暗处可见微红的物理下限即此档；锡 232 ℃ 暗处不显红，23 章镀锡同口径）→松香点剂→焊料条抵缝抹开，热铜把焊料吸进缝里为到位。
- 边界：铅毒按 17.8 路线防护级执行；焊料件**禁入食物线**（食物线用纯锡，见 17.12）；只登记用于铜件拼缝与补漏的低温钎焊方向。

### 17.11 铜板锻造与组织

17.6 管成形；本节管"成得好不好"——板越大越薄，方向性与均匀性问题越显形。

**锻打方向与纤维流线（冷锻十字换向）**

- 现象：单向反复锤打的铜板，内部晶粒沿打向拉长成"纤维流线"，板变得顺纹软、横纹裂——弯折沿纹开口，如同劈柴顺纹一劈就开。
- 十字换向规程：每锻完一轮，将板转 90° 再锻下一轮；展宽走横向、拔长走纵向，交替进行。同一方向连打 ≤2 轮（经验值，需现场标定：取单向锻 3 轮与十字锻 3 轮的试片各一，按 17.10 同法测弯折角——单向片弯角低 30° 以上即确认换向收益，记入锻性档案）。
- 目检判据：锻板对光斜看，单向过锻者表面见平行细痕带；换向合格者细痕交错不成组。

**退火均匀化（埋炭法）**

- 问题：板件架在火上烧，迎火面到温、背面还凉——同一块板上局部过热（晶粒粗大发绵）与局部欠退火（仍硬）并存，下锤必裂，且裂纹走向毫无规律。
- 埋炭规程：炉膛铺烧透红炭，厚度 ≥ 板厚 3 倍，板平埋其中，上覆炭 ≥ 板厚 2 倍，四面同温受热。保温按每 3 mm 板厚 5 min 起估（经验值，需现场标定：抽一件出炉入水，剖开于磨台磨光后冷锻边缘——中心起裂而表层已软即欠透，保温延长 30% 重标）。
- 出炉动作：绳勒夹整块夹出，**整板同一时刻入水**（17.2 铁律：铜入水是退火，快慢不影响软化，影响的只是均匀——分批出水必有一头先冷）。

**薄板矫平（木槌＋平板点压）**

- 原理：板翘＝一侧纤维比另一侧短。平锤面拍打只会把高点打薄、越拍越瓢；正确做法是**点压延展短侧**，把它拉长到与长侧一致。
- 规程：
  1. 细砂岩磨平大石板（第 9 章工装）置平，板放其上，逐一按压四角——翘动侧即短侧。
  2. 短侧朝上，硬木槌（槌头 300—500 g，第 7 章制）沿短侧密排轻点：点距 ≈ 槌头直径一半，力度以板面留下浅圆窝为度。
  3. 每打完一排按压复测一次；翘动消失即停。矫过头（反向瓢）比欠矫难修得多——宁可分三轮，不可一轮贪平。
  4. 精平：板夹两平板之间压重石 ≥10 kg 过夜。
- 合格判据：板自然平放石板上，四角逐一按压，塞标准杆检查翘量 ≤1 mm。
◎ 点压力度手感：见窝即收；窝深以指甲横刮不挂指为度（能挂住即已过 0.3 mm 级，重了）。练习法：废铜片 10 片，每片只打一排点，打完量板形与窝深，10 片建"力度—形变"对照；误判代偿：一律以标准杆塞检四角翘量 ≤1 mm 收手，手感只决定下一点打不打，不决定合不合格。

### 17.12 铜器表面处理

三件事按用途排序：着色（辨认与装饰）、抛光（精度与手感）、镀锡（食物安全线）。

**着色（登记性工艺，限两法）**

- 硫化着色（黑褐膜）：硫磺粉（硫化矿焙烧棚壁与窑壁的结霜物收集，第16章场地）与水调成糊，薄涂洁净铜面，温热处放 10—30 min，成深褐至黑的硫化铜膜；清水冲净、软布擦亮凸面，得"黑底亮纹"。色档由时间控制（经验值，需现场标定：同一铜片分三区各涂 5/15/30 min 比色定档，色样钉入台账）。
- 氧化着色（热色）：即 17.2 退火氧化色（紫→蓝→灰）的装饰用法。洁净件低温烘，暗处不见红为上限（火色辅助判据，第 6 章），到色即入水定色。每批先试片后上件。
- 边界：着色膜增摩擦阻、碍导热——刃口、摩擦面、镀锡面**禁着色**；着色只用于装饰件与标记件（批量编号件着色便于辨认，色样与时长入台账）。

**抛光（磨料三级＋皮轮）**

- 三级磨料（淘洗分级同第16章）：粗级石英砂（20—40 目级）去锻痕与氧化皮；中级河沙（40—80 目级）去粗痕；细级滑石粉或砖瓦细粉去中痕至映影。
- 递进铁则：**不跳级**。上一级磨痕未消净不换下一级——细磨料会填死粗痕，抛成"麻点镜"，返工要从粗级重来。每换一级，磨痕方向换 90°；痕向是否逐级变换，就是有没有跳级的自查线。
- 皮轮：皮条裹木轮（第 7 章木工），弓钻或轮架驱动（第 9 章），磨料蘸水间歇喂入。转速以磨料不被甩飞为限（经验值，需现场标定：见到磨料甩线即降速一档）。
- 合格判据：对光看无方向性划痕、能映出手影轮廓；器皿内曲面以软布蘸细粉手工推光。

**热镀锡（食物线应用）**

- 为什么镀：铜遇食物酸（果酸、醋、酸奶）溶出铜盐——蓝色、涩味、催吐毒性，铜器直接煮酸食是明确的中毒路径。锡对食物酸惰性、熔点仅 232 ℃，热镀一层 0.1—0.3 mm（经验值）即把食物接触面整体换成锡。
- 镀前净化（镀层牢不牢全在这步）：磨台磨光→粮食醋稀洗去氧化物→清水冲净→**干透**（任何水滴残留处必起鳞）。
- 镀规程度：锡入陶浅锅熔化（232 ℃，暗处不显红；锡液面平静如镜为到位判据），液面盖松香粉一层隔氧防渣；铜器预热 150—200 ℃（手感烫手级）后入锡液 5—15 s，取出趁热以干麻布卷推擦匀布——擦出的是薄层，厚处流淌聚滴。
- 食物线制度：凡接触食物的铜器（锅、勺、碗），内表面热镀锡并透光检验合格后方可入食物线；此后每季透光复检一次——内面对光看，锡面亮泽均匀为可，见铜红斑（露铜）即回炉化旧锡重镀（旧锡全回收，17.7 铜料账立"锡"栏，同式月结）。

| 字段 | 摘要 |
|---|---|
| 输入材料 | 锡锭首镀 200—300 g（锡来源与熔炼见 17.8）；粮食醋、松香粉、干麻布卷；铜器已磨光、无深划痕 |
| 所需工具 | 陶浅锅或废坩埚（第11章）、火钳、干麻布；坩埚敲声清脆校验（17.3 同法） |

【卡 17-07 热镀锡】（八字段）

1. **输入材料**：铜件（表面除油、除氧化，**有油污就挂不上锡**）；锡（熔点 232 ℃）。
2. **所需工具**：锡坩埚、夹钳、称（增重法算镀层）、撇渣工具。校准来源：镀层厚度不测微米，**用称重增量反算**（面积已知）。
3. **操作顺序与控制点**：铜件除油除氧化 → 预热 → 浸入锡液 → 取出控流 → 称增重。控制点：**锡液温度 232 ℃、表面保持镜面平静**——起渣说明温度偏高在氧化，先撇渣再浸。
4. **经验参数与标定法**：镀层目标 0.1–0.3 mm（用增重称量标定）；锡液 232 ℃；浸入时间以挂满为准，宁短不长（久了镀层超厚影响配合）。
5. **过程观察记录项**：每件记 增重克数 / 反算镀层厚度 / 表面是否均匀 / 有无露铜点 / 锡液表面状态。
6. **合格／返工／报废判据**：合格＝镀层均匀 0.1–0.3 mm、无露铜；返工＝局部漏镀，补浸（先查该处是否沾油）；报废＝镀层过厚导致装配不上（重熔回锡）。
7. **常见失败与排查顺序**：①完全不挂锡 → 表面有油或氧化膜，重新除油除锈；②局部不挂 → 该处有指印或局部氧化；③镀层厚薄不匀 → 锡液温度低、流动性差；④表面发暗起渣 → 温度偏高氧化，降温撇渣。
8. **L1／L2／L3 证据**：L1＝一件合格镀锡件＋增重记录；L2＝连续 5 件，镀层厚度落在 0.1–0.3 mm；L3＝第二人照本卡独立镀出同档件，两人反算的镀层厚度差 ≤0.05 mm。

## 失败模式与诊断

| 症状 | 候选原因（按概率） | 验证 | 处置 |
|---|---|---|---|
| 出炉是烧结矿团非铜 | 温度不足；炭不够（还原气氛未建立） | 试样法复测炉温；查装料比 | 加风加炭延时重炼 |
| 铜珠分散嵌渣里 | 渣太黏（缺熔剂）；出炉温度低 | 渣样挑丝（18 章渣棒法预告） | 增砂至 3%；提温 |
| 铜锭多孔发黑 | 还原不足；出炉后二次氧化 | 断面黑点孔洞 | 延时保温；搅动汇铜立即浇 |
| 气孔成群 | 模湿；排气槽堵；浇注卷气 | 模具滴水试验；吹排气槽 | 彻底烘干；加粗排气槽 |
| 缩孔在厚大处 | 补缩断流；浇口位置错 | 断面树状空洞 | 浇口设最厚处；浇口杯留铜 |
| 冷隔流痕 | 铜液温度低；断流再续 | 表面两层皮 | 提温；一次连续浇足 |
| 冷锻开裂 | 忘退火硬打；单轮减薄过头 | 回看起裂前减薄量记录 | 退火后轻打；下轮减薄 |
| 热锻低温开裂 | 火色褪尽仍在打（<450 ℃） | 回想火色 | 回炉复热；手感"暗不可见即停" |
| 坩埚开裂漏炉 | 升温过猛；坩埚劣质/侵蚀 >1/3 壁厚 | 敲声检查记录 | 分段预热；报废换新 |
| 泥芯漂移（壁厚不均） | 芯头过短；芯撑过稀；合范错位 | 剖件对测对向壁厚，差 >1.5 mm 即中招 | 加长芯头、加密芯撑；验壁环先行（17.9） |
| 缩孔在件不在冒口 | 冒口小于热节；补浇过迟 | 剖冒口根部见孔 | 冒口加大一号；按结膜时机补浇（卡 17-06） |
| 镀锡起鳞脱层 | 镀前未干透；器温不足；锡液多渣 | 指甲刮得起皮边、对光见露铜斑 | 烘干重镀；提器温；补松香撇渣（卡 17-07） |

- 熔铜炉温上限约束浇注质量：更大风量、更高炉温的炉型演进在18.3—18.4一并解决。

## 安全边界

- **CO中毒**：一切炉冶操作在露天或强制通风棚（第12章烟道规程），绝不入密闭室；轮班鼓风单人≤30分钟；头疼恶心立即撤人（第6章铁规）。
- **熔融金属遇水爆炸**（本章最高级危险）：浇注区半径3m内地面干燥无水洼、无雪冰；所有工具、模具、木棍**干燥预热**；禁止汗手悬于坩埚正上方；抬杠路线先清障演练空走一次。
- **烫伤处置**：冷水冲淋≥15分钟（第6章规程）；铜液飞溅入衣立即脱衣，切勿先冲水后脱衣颠倒顺序。
- **坩埚破裂预案**：每炉预备一块≥1m²干燥沙土区，破裂的铜液放流入沙，绝不浇水。
- 砷、铅作业防护见17.8，缺防护条件时这两条合金路线**整条关闭**。
- 硫化矿焙烧烟气（SO₂）：侧风向操作，刺激咳嗽即撤。
- 皮围裙、绑腿、手套为浇注必备；化纤类不存在，但皮质潮湿即换（湿皮导热快且蒸汽烫伤）。

## 验收标准

- **L1 原理验证**：自然铜冷锻—退火循环走通一轮（减薄≥50%无贯穿裂）；孔雀石一炉出铜（≥100g），断口玫瑰色致密。
- **L2 可重复制造**：连续3炉出铜率≥35%（铜kg/精矿kg，经验值）；一炉铸锭＋一炉陶范件全部通过17.5抽检（断面评级合格）；3件铜工具（凿、斧、锥各1）通过功能测试——铜凿凿灰岩成槽10cm不卷刃崩刃；铜斧砍软木50次刃口无裂纹；冷作硬化试样划伤木材深度优于同形退火试样。
- **L3 可持续生产**：铜料账运行≥1个月（四栏齐、月结平）；木炭储备与消耗率在账（每kg铜耗炭量稳定）；坩埚、铸模有备件且损耗率已知；≥1人独立完成全流程复现考核（第3章工艺卡出师判据）；维修记录（17.7分级表）连续在册。
