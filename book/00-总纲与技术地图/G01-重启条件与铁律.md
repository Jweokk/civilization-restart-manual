# 01 · 重启条件与铁律

> 本文件是全书宪法之一。任何章节与本文件冲突时，以本文件为准修订该章节。
> 第二版增补铁律六、铁律七，并把原五条铁律的表述与工艺卡制度（02 文件）对齐。

---

## 一、重启条件：读者从哪里开始

所有技术路线的歧义都源于起点不明。全书设定三种起点：

| 起点 | 初始条件 | 主要挑战 | 在本书中的角色 |
|---|---|---|---|
| A：纯自然起点 | 没有工具、容器、衣物和任何人工制品 | 从自然资源开始生存与制造 | 基础验证线：第二部按此标准写 |
| B：少量遗留物起点 | 有衣物、少量金属工具和容器，但无法补充 | 利用现有工具建立可持续生产体系 | 加速路线：各章标注"遗留物捷径" |
| C：知识保留起点 | 人们记得现代科学知识，但没有现代工业品 | 将知识转化为实际生产能力 | **主线** |

为什么以 C 为主线：本书的价值不是让读者重新发现科学定律，而是教会读者按现实可行的顺序重建技术体系。但必须始终记住一个区别——

> **知道一种技术的原理，不等于拥有制造这种技术的能力。**

一个人可以准确描述集成电路的工作原理，却仍然无法生产硅片、制造微细图形、沉积薄膜或检测芯片。全书在每项技术上区分三个等级：

1. **知识可理解**：读者能解释原理。
2. **技术可复现**：读者能利用已有资源制造出来。
3. **生产可持续**：读者能反复制造、检测、维修，并补充消耗掉的工具与材料。

三者不能混同。章节验收标准必须写明达到的是哪一级。

## 二、七条不可违反的铁律

### 铁律一：禁止工具穿越

任何章节都不能调用尚未制造出来的工具。

- 制陶章节不能预设金属模具。
- 冶铁章节不能预设现代鼓风机。
- 手工锻造章节不能预设电动砂轮。
- 精密机械章节不能预设数控机床。
- 早期发电章节不能预设现代绝缘材料。
- 半导体章节不能预设现代化学试剂和精密仪器。
- 真空器件章节不能预设膨胀系数匹配的封接丝——封接材料必须自己给出路线或明确列为外部依赖。

如果某个工具不可缺少，必须先回到它的制造章节。**章节编号即依赖顺序：第 N 章只能引用编号小于 N 的成果。**

### 铁律二：所有精度都必须有来源

不能只说"把零件加工到足够精确"。必须解释：

- 如何定义尺寸？（基准）
- 如何复制一个尺寸？（量规、模板）
- 如何比较两个尺寸？（比较测量）
- 如何发现误差？（检验方法）
- 如何制作比现有工具更精确的工具？（自举路线，如三平板互研）
- 如何判断精度是否满足要求？（验收判据）

精密制造不能从车床开始，而要从直尺、直角基准、划线工具、测量规、标准件和误差比较开始，然后才是刮研、研磨、基准面、精密滑动副、螺纹加工和机械母机。全书精度的合法来源只有两处：**第 3 章（自然基准与比较测量）与第20章（几何基准的自举）。**

### 铁律三：材料必须有完整链条

不能写"使用钢材""使用玻璃"就算交代完成。每种关键材料都必须追溯：

> 自然资源 → 采集 → 分选 → 初加工 → 提纯或冶炼 → 成形 → 检验 → 使用

铁矿石不等于铁，铁不等于钢，钢也不等于适合制造压力容器的钢。沙子不等于光学玻璃，普通玻璃不等于合格透镜，含硅矿物也不等于半导体级硅。**两种材料名字之间的每一次"等于"，都是一条要单独验收的工艺链。**

### 铁律四：每项技术都有可验证的成功标准

不以"看起来做出来了"为验收。验收判据必须写清三件事：**测什么、在什么条件下测、看到什么算合格/报废**。示例：

- 陶器：装水 24 h 液面下降 < 2 mm；沸水→冷水循环 3 次不裂。
- 铁器：折断试棒断口无大面积夹渣层；火花判碳与断口晶粒互相印证。
- 透镜：能形成可重复观察的清晰像（分辨率样板判据，见第24章）。
- 蒸汽机：水压试验 1.5 倍工作压力保压 30 min 无渗漏，然后才谈运行。
- 发电机："转了没电"必须先过排查表（剩磁→绕组→电刷中性面，见第31章），不许直接判废。
- 集成电路：在独立测试中实现规定的逻辑功能，且重复三批。

验收标准必须对应真实用途，而不是外观。

### 铁律五：所有关键技术都必须有退路

某种材料缺失不能让整条文明路线中断。替代路线必须明确说明**性能损失、资源成本、适用边界和最终瓶颈**，不能因为替代品理论上存在就宣称它能完全取代原技术。

- 没有优质铁矿 → 铜、木材、骨材、石材可推进哪些部分技术？
- 缺透镜原料 → 先走针孔成像、反射式观察和简单测量。
- 没有煤 → 木炭、水力、风力。
- 没有硅芯片条件 → 先建继电器、真空电子器件或锗晶体管路线。
- 没有匹配封接丝 → 碳电极、粗引线过渡封接，或把真空管降为外部依赖（第33章）。

### 铁律六：凡参数必有标定法，凡工艺必有失败判据，凡验收必存证据

这是第二版新增的铁律，针对"沉默失败"——冶炼、退火、绕组、真空这几类工艺做错了往往不会立刻坏，而是**坏得看不出来**：出来的是铸铁不是熟铁，外观几乎一样；玻璃没退火当天不裂，三天后在加热台上炸；发电机绕组接错与剩磁不足，症状都是"转了没电"。没有判据的读者不会知道自己错了，只会以为自己运气不好，然后重复同一炉废品。因此：

1. **参数**：写"经验值"必须同时写现场标定法；没有标定法的参数视为占位符，不得用于验收。
2. **失败判据**：每道工艺必须回答"做坏了是什么样、怎么验证坏在哪"；手册可以少讲一条捷径，不可少写一种失败。
3. **证据**：每次验收留下实物（试棒、试片、坏件）与文字（参数、判据、日期），归入台账（第43章）。**没有证据的合格不叫合格，叫印象。**

### 铁律七：劳动力是第一资产

一切设备、炉窑、电网的折旧都可以重新制造，工匠的死亡与致残不能。因此：

1. 每章安全边界的地位与工艺本身等同：**凡致死、致残、慢性中毒的工序，安全措施不是"注意事项"，是工艺步骤的一部分**，不执行视同未完成该工序。
2. 排产必须核算人：连续工序（高炉、窑、蒸汽机值守）的最小轮班人数写进工时块（第37章），单人视角的工艺书会在第二步崩掉。
3. 医疗、卫生、职业健康（第 44–49 章）与冶金、机械同权重：它们是"人的维护系统"，是全书唯一让读者活过二十年尺度的保障。疫病和硅肺杀死劳动力的速度比设备报废快，且不可逆。

## 三、明确排除的技术（写进书里会变成伪科学）

以下技术**不提供制造路线**，只在相应章节说明排除理由与将来恢复的条件。读者照书硬做会死人：

| 技术 | 排除理由 | 恢复条件 |
|---|---|---|
| 疫苗、抗生素、生物制剂 | 需要受控培养、无菌灌装、批次检测、冷链 | 显微镜+无菌技术+菌株库+检定体系（第 44–46 章给边界） |
| 电解铝 | 需要高纯氧化铝、耐腐蚀高温电解槽、稳定大电流 | 远超"毫米级手工制程"上限；铝列为本路线外部依赖 |
| 白炽灯钨丝 | 钨的粉末冶金、烧结、旋锻拉丝是高纯重工业 | 炭丝路线可用（第33章）；钨丝列为 C 项 |
| 航海钟与经度测定 | 独立的精密机械科技树，偏离主线 | 天文法粗定位可用（第 3、25 章） |

## 四、工具谱系理念：每个工具都要回答四个问题

写作与阅读都以此自检：

1. 制造它需要什么？
2. 这些东西又是如何制造的？
3. 制造过程中哪些工具会损坏、耗尽或需要更换？
4. 缺少其中某项资源时，能否走其他路线？

示例——不许只写"使用铁凿加工石材"，必须能追溯：

> 铁凿 ← 可用铁料 ← 铁矿物还原与锻造 ← 炉窑与木炭 ← 耐火材料与控温能力 ← 陶窑、燃料加工与基础测量

铁凿还需要：可反复修磨的磨料、提供冲击力的手锤、安全固定工件的装置、判断刃口状态的方法、必要时重新热处理的能力。**工具损坏时，手册必须说明能否修复、修复需要哪些条件，而不是"换一把新的"。**

## 五、从单件制作到生产体系

制造一个零件 ≠ 建立能够持续生产该零件的体系。全书各章在结尾的验收标准中，把"单件成功"（L1）与"体系建成"（L3）区分开。支撑持续生产的最小要素：

- 原料储备与补给路线（第38章物料账本）
- 燃料/能源的可持续消耗率（第38章能量账本）
- 工具的损耗率与修复/替换安排（第39章维护与备件）
- 工艺记录（参数、失败案例）（第43章档案制度）
- 质量检验方法（第 22、27 章 + 第39章质量追溯）
- 熟练劳动力与传承（第37章劳动组织、第43章师徒制）

**技术路线的上限，往往不由工具决定，而由分工规模决定。** 这也是第十部各环境版本评估"人力与时间"维度的原因。
