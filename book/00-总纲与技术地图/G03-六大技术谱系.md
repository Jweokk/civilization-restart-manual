# 03 · 六大技术谱系

> 贯穿全书的六条能力链。每写/读一章，都应知道它在这六条链上的位置：它消耗上游什么，为下游提供什么。

---

## 谱系一：材料

自然原料 → 工业材料的升级链。

> 天然矿物 → 选矿 → 冶炼 → 初级金属 → 锻造 → 热处理 → 机械零件

同理：黏土 → 陶器 → 耐火材料；砂 → 玻璃 → 光学玻璃；纤维 → 纱线 → 织物 → 工业织物。每一环都对应铁律三的完整链条：原料 → 采集 → 分选 → 初加工 → 提纯/冶炼 → 成形 → 检验 → 使用。

## 谱系二：工具

从简单工具到"制造工具的工具"。

> 石片 → 石锤 → 木工工具 → 金属工具 → 测量工具 → 精密机械 → 机床

判据：一种工具算"已建立"，当且仅当它损坏后能被修复或重造（谱系自持）。

## 谱系三：能源

> 火 → 木炭 → 炉窑 → 水力机械 → 蒸汽机 → 发电机 → 电动机

每一级能源决定上一级材料的加工上限：没有木炭与鼓风就没有铁；没有稳定机械动力就没有精密机床；没有持续供电就没有电化学与半导体。

## 谱系四：测量

> 目测 → 简单比较 → 标准尺寸 → 量规 → 精密机械测量 → 光学测量 → 电学测量 → 材料与器件检测

这是最容易被忽视、又最贯穿的谱系：从弓钻（第 7 章）到半导体（第34章），真正贯穿始终的能力就是**可靠地测量和重复**。测量的每一次升级，都来自前一级测量制造的"更精确的工具"（自举）。

## 谱系五：化学

> 燃烧 → 石灰 → 玻璃 → 基础酸碱盐 → 金属提纯 → 工业试剂 → 材料提纯与表面处理

不是所有地区都能按此顺序发展，但每项技术都应说明它需要的化学能力。终点意识：半导体路线的本质是"化学纯度能力"的总考核。

## 谱系六：信息

> 口头经验 → 图形记录 → 统一计量 → 工艺记录 → 技术图纸 → 标准化 → 生产记录 → 自动控制 → 电子计算

文明的恢复不仅依赖物质工具，也依赖可保存、可传递、可复现的知识。这条谱系提醒每个聚落：**账册与档案是基础设施，和窑炉同级。**

---

## 反馈环：文明不是单向生长的树

六条谱系之间存在增强回路，重建的真正引擎是这些回路而非链条本身：

- 精密仪器 → 改善材料研究 → 更好的材料 → 更精密的工具
- 更好的发电机 → 支持电动机械加工 → 更好的机床 → 更好的发电机零件
- 更好的测量 → 提高机械与电气产品质量 → 反哺测量仪器制造
- 电子控制 → 提高生产设备自动化 → 加速一切制造

**前期（第一至三部）以链条推进为主；中期（第四、五部）有意识地建立反馈环；后期（第六部）各环应开始自我增强。** 各章"下一步依赖"块应指出它喂入哪个环。
