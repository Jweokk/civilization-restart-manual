## 二、五条关键链（写作与审计的优先验证对象）

1. 石器 → 木工工具 → 简易机械（第 5、7、9 章）
2. 火 → 炉窑 → 耐火材料 → 金属冶炼（第 6、12、16–18 章）
3. 金属工具 → 测量 → 精密加工 → 机床（第 19–22 章）
4. 机械动力 → 电磁学 → 发电机 → 电力系统（第 21、28–32 章）
5. 玻璃与化学 → 材料提纯 → 半导体加工 → 集成电路（第 14、23–26、33–35 章）

**第 3、5 条最易出现未经说明的工具穿越，审校时逐节点核对。**

## 三、优先级决策框架

技术可行 ≠ 技术值得优先发展。比较框架（用于讨论，不是可计算的科学定律）：

> 优先级 = 生存贡献 × 资源可得性 × 可重复制造能力 × 对后续技术的支撑价值

每项技术进一步回答五问：

1. 不制造它，会卡住哪些后续技术？
2. 是否存在更廉价的替代方案？
3. 它消耗多少不可再生资源？
4. 它是否提高其他生产环节的效率？
5. 什么时候才值得投入更多人力？

**读者不仅要知道如何制造工具，还要知道什么时候不应该制造它。**

## 四、环境评估表（第十部四版本的统一模型）

| 资源或能力   | 需要回答的问题       | 影响的技术路线        |
| ------- | ------------- | -------------- |
| 水       | 是否稳定、可储存、可处理？ | 农业、化学、冶金、冷却    |
| 燃料      | 是否可持续获得？      | 制陶、石灰、玻璃、冶金、热机 |
| 黏土与耐火材料 | 能否造可靠的炉窑？     | 高温工艺与金属冶炼      |
| 金属矿物    | 有无可利用矿源？      | 金属工具、机械、电气设备   |
| 石英及含硅原料 | 原料与后续提纯条件？    | 玻璃、光学、半导体路线    |
| 木材与纤维   | 是否充足且可持续？     | 工具、建筑、运输、部分机械  |
| 可用动力    | 水流、风力、日照、燃料？  | 机械动力与发电        |
| 运输条件    | 能否搬运矿石、燃料、设备？ | 工业布局与专业化       |
| 维护能力    | 能否持续修理工具设备？   | 技术的长期可持续性      |
| 人力与时间   | 多少人能长期参与？     | 路线选择、产能、分工     |

核心原则：**环境差异不仅改变材料来源，还会改变整个文明的发展顺序。** 四个环境版本共享技术知识，但不共享同一条技术顺序。

## 五、技术边界：三种目标不得混同

以集成电路为例（第35章严格执行此表）：

| 目标     | 含义                             | 本书态度                     |
| ------ | ------------------------------ | ------------------------ |
| 理解     | 能解释工作原理与主要制造环节                 | 全书持续交付                   |
| 制造简单器件 | 在已建立的材料、设备和测量基础上，制造并验证有限复杂度的器件 | 第六部的终极挑战                 |
| 重建现代工业 | 持续生产高性能、复杂、可靠、有竞争力的产品          | **如实标注为超出单卷能力**，给出所需条件清单 |

诚实地写出边界，比编造一条看似完整、实际无法执行的路线更有价值。第36章"哪些现代技术暂时无法重建"是全书可信度的一部分，不是缺陷。
