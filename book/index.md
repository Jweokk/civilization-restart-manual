# 文明重启手册

工业文明断档之后，怎么从一块石头重新走到电。

这本书不赌灾难会不会来。它只假设一种处境：某一代人手里只剩下土地、石头、木头和火，而没有人记得怎么把它们变成工具。全书 56 章、11 部，从建立测量体系与取火开始，一路走到玻璃、钢铁、电、纸墨、医药，以及把人组织起来的那套制度。

## 怎么读

- 每一道「手把手才做得出来」的工序，编成一张**工艺卡**。卡有固定八项：输入材料、所需工具、操作顺序与控制点、经验参数与标定法、过程观察记录项、合格／返工／报废判据、常见失败与排查顺序、L1／L2／L3 证据。
- 卡可以单页抄出来带到工位：抄在木板上、钉在墙上、塞进工具袋都行。全书共 286 张这样的卡，中英文各一套。
- 凡是「经验值」，卡里都写明必须按本地材料标定——不给你一个假精确的数字。
- 每张卡的第 8 项写明这道工序该拿什么证据才算过关。

## 从哪儿开始

手上有什么，决定了读哪条线：

| 你现在的处境 | 先读 |
|---|---|
| 什么都没有，只有一片荒地 | 第 1–4 章，再按第 4 章的路线图选线 |
| 有土、有窑，想做容器与砖 | 第 11–14 章（陶、玻璃、高温炉） |
| 有矿石，想得到铁 | 第 16–19 章 |
| 想做得准，能量、能测 | 第 24–27 章（精密制造与仪表） |
| 要发电、要通信 | 第 31–36 章、第 55 章 |
| 人多了，要管起来 | 第 37–40 章 |
| 要留下记录、要教下一代 | 第 41–43 章 |
| 有人受伤、有人生病 | 第 44–49 章 |
| 在沙漠、海岛、寒地、疫区 | 第 50–53 章 |
