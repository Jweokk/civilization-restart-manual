# 第1章 文明重启究竟意味着什么

## 本章目标

* 建立三个判定能力：

  1. 判定自己所处的重启起点（A/B/C）；
  2. 判定任意一项技术处于 L0–L3 中的哪一级；
  3. 对任意目标技术列出依赖链，找出关键路径与瓶颈。

* 本章不制造任何实物。产出物是四件"纸面工具"（起点判定清单、等级判定表、依赖追溯四问卡、空白依赖图模板），后续所有章节都会调用它们。

* 本章同时给出全书最低层的边界规则：什么算"天然物直接利用"，什么算"工具"。

### 1.1 三种重启起点

三种起点是全书所有技术路线的分岔口，必须在第一天判定，写成一份"起点清单"。

| 起点        | 初始条件                | 主要挑战           | 本手册角色            |
| --------- | ------------------- | -------------- | ---------------- |
| A：纯自然起点   | 无工具、容器、衣物与任何人工制品    | 从自然资源开始生存与制造   | 基础验证线（第二部按此标准写）  |
| B：少量遗留物起点 | 有衣物、少量金属工具与容器，但无法补充 | 用现有工具建立可持续生产体系 | 加速路线（各章标"遗留物捷径"） |
| C：知识保留起点  | 记得现代科学知识，但无任何现代工业品  | 把知识转化为实际生产能力   | 主线               |

**判定步骤（第一天完成）：**

1. 盘点 24 小时内可用的人工制品：衣物、金属工具、容器、绳线。
2. 规则：有 ≥1 件金属工具且无法补充 → B；无任何人工制品 → A；有人群记忆中的现代知识、无工业品 → C。
3. 判定结果与盘点明细一起记入起点清单。混合状态（例：有衣物无工具）按最低档处理。

**起点资源盘点——任何起点都拥有三类资产：**

1. 身体：手、指甲、牙、体温、体力、步幅、心跳。它们是第一批"测量仪器"（第3章将正式利用）。
2. 天然物：捡拾即用的石块、木棒、藤条、贝壳、兽骨。\*\*边界规则（全书有效）：未经加工的天然物，直接手执使用，不构成工具穿越；一经打制、磨制、雕刻成形，即视为工具，归第5章及以后的成果。\*\*此后各章凡写"手执石块敲击"，均指本规则允许的用法。
3. 知识与记录能力：起点 C 的核心资产。但知识必须先过"记忆可靠性"检查——错误记忆比没有记忆更危险（见本章 C 节）。

**失败模式：**

* 误判起点。B 起点最常见的错误：把遗留钢刀当作可持续能力，过度使用直到磨损失效，且从未建立重造能力（可用铁料要到第18章）。规则：**遗留物只许用于加速制造"可自持的更低级工具"**（例：用钢刀削出第一根标准杆，然后立刻转入不用钢刀也能维持的路线）。

* 把起点 C 的知识当成资产的全部。知识是路线图，不是产能。见 1.2。

**B 起点遗留物管理三规则（防"坐吃山空"）：**

1. 登记造册：每件遗留物建一条档案（件名、材质、现状、启用日期），纳入第3章档案制度。
2. 用途分级：只用于加速制造"可自持的更低级工具"或一次性基准制作；禁止日常消耗性使用。例：遗留钢刀不许当厨刀，只许削第一批标准杆。
3. 失效预案：每件遗留物旁注"损坏后以第 N 章成果顶替"；写不出顶替方案的，视为"临终资源"，使用前必须先建顶替路线。

### 1.2 什么才算真正重建了一项技术

全书把"拥有一项技术"拆成四个等级，任何等级不得混报：

| 等级 | 名称    | 判据                          |
| -- | ----- | --------------------------- |
| L0 | 知识可理解 | 不看手册，能写出原理与主要工序             |
| L1 | 原理验证  | 做成过 1 次，有日期与现象记录，但不稳定       |
| L2 | 可重复制造 | 按记录的工艺连续 3 次做出合格品（合格判据须先写明） |
| L3 | 可持续生产 | 工具损坏能修复或重造；原料断供能续上；换人照记录能做出 |

**升级条件（逐级追问）：**

* L0→L1：缺的是一次实际操作。安排时间与材料。

* L1→L2：缺的是参数与记录。把每次操作的条件（材料批次、参数、天气）写全，找出成功与失败的差异。

* L2→L3：缺的是体系。回答：工具的损耗率？原料的补给路线？谁会第二套做法？备件在哪？

**"把 L1 当 L3"的三个识别信号（自查）：**

1. 没有失败记录——只成功过没失败过，说明试的次数不够。
2. 没有第二件产品——只做过一件的东西不是技术，是事件。
3. 没有消耗品补充计划——原材料用完了怎么办，答不上即未达 L3。

**误报句式对照（自查用）：**

| 常见说法        | 实际等级  | 纠正动作             |
| ----------- | ----- | ---------------- |
| "我学过、见过别人做" | 最多 L0 | 安排一次实际操作         |
| "我做出来过一个"   | L1    | 连做 3 件合格品并全程记录   |
| "照着做基本没问题"  | 不足 L2 | 补参数窗口与失败记录       |
| "反正随时都能做出来" | 未验证   | 停援测试＋换人复现（见 1.4） |

**贯穿示例（仅作预告，实物在第5章建立）：** 一片有刃石器。能说出"打制石片需要贝壳状断口的均质石料"=L0；打出过一片能切草茎的石片=L1；连续打出 3 片、每片都能切断 20 根干草茎而不崩刃=L2；石料来源在资源地图上有记录、打石锤磨损后能再捡再修、另一人按记录也能打出=L3。

### 1.3 为什么现代技术无法直接照搬

现代制品背后是四层隐性依赖，任何一层在重启初期都不存在：

| 隐性依赖 | 现代世界的默认条件    | 重启初期现实              |
| ---- | ------------ | ------------------- |
| 能源密度 | 电网、燃油，随取随用   | 只有肌肉、柴草与火（第6章起）     |
| 材料纯度 | 试剂级化学品、规格钢   | 只有矿物、黏土与生物质（第2章起）   |
| 标准化  | 公差、互换件、螺纹标准  | 连统一长度单位都没有（第3章起）    |
| 供应链  | 一台设备背后是数千家工厂 | 半径一日脚程内的一切（第2章资源地图） |

**"追三层"练习（本章必做一次）：** 任选一个现代物品，连续追问三轮："它用什么做的？→ 那些东西哪来的？→ 那些东西的加工工具又是什么？"

* 三层之内触底（落到石头、木头、黏土、火这类自然物）→ 该物品可较早尝试。

* 三层之外仍未见底（例：不锈钢刀 → 钢厂 → 铁矿＋焦炭＋耐火砖 → 各自再追一层）→ 必须先建上游，不可直接尝试。

结论：起点 C 的真正资产是"知道往哪走、知道哪条路是死的"，不是"已经拥有"。手册的任务是把"知道"逐章兑换成 L1、L2、L3。

**知识保留者的四个常见错觉（逐条自查）：**

1. "原理懂了就等于会做"——原理只是 L0，与 L2 之间隔着参数窗口与失败库（3.7）。
2. "跳过旧技术直接上更好的方案"——好方案的前提（材料、量具、能源）恰恰由旧技术建立。
3. "现代数字可以直接拿来用"——无标准量具时，"几毫米""多少度"这类数字没有测量来源（铁律二），只能以第3章自建基准表达。
4. "一个人可以全能"——现代技术的分工深度决定了重建必须分工（1.4）；单人路线的现实上限止于第二部。

### 1.4 从单件制作到生产体系

制造一个零件 ≠ 建立能持续生产该零件的体系。体系的六个最小要素（各章验收 L3 时逐项核对）：

| 要素    | 追问                | 记录载体          |
| ----- | ----------------- | ------------- |
| 原料储备  | 现有存量？补给周期？        | 资源地图（第2章）     |
| 能源消耗率 | 每件产品烧多少柴/耗多少工时？   | 工艺卡（3.7）      |
| 工具损耗率 | 哪些工具会坏？多久坏？坏了怎么办？ | 工具档案（第3章档案制度） |
| 工艺记录  | 参数、失败案例是否成文？      | 泥板档案（3.6）     |
| 质量检验  | 合格判据是什么？谁验？       | 验收标准（各章）      |
| 人力与传承 | 几个人会做？换人还行吗？      | 传帮带记录（3.7）    |

**两个量化判据：**

1. 产出率 = 合格品数 ÷ 投入总工时。只在 L2 之后开始统计。
2. 可持续判据：资源消耗速率 ≤ 资源再生/补给速率。例（预告第11章）：一窑陶器消耗的木材量必须落在该片林地的年再生量内，否则陶器生产会在几年内自我断供。

**体系存在性的粗暴检验：停援测试**——假想（或实际）停止一切外部输入 30 天，该技术的产出是否还能维持。能维持的才算聚落"拥有"它。

\*\*示例（数字为虚拟，格式供模仿）：\*\*某聚落月产陶罐 30 只，合格 24 只，投入 60 个工作日 → 产出率 0.4 只/工日；燃料消耗每窑 3 担柴、每月 4 窑，对照林地年再生量 200 担 → 占用约七成。两数每月各记一次，趋势比单值重要：产出率连降三月，先查工具损耗与原料批次，而不是催促工时。

**失败模式：** 把"某位工匠会做"当成"聚落能产"。工匠病倒即停产 = 体系缺失第 6 要素。对策在 3.7（从个人经验走向可复制工艺）。

### 1.5 技术树、瓶颈与依赖关系

**依赖倒推法（四问卡）：** 对任何目标技术，依次回答：

1. 制造它需要什么？（工具、材料、能源、知识——四依赖，第4章展开）
2. 这些东西又是如何制造的？（对每项重复追问，直到落到第2章的自然资源或已建成的章节成果）
3. 制造过程中哪些工具会损坏、耗尽或需要更换？
4. 缺其中某项时，能否走其他路线？（替代路线须写明性能损失、资源成本、适用边界、最终瓶颈——铁律五）

**示例（引自提纲，供模仿）：** 铁凿 ← 可用铁料 ← 铁矿物还原与锻造 ← 炉窑与木炭 ← 耐火材料与控温能力 ← 陶窑、燃料加工与基础测量。旁支：磨料、手锤、夹持装置、刃口判定法、再热处理能力。每一环的实物分别在第18、12、11、6、3、2 章建立。

**第二个示例（读者照此格式练一遍）：** 陶罐 ← 黏土净化与配料 ← 陶窑与燃料 ← 耐火材料 ← 可控燃烧 ← 引火物与干柴 ← 资源地图。旁支：收缩率记录（第3章量具）、烧成周期（第3章时间锚）、验收判据（不漏水、耐热循环——铁律四）。实物分别落在第11、12、6、3、2 章。两条链的公共节点是"可控燃烧与资源地图"——它同时卡住两条链，这就是瓶颈：瓶颈优先投入人力，因为它解除后多条链同时前进一步。

**关键路径与瓶颈的定义：**

* 关键路径 = 从起点到目标的最长前置链。它决定最早完成时间，其余链可并行。

* 瓶颈 = 被多个下游同时依赖的节点（例：可控火源是陶、炭、石灰、冶金的公共前置；测量体系是几乎所有 L2 验收的公共前置）。瓶颈应当优先投入人力。

**优先级决策（引用总纲 G04）：** 优先级 = 生存贡献 × 资源可得性 × 可重复制造能力 × 对后续技术的支撑价值。这是讨论框架，不是可计算的公式。配套五问：不制造它会卡住什么？有更廉价的替代吗？消耗多少不可再生资源？能否提高其他环节效率？何时才值得加人？

**产出：空白依赖图模板。** 节点字段：名称 / 来源章节号 / 当前等级（L0–L3）/ 旁支依赖 / 替代路线。用刻划泥板或地面刻划场维护（载体见 3.6）。规则：**任何节点在未达到标注章节之前，图纸上的状态永远是"未建成"，哪怕你觉得你会做。**

## 失败模式与诊断【方法章】

本章无工艺，失败模式为方法误用：①把遗留物当可持续能力（自举线预告见第18章）；②把预告当已有（判据见第4章）；③记忆污染（关键数字≥2人交叉核对，定量验证待第25章）。

## 工艺卡索引【方法章】

本章不设工艺卡——交付物为方法件（清单/表格/循环），见 B 清单；各工艺章的卡以本章 4.7 的循环使用。

## 安全边界

* 本章无物理操作。

* 唯一条款：**不得以"知道原理"为由跳过验证直接从事危险工艺**（高压、高温、毒性物质）。相关硬性禁令见各章"安全边界"块，第六部（蒸汽、电力、化学品）尤其不可凭知识裸奔。

## 验收标准

* **L1 原理验证**：对给定技术（示例：陶罐），能说出 L0–L3 差异与自己当前所处等级，并指出三个"L1 当 L3"信号中自己中招与否。

* **L2 可重复制造**：完成本环境的起点清单 + 至少 1 张完整依赖倒推图（含旁支与替代路线），由第二人按四问卡独立复核，未发现工具穿越。

* **L3 可持续生产**：聚落内 ≥2 人能独立使用本章工具对新目标做依赖分析；分析结论与后续实际推进之间的偏差被记录，并用于修订分析方法本身。

本章为立场与方法章，能力边界即全书边界本身（天然物可直接用、一切工具必须可追溯）；不含工艺参数，无参数总表；本章的定量性内容只有一处能力等级判定（L0–L3 的三等级表，见 1.2）。各工艺章的参数与判据均落在本章之后各章——本章不预发任何数字，正是"禁止工具穿越"的自身演示。
