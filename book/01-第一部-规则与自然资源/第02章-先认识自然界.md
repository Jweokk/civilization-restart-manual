# 第2章 先认识自然界

## 本章目标

* 建立"资源调查"能力：对活动半径内的岩石、土壤与黏土、植物材料、水与常见原料、燃料与自然能量做系统普查。

* 产出三件实物成果：资源调查记录表（≥20 条）、资源地图（1 张）、符号对照表（2 份备份）。

* 本章只做识别、简单试验、记录与评级，不加工任何材料。结论一律标注置信度（确认/疑似/未知），"疑似"待后续章节煅烧、试烧验证后回填。

### 2.1 岩石、矿物与矿石的区别

**三个工程定义：**

| 概念 | 定义                     | 调查时的问法           |
| -- | ---------------------- | ---------------- |
| 岩石 | 多种矿物的天然集合体（花岗岩、砂岩、石灰岩） | 它整体能不能当建材/磨石/石料？ |
| 矿物 | 单一天然化合物或单质（石英、方解石、赤铁矿） | 它的条痕、硬度、光泽是什么？   |
| 矿石 | 某种有用成分的品位高到值得回收的岩石     | 就地捡到的量值不值得运回去？   |

关键认知：\*\*普通岩石遍地都是，矿石极少。\*\*红褐色的石头不等于铁矿。判据永远优先于颜色印象。

**一级线索（肉眼可得，按可靠性排序）：**

1. 条痕：样品在粗石英砂岩板上划出的粉末色。条痕色比块体外表色稳定得多。
2. 断口形态：贝壳状断口（像贝壳内面的弧面）是燧石、黑曜石这类均质玻璃质石材的特征——它们是第5章打制石器的首选。平坦断口、层理面则是沉积岩。
3. 硬度档（见 2.6）：指甲（约 2.5）与石英（约 7）划出三档。
4. 光泽：金属光泽/玻璃光泽/油脂光泽/土状。
5. 晶形：能看清晶面的（石英六方柱、立方体黄铁矿）记下形状。

**常见条痕对照（现场背下 5 条即可起步）：**

| 矿物  | 块体外观    | 条痕  | 备注                              |
| --- | ------- | --- | ------------------------------- |
| 赤铁矿 | 红褐至黑    | 红棕  | 铁的最常见来源（第18章）                   |
| 磁铁矿 | 黑、金属光泽  | 黑   | 密度明显大；铁来源                       |
| 褐铁矿 | 黄褐、土状   | 黄褐  | 含水氧化铁，铁来源                       |
| 黄铁矿 | 金黄色、立方晶 | 绿黑  | "愚人金"：比金硬（约 6），金软（约 2.5–3）且条痕金色 |
| 石墨  | 黑、滑腻、染手 | 黑、亮 | 极软（1–2），后续做润滑与标记                |

**失败模式：**

1. 背矿物名称清单却无产地证据。对策：手册只给判据，"脚下有没有矿"必须由 2.7 的实地调查回答。
2. 被块体颜色骗（黄铁矿当金、红色砂岩当赤铁矿）。对策：先划条痕再下结论。
3. 把单个好看的晶体当"矿脉"。对策：记录时必须写分布范围（见 2.7 表），单颗晶体在"可采量"栏如实写"少"。

### 2.2 土壤、黏土、砂砾和沉积物

黏土是陶器（第11章）、泥板（3.6）与建筑（第13章）的共同原料，优先级最高。

**黏土现场四试验（全部徒手＋水）：**

1. 湿搓试验：指节大小土样加水揉透，在掌心搓条。能绕小指一整圈不断裂 = 塑性好，黏粒含量高；一弯即断 = 含砂多或黏粒低。
2. 指捻试验：湿样在指腹捻开。滑腻如膏 = 细；明显砂粒感 = 砂质。此档手感分三档记录：膏/粉/砂。
3. 沉降试验：天然容器（剖开的大竹节、大贝壳、折成的树皮斗）装水，投入指节大土样搅散静置（时长以心跳计，见 3.1）。粗砂数拍即沉；粉粒沉清需数刻；水放置大半天仍浑 = 含细黏粒。沉降时间分界为经验值，需现场标定：用一份已知河砂做对照同时沉降。
4. 干缩试验：湿样压成掌大泥饼，阴干两日。对比刻痕：收缩大、裂成数块 = 黏粒极高，直接制陶会开裂，需掺砂（配料在第11章解决）；几乎不裂不缩 = 砂多，塑性不足。

**砂砾与沉积物：**

* 河砂：颗粒圆，通常较干净；海砂含盐（咸味，微量确认），后续用于灰浆与玻璃前需用淡水冲洗（冲洗工序属第13、14 章，此处只记录"含盐"属性）。

* 石英砂（白色、玻璃光泽颗粒为主）：记入地图并标"高优先"——它是玻璃路线（第14章）的原料。

* 沉积环境判读：河湾、湖积、旧河道、风积黄土层——土层厚且细的地带同时是黏土与农田（第10章）的候选，记录时两栏都勾。

**失败模式：** 只试一处就宣布"有黏土"。对策：同一河谷至少取 3 处样分别做四试验，条目分开记录——黏土质量可以在几十步距离内剧变。

### 2.3 木材、树皮、纤维、树脂与天然黏结材料

**每棵候选树一条记录，调查维度：**

| 维度   | 现场判法                                      |
| ---- | ----------------------------------------- |
| 树种分组 | 落叶/常绿；针叶/阔叶。针叶树常有树脂                       |
| 干形   | 主干通直长度（步数量）、弯曲、分叉高度——决定能否取直料              |
| 材质手感 | 同手长度的断枝掂重分三档：轻（泡桐类）/中/重（栎类）；重者后续做锤、轴（第7章） |
| 纹理   | 顺纹劈裂试验：用捡拾石块沿纹理敲进裂缝，易顺纹劈开 = 取板/取条性好       |
| 含水状态 | 枯立木（死而未倒）比倒木干、比绿木易燃——燃料首选（第6章）            |
| 韧皮   | 剥下内树皮条，手拉不断 = 韧皮纤维可用（绳索候选，第7章验证）          |
| 渗出物  | 树干伤处渗出的树脂、树胶：捏软硬、闻味、记颜色（黏结与防水候选，第8章验证）    |

**纤维的其他来源：** 草茎（长而韧的）、藤条、树根须、动物毛与筋腱（若有猎获）。本阶段只记录"拉不断"这一项手试结果，加捻成绳是第7章的工艺。

**可持续采收规则（起步值）：** 每片林地首个采伐年不超过十分之一乔木（经验值，需现场标定：标记 20 棵样树，逐年记录更新量后修订上限）。枯立木、倒木优先采。资源地图上每片林地单列一条，含"年采上限"栏。

**失败模式：** 资源地图只记"有树林"不记树种构成与蓄积量，三个月后才发现好材种只有七棵。对策：分布与估量栏必须写步数尺寸与优势树种。

### 2.4 水、盐、石灰石、硫及其他常见原料

**水（每处水源单独立条）：**

* 类型：泉/溪/河/湖/雨/雪。泉与活溪优先。

* 记录：位置、季节性（不知则标"待观察一年"）、浊度（透明/微浑/浑）、气味、水温手感、下游污染迹象（尸体、藻华、异味）。

* 本阶段饮水判据（极有限，如实声明）：活水＋透明＋无味＋上游无人畜腐尸迹象。**这不是消毒**——致病微生物不可见。煮沸消毒能力在第6章建立之前，静水与浅洼水原则上不饮。

**盐：** 岩盐露头（白/无色、咸味、质软能掐碎）、盐泉（泉边白色盐霜）、盐湖、海滨。味觉判定仅限已判明咸味的微量确认，未知样品禁尝。用途预告：食品保存（第10章）、化学工业起点（第23章）。缺盐地区在地图上如实标"无"。

**石灰石（无酸时代的判据组合）：** 灰白至青灰色；能被石英块刻出粉痕（硬度 3–4 档，低于石英的 7）；断口较平坦；**常含贝壳或珊瑚化石；常与溶洞、泉口钙华（疏松多孔的白色石灰华）共生**——化石与钙华是最有价值的间接证据。最终验证靠煅烧：烧后变轻、遇水发热化粉（需第6章的火与第12章的窑，届时回填）。

**硫：** 黄色、脆、易碎成粉、有特殊气味，见于火山与温泉区。无火山区常无硫——如实记录；缺硫对后续某些化工与消毒路线是硬边界，不在本章解决。

**其他单列原料：** 燧石结核与条带（石灰岩中，第5章首选）；黑曜石（玻璃质火山岩，贝壳断口，锋利但脆）；高岭土（白色土、蚁丘白土线索）；赭石颜料；天然磨石（细砂岩平整大板）；石墨（见 2.1 表）。

**失败模式：** 把"理论上应该有"当"已找到"。对策：地图上每个条目都要有位置与实物样，没有实物的猜测一律写进"待查清单"而不是资源条目。

### 2.5 燃料、热源与可利用的自然能量

**燃料资源（只调查，不试烧——试烧需要火，属第6章）：**

| 燃料     | 识别                | 备注                  |
| ------ | ----------------- | ------------------- |
| 枯立木/倒木 | 死树、干枝             | 首批主燃料               |
| 绿木     | 含水高、烟大            | 记而不采                |
| 兽粪     | 草原/牧区             | 晒干后可燃（第6章验证）        |
| 泥炭     | 湿地黑色纤维土、可见植物残体    | 采掘有陷落风险（安全边界）       |
| 煤露头    | 黑色、比同块岩石轻、易碎染手、层状 | 记"疑似煤"，试烧验证推迟到取得火源后 |

**自然能量（记录存在与位置，利用属远期）：**

* 水力：候选点记落差（步数与目估，精确测量等 3.3）与流速（叶片漂过两步点所耗节拍数，粗测）。水轮与传动在第21章。

* 风力：常年风向（旗形树冠指示）、体感风级表：静/动叶/动枝/摇干。风车属第29章。

* 日照：坡向（向阳坡记录）、云量等级。太阳能利用属第52章。

* 畜力/人力：现有牲畜种类与数量、可投人工时。

\*\*失败模式：把能量存在当能量可用。\*\*有河不等于有水力——没有落差与水轮（第21章），河水只是水。条目"可能用途"栏只许写"候选＋目标章节号"，不得写"可用"。

### 2.6 怎样从外观、硬度、密度和其他简单试验识别材料

**随身测试包（全部为捡拾天然物，不加工）：**

| 工具                       | 用途         |
| ------------------------ | ---------- |
| 条痕板：手掌大平整粗石英砂岩板          | 条痕色        |
| 指甲（硬度约 2.5）              | 下限参照       |
| 石英参照块（确认过是石英的白色晶块，硬度约 7） | 上限参照       |
| 树皮斗/大贝壳 + 水              | 沉降、浮沉、吸水试验 |
| 树叶或草茎标尺                  | 记长度档（不标数值） |

B 起点若有铜器遗留，可加"铜（约 3）"档；A/C 起点无，不补。

**随身硬度阶梯表**：

| 试物（划具）                | 硬度档   | 判读                   |
| --------------------- | ----- | -------------------- |
| 指甲划得动                 | <2.5  | 极软：方铅矿、石膏、云母类——金属矿候选 |
| 指甲划不动、铜片能划（B 起点）      | 2.5–3 | 软：多数硫化矿              |
| **小刀/铁钉划得动**（第四部后补此档） | 3–5.5 | 中：孔雀石、赤铜矿、萤石、磷灰石     |
| 小刀划不动、**硬币划不动**       | 5.5–7 | 硬：磁铁矿、赤铁矿、长石、黄铁矿     |
| 石英（参照块）也划不动           | ≈7    | 极硬：石英、锡石、刚玉          |

用法：自上而下逐档试，**停在第一档"划不动"处即该物硬度档**——与 2.1 各矿物表对照可排掉一半候选。经验备注：划痕以"能留下擦不掉的刻线"为准，粉痕擦得掉的不算（那是划具自己的粉末）。

**十步鉴别流程：**

1. 记采集位置与环境（河滩/坡地/露头）。
2. 肉眼：颜色、光泽、层理、晶形。
3. 断口：贝壳状/平坦/锯齿/土状。
4. 条痕：在条痕板上划，记颜色。
5. 硬度三档：指甲划得动（<2.5）/指甲划不动但石英划得动（2.5–7）/石英划不动（≈7）。
6. 密度三档：同手大小掂重——轻（明显轻于一般石头）/中/重（坠手，多为金属矿物）。
7. 水试：浮沉（木/轻质）；滴水看吸水（黏土吸水变黏，页岩不吸）。
8. 磁性：无铁器时代的弱判据——碎屑间互相吸引才记录"疑似磁性"，主判据仍是条痕＋密度。
9. 对照 2.1–2.5 的表，给出判定＋置信度（确认/疑似/未知）。
10. 装袋编号（草茎捆扎），回填 2.7 记录表。

**误判记录法：** 每次事后发现判错，补写一条"误判条目"：原判定/实为何物/哪条判据失灵。误判条目与资源条目同等归档——它是判据表的修正依据。

**失败模式：** 跳步出结论（只看颜色就写"赤铁矿"）。对策：流程卡上十步做完才许填"判定"栏；做不完填"未知"。

### 2.7 如何建立自己的资源地图

**地图三要素：**

1. 基准点：营地正中立一块人头大的石，地图一切位置以此为原点。
2. 方向：立杆等影法定南北——上午标记杆影端点 A，下午标记影长与上午相等时的影端点 B，AB 连线为东西向，其垂直方向为南北。此法不依赖任何工具，任何晴日可复测校验。
3. 距离：步数。注明"非标准单位，待第3章升级"。步测本身先做个人标定：走 100 步量长度记入个人步长（见 3.7 示例工艺卡）。

**记录载体（按耐久性）：** 阴干刻划泥板（怕水，离地高架存放）、刻木、结绳（仅作提示索引，不存参数）、营地地面刻划场（大比例示意）。符号系统约定 ≤20 个刻符（水/黏土/石/燧石/铁/燃料/危/优……），符号对照表本身作为档案，两份异地备份。

**资源调查记录表模板（本章核心交付，逐栏必填）：**

| 栏目        | 填写内容                    | 示例                |
| --------- | ----------------------- | ----------------- |
| 编号/日期/调查人 | 顺序号＋日名                  | 007 / 第9日 / 甲     |
| 位置        | 相对基准点方向＋步数＋地貌           | 东偏南，约1200步，河湾北岸   |
| 类别        | 岩/土/植物/水/燃料/能量          | 土                 |
| 判定＋置信度    | 名称＋确认/疑似/未知             | 黏土，疑似（未煅烧验证）      |
| 试验记录      | 条痕/硬度档/断口/密度档/四试验结果     | 搓条绕指不断；沉降大半日仍浑    |
| 分布与估量     | 露头或区域尺寸（步数）＋可采量级（少/中/多） | 沿岸约200步，厚约3指，量级：多 |
| 采集难度      | 徒手/需工具/需多人/需搬运步数        | 徒手可挖              |
| 可能用途      | 候选用途＋目标章节号              | 陶器（第11章）、泥板（3.6）  |
| 验证状态      | 未验/已验（注章节号）/误判（注条目号）    | 未验                |
| 优先级       | 高/中/低（按第1章优先级框架）        | 高                 |

**勘察计划（分层推进）：** 第 1 周覆盖半日脚程圈；第 1 月扩至一日脚程。黏土、石料、燃料、水源四类目标优先，每日以一类为主线。

**回填规则：地图是活档案。** 条目被后续章节验证或证伪，当月回填"验证状态"栏。只增不填的地图，一年后就是一堆过期信息。

**失败模式：**

1. 只记"有"不记"量"——第三部规划产能时无从下手。对策：估量栏与量级栏必填。
2. 无基准点或地标描述含糊，第二人无法重访。对策：位置栏三要素（方向/步数/地貌锚点）缺一不可，验收即按重访测试。
3. 记录人变动后符号失传。对策：符号表双备份，新人第一课先学符号表。

## 失败模式与诊断【方法章】

本章失败模式：①跳步判定（十步未完即写结论——流程卡强制）；②把'疑似'当'确认'（置信度必须标注）；③把能量存在当能量可用（有河≠有水力，第21章）；④单次取样定矿点（连续三点无矿化才封边）。

## 安全边界

* **禁止品尝未知矿物与土壤**；味觉仅限已判明为食盐类的微量确认，不得吞咽。

* 悬崖与洞口：先远观划出崩落区再靠近，不敲上方岩体。本阶段无照明与支护，矿井与深洞禁止进入。

* 泥炭沼泽取样 2 人同行，长棒探路，人不下软泥。

* 无煮沸手段（第6章前）不饮静水；野炊尚未建立（同前）。

* 陡坡采伐、攀高取藤一律禁止——木工与安全绳索在第7章。

## 验收标准

* **L1 原理验证**：完成半日脚程圈首轮普查：≥20 条记录＋1 张资源地图，每条含位置三要素与置信度。

* **L2 可重复制造**：任抽 3 条记录，第二人按"方向＋步数＋地貌"独立重访，全部定位成功；黏土、燃料、石料/矿石三类各有 ≥1 条"疑似"以上条目；十步流程卡对 5 个样品执行留痕。

* **L3 可持续生产**：记录-回填制度运行（≥10 条被验证/证伪并回填）；符号表与地图双备份每季核对一致；勘察圈扩至一日脚程；≥1 条误判条目并据此修订判据表。
