    第9章 第一批真正可重复使用的工具¶

    第二部·生存、火与原始材料（本部终章）。前四章积累了石器、火、木与绳、黏土与胶；本章把它们组合成可复用、可维修、可复制的工具体系：复合工具、工装（钻、锯、磨、夹）、工作台与工具箱，并建立多人协作与产能制度。本部验收目标：具备采集材料、制作工具、控制火、加工木材和记录工艺的基本能力。

    本章目标¶

    • 完成"占位工具"到"正式复合工具"的升级：装柄规范＋胶粘＋楔锁＋绑扎四重连接。
    • 建立第一批工装：砂磨钻孔（石/骨/木）、弓锯与弦锯、磨削平台。
    • 建立第一套固定装置与工作台（夹持是重复精度的前提）。
    • 建立"工具的工具"自举路线、标准件与维修制度。
    • 建立多人协作工序与第一套基础工具箱。
    • 产出物：每个工位一套合格工具箱＋台账＋维修记录。

    最低前置条件¶

    工具 石器全套、木工工具、弓钻、绳三档 第5、7章
    热源 火堆、炭床、木炭 第6章
    材料 焦油胶、生皮条、筋腱、羼料黏土、颜料 第8章、7.3
    记录 角度板、刻线尺、编号制度 第3、8章

    9.1 石器与木器的组合¶

    完整复合工具规格表：

    工具 刃角 柄长 装柄角 用途边界
    石斧 60°—80° 60—90cm 刃线垂直柄轴 砍伐、劈
    石锛 45°—60° 30—45cm 刃与柄60°—75° 削平、剔槽
    石刀 20°—40° 15—25cm 直柄或侧槽 切割
    石凿 30°—50° 15—20cm 同轴 剔、撬；禁锤
    刮刀 45°—70° 10—15cm 同轴 刮光

    木卡尺：硬木条一端钉/刻固定直挡（基准爪），木条上以标准杆的"指"级刻线为滑爪位置——滑动爪（直挡小木块）贴工件后，把它的边线压刻到木条上读最近刻线。零位校准：两爪闭合时滑爪边应压在零线——偏了在爪背垫薄木片校正，校后以烧灼硬木条烫痕＋焦油点固（铁丝待第 17–18 章）。精度：指宽刻线＋目估半指（约 5–8 mm 级，经验值）——比"看着差不多"强，比第20章卡板弱一档，做它就是为了在还没有卡板之前让"一样大"有证据。零位每周复校（木件胀缩，湿季加密）。

    【卡 09-03 木卡尺制作与零位校准】（八字段）

    1. 输入材料：硬木条一根（尺身）；直挡木块两只（基准爪与滑爪）；薄木片（垫隙校正用）；焦油（点固用）。
    2. 所需工具：刻线具（按标准杆"指"级刻线）、炭（烧灼烫痕定线）、磨石（爪面修平）。校准来源：刻线取自标准杆的指级分单位（第 3 章），不自定刻度。
    3. 操作顺序与控制点：一端钉或刻固定直挡（基准爪）→ 尺身按指级刻线 → 滑爪贴工件后把边线压刻到尺身、读最近刻线 → 零位校准（两爪闭合时滑爪边应压在零线）→ 偏了在爪背垫薄木片校正 → 烧灼烫痕＋焦油点固定位 → 每周复校。控制点：零位未校不得使用；湿季加密复校。
    4. 经验参数与标定法：精度＝指宽刻线＋目估半指（约 5–8mm 级，经验值，须按本地条件标定）；零位每周复校、湿季加密；读数只作比较级（同大／差半指），不作绝对读数。
    5. 过程观察记录项：记 卡尺编号／尺身干湿状态／零位复校日与偏差（以半指为单位）／被量件编号与读数／与样板比对结果。
    6. 合格／返工／报废判据：合格＝零位在零线、同件两次读数一致；返工＝零位漂移，垫片重校后点固；报废＝尺身开裂或刻线磨平（干材重制，旧读数不得沿用）。
    7. 常见失败与排查顺序：①读数漂 → 先查零位（湿胀是第一因），再查爪面是否磨圆（须修平），最后查是否量在斜面处；②同件两次读数差半指以上 → 先查滑爪是否压紧（松手即退），再查刻线是否磨平；③零位总校不住 → 先查垫片是否过厚（垫薄木片，不是垫厚），再查爪背是否已压溃（换爪）；④与样板比对总差一档 → 先查刻线是否取自标准杆（自定刻度必差），再查量点是否一致。
    8. L1／L2／L3 证据：L1＝一把能读出"差半指"的卡尺＋零位复校记录；L2＝连续两月每周复校，读数用于孔径判定；L3＝第二人照本卡复校同一把卡尺，零位一致。

    柄的防震楔：敲入式楔锁在长期冲击下会退松，防松三法并用——①双楔十字：一楔顺纹、一楔横纹交错打入（涨力互相锁定）；②楔前蘸胶（焦油胶）填隙；③柄尾铁丝/绳缠箍一道压住楔口。每周检查：楔口见缝即复打（打前清缝中的泥沙，沙会碾碎木纤维）。

    【卡 09-02 防震楔双楔法】（八字段）

    1. 输入材料：硬木楔两枚（一顺纹、一横纹；7.5 规格：楔面角 8°–12°、顶端留 2–3mm 钝棱）；焦油胶；绳（或第 17–18 章后的铁丝）作柄尾缠箍。
    2. 所需工具：木槌（打楔）、刮刀（清缝）、角度板（校楔面角）、刻记具。校准来源：楔面角以角度板对照（45/60/90 三档硬基准＋近似档）；楔尺寸按 7.5 规格。
    3. 操作顺序与控制点：清缝（泥沙必清，沙会碾碎木纤维）→ 第一楔顺纹打入 → 第二楔横纹交错打入（涨力互相锁定）→ 楔前蘸胶填隙 → 柄尾缠箍一道压住楔口 → 每周检查。控制点：两楔必须一顺一横（同向打等于单楔）。
    4. 经验参数与标定法：楔面角 8°–12°（经验值，须按本地条件标定）；顶端钝棱 2–3mm；楔前蘸胶；柄尾缠箍一道；检查周期每周；干楔打入湿孔（孔干缩后抱死）。
    5. 过程观察记录项：记 工具编号／两楔方向（顺纹、横纹）／楔面角（角度板对照）／蘸胶与否／缠箍道数／每周检查时楔口缝隙（有无、宽窄目估）。
    6. 合格／返工／报废判据：合格＝两楔交错到位、楔口无缝、缠箍压住楔口；返工＝楔口见缝，清缝后复打（不许只敲紧不清理）；报废＝柄端楔口劈裂（木纤维已碎），换柄或柄改短。
    7. 常见失败与排查顺序：①楔用几天就退 → 先查是否只打了一枚楔（单楔必退），再查两楔是否同向（必须一顺一横）；②复打后仍退 → 先查缝中泥沙是否清净，再查楔是否蘸胶；③楔把柄端劈裂 → 先查楔面角是否出了 8°–12°，再查顶端钝棱是否已打毛；④柄尾缠箍松 → 按周检补缠（缠箍是压住楔口，不是装饰）。
    8. L1／L2／L3 证据：L1＝一件工具完成双楔十字＋蘸胶＋缠箍；L2＝每周检查记录连续在档、楔口无缝；L3＝第二人照本卡复打同一柄，两楔方向与楔面角一致、周检无缝。

    装柄标准流程（四重连接）：

    1. 开槽：烧凿法成槽线（6.5）→石凿剔深→刮刀修壁。槽宽=刃厚过盈0.5—1mm，槽深=刃高的2/3。
    2. 涂胶：焦油胶（8.5配方）温热态满涂刃槽结合面。
    3. 嵌刃：刃就位，对正力线——打击力方向必须通过刃口中点与柄轴（在台面上画线检验）。
    4. 绑扎：湿生皮条或筋腱（7.3）按十字编结缠槽口上下各5道；干后收缩自锁。
    5. 楔锁：槽口端面顺纹敲入硬木楔（7.5规格）涨死。
    6. 固化：静置24小时后交付。

    验收（三段递进）：空挥20次→轻砍木墩20次→正常使用1日。合格判据：绑扎位移<2mm；刃体不移位、无脱胶声响；胶缝无连续开裂。不合格回炉：加热软胶（焦油可热熔复粘）→重绑。

    工具解剖学要点：柄径3—3.5cm（掌规，标准件见9.4）；斧重心近头部，锛重心近刃；直纹柄，节疤不在受力面。装柄失败主因排序：力线偏＞胶层过厚＞绑扎不均＞槽过宽。

    【卡 09-01 四重连接装柄】（八字段）

    1. 输入材料：刃件（石斧／石锛／石刀／石凿／刮刀，规格见 9.1 表）；柄料（直纹硬木，柄径 3–3.5cm）；焦油胶（8.5 配方）；湿生皮条或筋腱（7.3）；硬木楔（7.5 规格）。
    2. 所需工具：烧凿与石凿（开槽）、刮刀（修壁）、木槌（打楔）、台面划线（对正力线）、角度板（校装柄角）。校准来源：槽宽过盈以刃厚为基准；装柄角按 9.1 表（斧刃线垂直柄轴、锛 60°–75°）用角度板对照。
    3. 操作顺序与控制点：①开槽（槽宽＝刃厚过盈 0.5–1mm、槽深＝刃高 2/3）→ ②涂胶（温热满涂刃槽结合面）→ ③嵌刃对正力线（打击力过刃口中点与柄轴，台面画线检验）→ ④绑扎（十字编结缠槽口上下各 5 道）→ ⑤楔锁（顺纹敲入硬木楔涨死）→ ⑥静置 24 小时。控制点：力线对正；胶层不可过厚。
    4. 经验参数与标定法：槽宽过盈 0.5–1mm；槽深＝刃高 2/3；绑扎上下各 5 道；静置 24h；三段验收＝空挥 20 次 → 轻砍木墩 20 次 → 正常使用 1 日；合格判据 绑扎位移 <2mm、刃体不移位、胶缝无连续开裂；柄径 3–3.5cm（掌规）。
    5. 过程观察记录项：记 工具编号／刃角与柄长（对照 9.1 表）／槽宽实测／胶层厚（目估）／绑扎道数／力线检验结果／静置时长／三段验收逐段结果。
    6. 合格／返工／报废判据：合格＝三段验收全过且绑扎位移 <2mm；返工＝胶缝开裂或绑扎松，加热软胶（焦油可热熔复粘）→ 重绑；报废＝柄身开裂或槽过宽无法补胶（柄改短另作他用，刃坯回收）。
    7. 常见失败与排查顺序（按正文主因排序）：①力线偏（脱柄与柄周断裂的第一因）→ 台面画线重对，打击力须过刃口中点与柄轴；②胶层过厚（胶把贴合面隔开）→ 加热刮薄重涂；③绑扎不均 → 按十字编结上下各 5 道重绑；④槽过宽（过盈超 0.5–1mm）→ 柄改短另作或换柄；⑤楔口见缝 → 清缝中泥沙后复打。
    8. L1／L2／L3 证据：L1＝一件四重连接复合石斧通过空挥＋轻砍；L2＝连续 3 把通过 9.1 全部验收；L3＝第二人照本卡独立装柄，三段验收全过且绑扎位移 <2mm。

    9.2 简易钻具、锯切和磨削工具¶

    砂磨钻孔（本章核心新工艺）：

    • 木料：弓钻（7.6）＋石钻尖，直接切削。2cm厚硬木5—15分钟/孔（经验值，需现场标定）。
    • 石料与骨料：切削不可行，改磨削——中空钻头（骨管、竹管）＋湿石英砂磨料：管钻压在工件上，弓钻驱动旋转，每转数圈加砂浆、每20—30秒提起清屑。穿1cm厚石片约需2—6小时（经验值，需现场标定）；孔成后工件背面出现环状凸台，轻敲即落，得到规整圆孔。
    • 钻头损耗入账：骨管每穿2—3孔换端，石英砂消耗按碗计。

    锯切两条路线：

    工具 制作 用途与效率
    弓锯 锯齿石片（5.5毛坯，齿距2—3mm）绑入弓形木框张紧 木料往复锯切：直径5cm木杆20—40分钟（经验值，需现场标定）；比石斧砍断面平整
    弦锯 绳＋湿石英砂 割石片、贝壳、骨料：绳带砂浆往复拉磨，速度慢但切口平直，可下料磨制石坯

    磨削平台与流程：

    1. 磨石分级：粗（划痕肉眼可见）——中（指甲可感）——细（无粒感）；粗中磨石固定在工作台挡块间（9.3）成"磨台"。
    2. 平面磨制流程：划线留量→粗磨去量→中磨成形→细砂撒板＋皮革抛光。
    3. 平度自检：两工件对磨面互检——涂炭粉对压，高点显黑；或对光看透光缝，缝宽<1mm合格（对照第3章基准直边）。
    4. 角度控制：以木角度板（45°/60°/90°）随磨随比。

    磨制一把完整石斧3—8小时（经验值，需现场标定）；磨制是慢工艺，产量靠分工（9.5）维持。

    【卡 09-04 磨台磨制与角度板对照】（八字段）

    1. 输入材料：磨石三档（粗：划痕肉眼可见；中：指甲可感；细：无粒感）；水与石英砂（细砂撒板）；皮革（抛光）；待磨石坯。
    2. 所需工具：挡块（把粗、中磨石夹在台面挡块间成"磨台"）、木角度板（45°/60°/90°，第 3 章自举）、炭粉（平度互检）、直边基准（第 3 章）。校准来源：角度靠角度板对合透光；平度靠两工件涂炭粉对压或对光看缝。
    3. 操作顺序与控制点：划线留量 → 粗磨去量 → 中磨成形 → 细砂撒板＋皮革抛光；每遍之间以角度板对照刃角。控制点：磨痕方向一致且与刃缘平行（角度未变的证据）；全程保持原刃角不变。
    4. 经验参数与标定法：平度判据 对光透光缝 <1mm；角度三档 45/60/90 为硬基准（近似档 ±2–3°）；磨制一把石斧 3–8 小时（经验值，须按本地条件标定）；刃角按 9.1 表（斧 60°–80°、锛 45°–60°、凿 30°–50°、刮刀 45°–70°）。
    5. 过程观察记录项：记 工件编号／所用磨石档／每遍后角度板对照结果／磨痕方向／透光缝宽／单件工时／磨石消耗深度。
    6. 合格／返工／报废判据：合格＝透光缝 <1mm、刃角与角度板一致、磨痕同向平行；返工＝刃角跑偏，回粗磨重开刃再逐遍对照；报废＝磨过头（刃体过薄或尺寸不足样板），降级作练料或改小件。
    7. 常见失败与排查顺序：①磨刃角度跑偏 → 先查有没有逐遍对角度板（无角度板对照是第一因），再查磨石面是否磨凹（挡块未夹牢），最后查手持是否偏摆；②磨面不平、透光缝忽大忽小 → 先查磨石面平度（两工件炭粉互检），再查挡块是否松动；③磨得慢、只见划痕不下肉 → 先查磨石档是否用错（粗磨须用粗档），再查是否忘了加水（粗砂岩须加水研磨）；④刃口崩口 → 先查磨向是否逆刃（须顺刃缘），再查下压力是否过大。
    8. L1／L2／L3 证据：L1＝一件磨制件附角度板对照与透光缝记录；L2＝三档磨石各完成一件、工时与消耗入账；L3＝第二人照本卡磨出同刃角件（角度板对合透光一致）。

    9.3 如何制造简易工作台与固定装置¶

    工作台：矮桩桌——台面厚板5—8cm（径劈板，7.2），高50—70cm坐姿/75—90cm站姿，四腿榫接（7.5）＋楔锁，腿间加横撑防晃。台面一条长边刨直，作为本工位的第一直线基准（第3章基准的实物延长）。台面钉入（打入孔中）挡木与挡钉位若干，作为刨削止点。

    固定装置谱系（夹持是重复精度的前提）：

    装置 结构 适用
    楔夹槽 台面开V槽，工件置槽中，两侧打楔 圆料、柄类削制
    绳勒夹 门形木框＋绳绕绞紧（绞杆插入绳圈拧紧，回弹自锁） 板材刨削——原始虎钳
    叉木夹 带叉树枝固定于台边或地锚 持圆件钻孔
    地锚＋踩踏 弯木桩斜钉入地，工件踏住 大件粗加工
    热焦油点粘 小件以热胶点粘于石板，加热脱开 小件钻孔、磨边（防手近钻位）

    划线与定位：台面基准边＋直角尺（第3章）完成十字划线；批量件用样板：合格件轮廓描于薄板成样板，新件对照加工，透光缝<1mm为合格——这是模板复制法（铁律二：精度有来源）在本阶段的实现。

    工位薄兽皮置：采光从侧向（正面光产生阴影误判）；磨台与钻位分开（砂浆与木屑互污）；体位：作业面近肘高，弓钻位留双人空间（7.6）。

    9.4 如何制造工具的工具¶

    自举原则：每种工具必须能由"其他已验证工具＋记录的工艺"重造；一旦某工具只能修复不能重造，体系即出现单点依赖（第1章三级定义）。

    工具母机雏形（三条自举线）：

    1. 弓钻＋台面叉夹＝旋转动力头：钻头可换（石尖切削/骨管磨削），是钻床原型。
    2. 磨石平台＋挡块＝平面加工原型：挡块定角度，磨出台面基准边，基准边再校验磨石——磨与量互为校正。
    3. 样板＋槽位＝复制模板：样板由合格件生成，新件照样板加工，实现"复制一个尺寸"（铁律二）。

    标准件（互换性的第一步）：

    标准件 统一规格 用途
    柄径 3—3.5cm（掌规） 任何工具柄互换握感
    斧柄长 75cm 备件互换
    钻杆 25×2.2cm 弓钻、管钻通用
    绳径档 3/6/10mm 绑扎与吊装分级

    维修体系（每件工具登记）：

    故障 处置 工序来源
    刃钝 重磨，角度不变 7.8
    小崩刃（<3mm） 压剥重修 5.5
    大崩刃 刃坯回收重打 5.5
    绑扎松 按标准绑扎图重绑 7.4
    胶开 热熔复粘（焦油特性） 8.5

    备件库存（经验值，按周消耗标定）：石片刀≥5、石钻尖≥3、骨管钻头≥2、绳卷≥20m、焦油胶≥2团、生皮条≥10根、磨石粗细各1备件。库存低于下限即触发补造，不等用尽。

    9.5 从单人手工到多人协作¶

    工序分解示例（制斧，7工位）：采石→粗打→精修→磨制→开柄槽→装柄（胶＋绑＋楔）→检验。单人全流程1—2天/件；流水线3—5人日产数件（经验值，需现场标定，以本队实测回填台账）。

    双人操作规范：

    • 大件打制：一人扶核（木夹＋侧站位）、一人打击；扶者位于击打者侧后45°。
    • 弓钻深孔：一人压帽定向、一人拉弓供力。
    • 搬运：统一号令（"起—走—落"），长料前喊后应。

    质量责任制度：

    • 每件工具刻工号（8.4颜料标记）→可追溯、可返修。
    • 检验员独立于制作者，按9.1验收表执行并签字（刻符）。
    • 返修率入账：某工位返修率连续超20%（经验判据）即回炉培训。

    师徒传递（信息谱系落地）：

    1. 工序口诀化：每道关键工序压缩为口诀（选—打—修—磨—胶—绑—楔）。
    2. 示范＋复现：徒弟独立做3件，全部通过9.1验收方可出师（L3人员判据）。
    3. 档案复现考核：定期抽一人按8.7记录复现指定工艺，偏差超限即修订记录。

    安全协作铁规：打制飞溅区3m禁入；挥击工具（斧、锤）作业前背后喊令；弓钻弦区禁伸手；磨台砂浆及时清理防滑。

    【卡 09-05 七工位流水排薄兽皮】（八字段）

    1. 输入材料：毛坯（石料、骨料按 9.7 料架三分）；各工位耗材（焦油胶、生皮条、筋束、石英砂）；档卡（9.10 一器一卡）。
    2. 所需工具：各工位套件（打制：硬锤、软锤、压剥器；磨制：磨台；开槽：烧凿与石凿；装柄：胶、楔、绑料；检验：样板、角度板、木卡尺）。校准来源：检验工装即 9.4 标准件，判据即 9.8 三级制。
    3. 操作顺序与控制点：按 采石 → 粗打 → 精修 → 磨制 → 开柄槽 → 装柄（胶＋绑＋楔）→ 检验 七工位排开 → 每件随档卡走 → 检验员独立于制作者、按 9.1 验收表签字（刻符）。控制点：检验员不得兼制作；每件刻工号。
    4. 经验参数与标定法：单人全流程 1–2 天/件；流水线 3–5 人日产数件（经验值，须按本地条件标定，以本队实测回填台账）；返修率连续超 20%（经验判据）即回炉培训；出师判据＝独立做 3 件、全部过 9.1 验收。
    5. 过程观察记录项：记 工位号／操作人工号／每件过站时刻／各站返修原因／日产量／返修率／料批号。
    6. 合格／返工／报废判据：合格＝每件过七站、9.1 三段验收全过、档卡字段齐；返工＝某站返修率超 20%，该工位停线培训后复排；报废＝档卡缺失或工号不可追溯（不可交付，退回首站补刻）。
    7. 常见失败与排查顺序：①产量上不去 → 先查瓶颈站（过站时刻最长者），再查该站是否一人兼两站（双人操作规范：大件打制、弓钻深孔、搬运各有分工）；②返修集中在一站 → 先查工号（集中即该工位复查），再查料批是否集中（料源问题），最后查规格本身是否不适配（回修订 9.1 表）；③件与卡对不上 → 先查是否过站未签字，再查工号是否被磨掉；④交叉作业伤人 → 先查动线是否穿行钻位弦区（9.7 的"6"字回转），再查挥击前是否喊令。
    8. L1／L2／L3 证据：L1＝一件按七工位走完全程并留档卡；L2＝连续 3 件过 9.1 全部验收、返修率入账；L3＝两名以上出师（各 3 件过验收）＋返修率与日产数据用于排产。

    工具定置管理（影绘板）：工具箱盖内侧或工位墙上挂一块薄木板，把每件工具按存放位摆好后沿轮廓描影（炭笔），工具归位必须影内入位。三重收益：缺件一眼可见（影空即缺，不必翻账）；错型归位立刻暴露（圆头进不了方影）；新人无需记忆即知每件工具的家。规则：影绘板随周检每周核对一次，影与物不符按缺件登记；工具借走须在影位压木牌（刻借用人工号）。这是"定置"制度的雏形——后文机床工位"工具到位即工作到位"的祖先。

    9.8 石器精磨细工¶

    9.2 给了磨削框架，本节把三项精工序的判据补到第三档。

    砂管钻孔的孔径与垂直度判据：

    • 孔径控制：管外径即孔径下限——管外裹砂层转动，成孔比管径大 0.5—1mm（经验值，现场标定：同管钻三孔，木卡尺量径取均值，把"管径＋增量"誊入台账）。要孔径 d，选外径约 d−1mm 的管。
    • 垂直度判据：钻透后插试棒（9.4 标准钻杆料削的细木棒，径=孔径−1mm），棒在孔口两侧摆动量差<1mm 视为垂直（经验判据）；或工件底面预先画十字线，透光看孔圆心与十字交点偏移，偏移<1mm 合格——这是 L2 验收"孔位偏差<2mm"的工位级内控（比终验更严，留余量）。
    • 防偏三法：①起钻面先以石尖轻凿定位窝（深 1—2mm）；②压帽者只施垂直压力、不加侧向力（双人分工，9.5）；③每穿 5 分钟停机对一次划线——孔浅期发现偏斜，可把孔磨成椭圆再收圆纠正；钻过半厚再发现只能报废或改做小件。
    • 砂浆：砂与水体积比约 2:1（稠糊挂壁不流淌）；砂双筛——粗筛级（粒≤1mm）开孔、细筛级（粒≤0.3mm）收光，透前换细砂。

    开槽（槽宽渐进法）：石坯上磨槽（绑扎槽、柄槽、装饰槽）不得一次磨到全深，三遍渐进：

    1. 第一遍：槽宽磨到全宽 1/2、深到全深 1/3；用与槽同宽的木条涂炭粉压印槽底，炭粉点均匀即底平直。
    2. 第二遍：加宽到 3/4、加深到 2/3；槽规（同宽硬木条＋两侧刻线）量宽。
    3. 第三遍：到尺寸，槽壁走细磨石收光。

    理由：一次磨满宽，槽壁没有退路——磨过头无法补。每遍之间必检，检查件即上文木条与槽规（第 3 章自制量具法）。

    抛光（三级磨料＋皮条）：

    1. 粗级：湿石英砂（细筛级）蘸水画圈磨，去尽中磨划痕——判据：侧光看无定向划痕。
    2. 中级：沉积细泥（河湾静水底细泥，捻之滑腻无砂感）加水抛——判据：斜 45° 对光见连续反光带。
    3. 精级：干皮条（生皮条 7.3 裁 10cm 段）蘸兽脂快速擦拉——判据：皮条擦过不留痕、指腹划过无阻涩。

    封顶判据：抛光面能照出手指轮廓的模糊影即停。再抛收益趋零而工时翻倍，是高成本低回报工序——按用途分级抛（刃件精级、器身中级、毛坯件不抛），不为抛而抛。

    石器成品分级（三级制）：每件完工即定级，级号刻在柄尾（8.4 颜料标记）：

    级 判据 用途
    一级（正式） 全部尺寸过样板（透光缝<1mm）、刃口无可见崩口、装柄过 9.1 三段验收 交付使用
    二级（备用） 尺寸偏差 1—2mm，或刃口<1mm 浅崩但不影响受力 入备件盒，一级退役时顶替
    三级（练料） 中途失手件：崩口>2mm、槽偏、孔斜 只作教学与手感练件，禁入台账工具序列

    升降级规则：二级经重磨复检达一级判据可升级入役；一级使用中损伤按 9.4 维修表处理，处理后复检定级。禁三级件混入二级盒——练料混入库是"备件不可靠"的头号来源。

    9.9 骨角器工坊¶

    骨与角是本阶段唯一的韧性材料——石会崩、木会裂，骨可弯、可磨、可钻，是针、锥、钩、柄的独占来源，值得单设一坊（工位薄兽皮置按 9.7 四区制，料架"骨"区即其库）。

    骨料蒸煮脱脂：鲜骨含脂，直接加工发腥发滑，且胶合面永远粘不牢（脂隔胶，8.5 焦油胶对油面无附着力）。

    1. 锯短段（下法）入陶釜（第 8 章）或挖坑镶石板锅，加水没骨，水沸后保持微沸 2—3 小时（经验值，现场标定：捞出骨段以指腹压断面——压出油光则再煮 1 小时，压出涩感即成）。
    2. 中途换水一次（沸后 1 小时时点），防油脂回裹骨面。
    3. 捞出阴干 3—5 天（经验值，判据：敲击声由闷转脆）——火烤速干必翘裂，禁。
    4. 脱脂终判：断面无油光；水浸 15 分钟水面无油膜。脱脂质量直接决定后续胶合与绑扎寿命，入料批号随档卡走（9.10）。

    锯割（石刀划槽＋折断）：骨料下料不用弦锯整切（慢且抖），用"应力断料"：

    1. 石片刀（刃角 20°—40°，9.1 表）在断位环划一圈深槽，深达骨壁厚的 1/3—1/2（经验起点，见练习法）。
    2. 槽内垫双筛细砂加快划切（9.2 砂浆原理的干用版）。
    3. 两端架空、槽线对准台边棱，木锤背轻击骨身或按压——沿槽整齐断开。

    判据：断面沿槽走（偏了说明槽深不均）；断口斜裂入骨身>5mm 该段降三级。◎手感："轻击"的分寸最难文字化——练习法：废骨段 10 根，从 1/4 壁厚深划起逐根加深，逐根记断口质量于练料账，找出本队常用料源的临界槽深（多数兽骨落在壁厚 2/5—1/2 之间，经验区间）；误判代偿：宁可划深、不可敲重——划深损失几分钟，敲重损失整段料。

    磨尖磨刃（骨针/锥/鱼钩规格表）：

    器物 规格 磨法 合格判据
    骨针 长 6—8cm、径 1.5—2mm、孔径 0.8—1mm（经验值） 磨台细级往复磨尖；针孔以细骨管旋磨（9.2 管钻缩版，双面各半钻防崩） 孔缘无裂；针尖过薄兽皮不劈线
    锥 长 10—15cm、锥段 3—4cm 粗磨成形、细磨开刃、四面收尖 硬木试扎，入木 2mm 不折
    鱼钩 弯钩内径 5—8mm、倒刺长 2—3mm 骨片裁坯（划槽折断）→磨弯面→磨倒刺→磨锐尖端 挂重（约目标鱼 1 倍体重的石块）静吊 10 秒，不脱形不回直
    刮刃 骨片长 8—12cm、刃角 45° 单面磨刃 刮皮试件不起卷、不留划沟

    骨针是本坊难度上限件：熟手日产 5—10 支、合格率约五成（经验值，需现场标定后入台账）——排产按实测产能估，不按"想要多少"排（9.5）。

    鹿角工具（柄材与锤面）：

    • 柄材：鹿角主枝直段（长≥15cm、径 2.5—3.5cm）天然成柄，角根膨大处即握把——省去开槽装柄工序；刃件钻孔后以细骨销蘸胶（8.5）固定，用于小刀、锥、刮刀。判据：主枝无纵向裂纹，断面致密无蜂窝。
    • 锤面：角基部横截段（厚 4—6cm）作软锤，专用于打制压削（5.5）与装柄楔紧——它硬度低于石，打石不崩石刃。锤面磨平（9.8 抛光粗级即可）后归入夹持/打击类台账。
    • 热弯：鹿角热水烫软可弯出钩形与曲柄（大鱼钩、曲柄钻把手），弯后绳绑定形、阴干 3 日定型（经验值）。

    9.10 工具寿命台账详规¶

    9.4 给了维修表，9.6 给了盘点字段，本节把"一件工具的一生"补成闭环——台账不是记录癖，是补造计划与工艺复查的唯一数据来源。

    每件一档（档案卡）：工具入役即立档，一器一卡（木牍，挂影绘板对应影位旁）：

    字段 记什么 例
    编号/名称 台账编号（第 8 章制度）＋器名 T-041 石斧
    制日/料批 制造日期＋料批号（石料/骨料批号） 秋3日／石批B-7
    定级 9.8 三级（入役与每次变动均记） 一级
    修磨次数 每次重磨/重绑/复粘计一次并记日 第3次，冬1
    损伤记录 症状＋当场判断的原因（对照失败模式表填行） 崩刃2mm／湿料过韧
    状态 在用/备件/待修/退役 在用
    退役 日期＋原因（五选一：磨尽/崩毁/脱柄不可复粘/断/丢失） ——

    记录纪律：修磨不记，寿命曲线即断，补造计划会系统性低估；卡与物同在；退役卡按月捆扎归档盒，不许销毁。

    月度损耗汇总→补造计划：每月末日各工位交档卡副本，汇总成月度损耗表：

    汇总项 来源 用途
    各类退役数/在役数 档卡退役栏 得月损耗率＝退役数÷月初在役数
    高损耗件排名 退役原因归类 定补造优先级、修订 9.4 备件下限
    料批关联 档卡料批号 某料批损耗异常→料源问题（触发线）

    补造计划三行式：本月退役 N 件→下月补 N 件（同规格）→若 N 使库存低于 9.4 下限，则按"下限−现有"补足，两者取大。补造件计入 9.5 流水排产，不走"有空再做"。

    高损耗工具的工艺复查触发线：某型工具月损耗率超过在役数的 1/3（经验触发线，运行 3 个月后按实测修订），即触发工艺复查——不是简单多做几把：

    1. 查料：退役件料批是否集中——集中即换料源或改选料判据；
    2. 查工：退役件刻工号是否集中——集中即该工位返修流程复查（对接 9.5 返修率>20% 条款）；
    3. 查规：损耗均匀→规格本身不适配工位，回修订 9.1 规格表。

    复查结论记入台账附页；触发而不查视同台账制度失效——数据造出来不用，比没有数据更坏。

    【卡 09-06 砂管钻孔**】（八字段）

    1. 输入材料：骨管（外径=目标孔径−1mm、壁厚≥2mm）；石英砂双筛级（≤1mm 开孔、≤0.3mm 收光）；水。替代：竹管代骨管（磨耗快约一倍，孔径同法标定）。
    2. 所需工具：弓钻（7.6，弦张力判据：拨弦声清脆）；压帽木块；砂浆碗；试棒（细木棒，径=孔径−1mm）。校准：空转试转，管端画圈≤1mm 为同心。
    3. 操作顺序：①定位窝（石尖凿深 1—2mm）→②入粗砂浆、弓速中速→③每 20—30 秒提管清屑→④每 5 分钟对划线核偏→⑤钻透前换细砂浆→⑥透后翻面轻敲落芯。控制点：加力只许垂直（压帽者职责，9.5）。
    4. 经验参数与标定法：穿 1cm 石片 2—6 小时；砂浆砂水体积比 2:1。标定：同料三孔计时取中值入台账；砂浆稠度以挂壁不流淌为判。
    5. 过程观察记录项：提管屑色（白=石屑正常；色深=触及下层异料）；孔壁温热＝砂已钝（立即换砂）；偏斜量（对线目测）——记入档卡损伤栏。
    6. 合格/返工/报废：孔径=管径+0.5—1mm、垂直偏移<1mm 合格；孔浅期偏斜可磨椭圆收圆＝返工；过半厚偏斜或孔口崩裂>2mm＝报废改小件。
    7. 常见失败与排查顺序：不进尺→先查砂钝（换砂）→再查管端磨损（重磨管端）→后查转速不足（紧弦）。孔偏→先查定位窝深浅→再查压帽侧向力→后查料面倾斜（垫平重夹）。
    8. L1/L2/L3 证据：L1 留首孔工件；L2 留三孔标定记录＋孔径卡尺数据；L3 留月度孔件台账＋砂耗记录（碗/孔）。

    【卡 09-07 骨针磨制**】（八字段）

    1. 输入材料：脱脂骨片（9.9 蒸煮后，厚 1.5—2.5mm、长≥8cm）。替代：硬木削针（不耐穿，只作练手）。
    2. 所需工具：磨台细级磨石；皮条（精磨）；细骨管（钻孔用）；兽脂。校准：磨石面平度以 9.2 对磨法每周检。
    3. 操作顺序：①裁坯（划槽折断法）→②粗级磨出针身锥度→③细级磨尖，边磨边在指腹滚查圆度→④针尾段磨扁磨薄→⑤管钻旋磨针孔（双面各半，防单面崩）→⑥皮条蘸脂精磨全针。控制点：孔位在针尾 1/4 段内、居中。
    4. 经验参数与标定法：针径 1.5—2mm、孔径 0.8—1mm、熟手日产 5—10 支。标定：首批 20 支记合格数定个人产能；孔径以细刺试插定。
    5. 过程观察记录项：磨尖时"吱"声变尖即近成（薄处共振）；针孔周缘白痕为裂纹前兆——记练料账。
    6. 合格/返工/报废：孔缘无裂、针身直（平面滚不跳）、尖过薄兽皮不劈线＝合格；孔裂未透＝磨去重钻（针变短）＝返工；断、孔崩、身弯＝报废入练料盒。
    7. 常见失败与排查顺序：孔位裂→先查单面钻（改双面各半）→再查管径过大→后查骨片未脱脂（回 9.9 重煮）。针尖劈→先查磨石粒度偏粗→再查磨向（须顺骨的长轴磨）。
    8. L1/L2/L3 证据：L1 留首支合格针；L2 留 20 支批次合格率记录；L3 留月产账＋失针原因分类（作为排产与选料依据）。

    • 磨台湿砂作业防滑；磨石裂（受撞击）立即报废更换。
    • 热焦油点粘脱件用木夹，徒手禁触胶点。
    • 工具箱内刃具一律刃口向内码放；运输中刃具包裹（草束＋绳缠）。
    • 任何挥击类工具未经9.1三段验收不得交付他人使用。

    验收标准¶

    • L1 原理验证：完成一件四重连接复合石斧并通过空挥＋轻砍测试；一次砂磨穿孔（骨或石）。
    • L2 可重复制造：连续3把复合斧通过9.1全部验收；弓锯、弦锯、磨台、绳勒夹全部建成并各完成一次正式作业；砂磨孔位偏差（十字线）<2mm；样板复制件透光缝<1mm。
    • L3 可持续生产：标准工位工具箱齐备并台账在册；备件库存不低于下限制度执行≥1个月；维修记录连续；两名以上成员出师（连续3件过验收）；返修率与日产数据入账并用于排产。
