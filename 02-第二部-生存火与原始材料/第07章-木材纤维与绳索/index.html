    第7章 木材、纤维与绳索¶

    第二部·生存、火与原始材料。起点A标准继续有效：只使用第1—6章已建立的能力（石器、火、测量）。本章产出第一代木工工具、绳索与机械连接，为一切木结构、搬运与后续机械传动供基础。

    本章目标¶

    • 建立木材评价—干燥—劈分成形的完整工艺；建立植物与动物纤维的采集处理工艺；建立反向捻合制绳工艺并完成静载与冲击标定。
    • 产出物：合格木料储备、三档绳径的绳索、弓钻全套（第一台可复用旋转工具）、石锛/石斧复合柄、楔与榫连接的规范、杠杆/滚杠/三脚架搬运装置。
    • 本章是测量谱系（谱系四）上第一次"工具自举"：弓钻的旋转能力将在第9章工装化为钻床原型。

    最低前置条件¶

    项 要求 来源
    工具 石片刀、刮削器、尖状器、手斧、硬锤、软锤、压剥器 第5章
    热源 稳定火堆、炭床、封火（烧槽、火矫直、干燥） 第6章
    测量 长度、角度板、线坠、记录 第3章
    材料 立木与倒木、树皮、草类、兽皮与筋腱 第2章资源地图

    7.1 如何辨别适合加工的木材¶

    硬度现场三级判据（不依赖任何金属工具）：

    1. 指甲掐边材：深痕且缓慢回弹=软木；几乎无痕=硬木。
    2. 石片刀横切刻划：切面光滑、切屑成片=细密好料；切面毛糙、撕裂=粗纹或斜纹。
    3. 同尺寸掂重与敲声：沉、声清脆=致密；轻、声闷=疏松或多孔。

    结构四查：纹理通直（顺干看纹线不扭）；节疤少且活（死节周围有黑环、易脱落）；无裂纹（特别是端面放射裂）；无虫眼（孔洞与粉末并存者弃）。

    含水状态：新伐材湿重；表面起细裂纹、重量明显变轻=已进入气干状态。

    按用途选材表：

    用途 首选 理由
    工具柄、杠杆 栎、槐、榆类硬木 硬而韧、抗弯
    弓钻板/杆 柳、杨、椴 软质、摩擦粉尘细、易成孔
    楔子 柞木直纹、山楂 顺纹抗压、不崩
    容器（凿挖） 软木整段 烧掏容易
    引火柴/炭 见6.2 —

    树皮外观登记入资源地图（第2章）：每处林地记录树种、径级、数量、距离。砍伐规则：优先取倒木与枯立木；活树采伐在形成层活动期（皮易剥）进行，只砍不环剥。

    7.2 木料的干燥、劈分和成形¶

    干燥：生材含水率约30%—60%（经验值，需现场标定），使用目标：气干至12%—18%（经验值，需现场标定）。

    规程：

    1. 剥皮（防虫蛀边材）。
    2. 端面封浆：湿泥或树皮包裹端头——木材端面蒸发最快，不封则端裂。
    3. 垫高架空、堆放留缝、阴凉通风处气干；避免暴晒（表里收缩差导致开裂）。
    4. 厚板气干时间按"每2.5cm厚约1年"估算（经验值，干燥气候，需现场标定）；小截面工具柄约1—2个月可用（经验值）。

    劈分：顺纹劈是木加工效率最高的方式——裂纹自动追踪木纹，不需切削力。

    流程：端面观察纹线走向→手斧或硬锤＋石楔对准端面纹理线敲入→裂纹起后依次跟进第二、第三枚楔，沿裂线向下推进→成板。扭转纹料劈不出直板，只能整段用。

    径劈面（过髓心）板材尺寸稳定性优于弦劈面：弦向收缩约为径向的1.5—2倍（经验值，需现场标定），故台面、滑道用径劈板。

    成形：手斧粗砍（自远端向身体方向削，逆纹砍必撕裂）→石锛（见7.8）细削→刮刀刮光→火矫直（弯曲段浇水后近火烘烤至烫手， 加压保形冷却）。

    防裂管理：大件先粗成形再干燥（粗坯裂了损失小）；孔与槽开在干燥之后；厚薄过渡区厚薄比≤2:1。

    7.3 树皮、藤蔓、草纤维和动物纤维¶

    植物纤维表：

    来源 采集 处理 特性
    椴树、构树内皮 春夏形成层活跃期环割剥取（割口每树只取30cm段，不整环剥） 沤浸7—14天（经验值，水温高则缩短）→木槌捶软→水中梳洗出纤维束 长而强，绳索主力
    荨麻茎 秋季割取 晾至脆折→压碎外皮→抽出内芯纤维 强度高，但采集刺手
    茅草、莎草、香蒲叶 干季割取 捶软→梳直成束 快速粗绳、编织
    鲜树皮条 随取 即用 干后发脆，仅临时捆扎
    藤蔓 活体采集 浸软、去节瘤 整条绑扎，弹性好

    动物纤维：

    • 兽筋（后腿腱、背筋）：晾至半干撕成束。湿缠干缩——绑扎石刃后干燥自锁，是装柄第一绑料（9.1）。
    • 生皮条：皮张螺旋切剥成条，湿绑干缩同上。
    • 马尾毛、绒毛：编结与缝线辅助。

    选用判据：纤维长≥10cm为优；手感拉测——取单束反复拉20次不断；无霉斑黑点。储备：干燥悬挂存放，使用前水润恢复柔性。

    7.4 捻绳、编织与基本连接结构¶

    反向捻合的力学原理：单股加捻后，股内纤维靠摩擦与螺旋几何抱合；但单股有退捻趋势，一端松手即散。解决办法是反向合股：两股各自Z向加捻，再把两股以S向相互搓合。股的退捻趋势恰好被合股的缠绕所抵消——整体处于扭转平衡，绳不上劲、不松散。这是绳索可用而"拧一下的草绳"不可用的根本区别。

    沤制时间—水温对照：脱胶是微生物消化果胶，水温每高约一档（"温热"对"凉"），时间约减半（经验值，需现场标定）：

    水温档（第3章锚点） 沤期（经验起点） 中途判据
    凉（<15 ℃） 14–20 日 第 7 日抽验：外皮与木质芯可分离否
    不冷不热（15–25 ℃） 7–14 日 隔日抽验
    温热（25–30 ℃） 4–8 日 每日抽验——过沤纤维发脆（拉之即断如纸）

    纤维湿强对比：

    纤维 干强 湿强 备注
    椴/构内皮 高 更高 绳索主力：湿用反而变强
    荨麻 高 高 细绳与缝线
    干草茎 中 骤降 只作干态捆扎与燃料
    兽筋腱 高 中 湿后回软，接缝专用（7.3）

    【卡 07-01 沤制脱胶】（八字段）

    1. 输入材料：椴树或构树内皮（春夏形成层活跃期环割剥取，割口每树只取 30cm 段，不整环剥）；沤浸水体。
    2. 所需工具：木槌（捶软）、清水（梳洗）、温度锚点卡（判水温档）、记录板。校准来源：水温只用第 3 章手感档（凉／不冷不热／温热），不测温；时间以日为锚。
    3. 操作顺序与控制点：剥皮（每树 30cm 段）→ 入水沤浸 → 按水温档定沤期 → 中途抽验（外皮与木质芯可分离否）→ 木槌捶软 → 水中梳洗出纤维束 → 悬挂干存。控制点：宁可早取，不可过沤——过沤纤维拉之即断如纸。
    4. 经验参数与标定法：凉（<15 ℃）14–20 日、第 7 日抽验；不冷不热（15–25 ℃）7–14 日、隔日抽验；温热（25–30 ℃）4–8 日、每日抽验；水温每高约一档，时间约减半（经验值，须按本地条件标定）。判据：外皮与木质芯可分离、纤维反复拉 20 次不断。
    5. 过程观察记录项：记 树种／剥取日／水温档／沤期起止／抽验日与结果（可否分离、手感、气味）／纤维湿强（湿用是否反而变强）。
    6. 合格／返工／报废判据：合格＝纤维可梳散成束、拉 20 次不断；返工＝分离不净，延长沤期并每日抽验；报废＝过沤（拉之即断如纸），整批弃。
    7. 常见失败与排查顺序：①纤维沤烂成絮 → 先查是否按最高水温档排期（温热档须每日抽验），弃该批并缩短下批沤期；②外皮剥不下来 → 不在形成层活跃期，改季再采；③纤维发脆一折即断 → 先查过沤，再查是否晒干过快（干存须悬挂阴干）；④湿用强度骤降 → 用错了纤维（干草茎湿强骤降），换椴／构内皮。
    8. L1／L2／L3 证据：L1＝一批沤制并梳洗成束；L2＝两个水温档各一批，沤期与抽验记录能对上；L3＝第二人照本卡独立沤一批，出纤维率与强度手感一致。

    制绳工艺：

    1. 取两束等粗纤维（束径决定成品绳径的一半）。
    2. 右手把每股向同一方向搓紧（Z捻），左手随搓随把两股反向绕在一起（S合）。
    3. 膝上或大腿上搓制最省力；双人配合：一人供料续接，一人搓合。
    4. 续接：两股的续头错开≥10cm，搭接处搓入股内，接头不粗于绳身。
    5. 收尾：端头回编三扣或用细绳缠死。

    【卡 07-02 反向捻合制绳】（八字段）

    1. 输入材料：两束等粗韧皮纤维（束径决定成品绳径的一半）；细绳（收尾缠死用）。
    2. 所需工具：徒手（膝上或大腿上搓制）；割绳用石片刀；已知重量石块与水袋（供 07-03 标定）。校准来源：绳径按标准杆分单位估读；载荷分级只用已知重量物。
    3. 操作顺序与控制点：取两束等粗纤维 → 每股各自向同一方向搓紧（Z 捻）→ 两手同步把两股反向绕合（S 合）→ 续接时两股续头错开 ≥10cm 搓入股内 → 端头回编三扣或细绳缠死。控制点：单股 Z、合股 S，全队统一（方向反了绳必打扭）。
    4. 经验参数与标定法：束径＝成品绳径之半；续接搭头 ≥10cm 错开、接头不粗于绳身；收尾回编三扣；绳径档 3/6/10/16mm，静载断裂力 30–60／80–150／200–350／500–800kgf（经验值，须按本地条件标定）。
    5. 过程观察记录项：记 纤维种／批号／束径／捻向（Z/S）／绳径／续接位置／操作人。
    6. 合格／返工／报废判据：合格＝绳身不上劲、不回扭、端头不散、接头不粗于绳身；返工＝绳打扭起圈（合股方向反了），拆开重合（S/Z 互换）；报废＝纤维过沤发脆（拉之即断），整批换料。
    7. 常见失败与排查顺序：①绳不上劲、一松手即散 → 先查捻度是否不足，再查两股是否粗细不均（配粗细）；②绳打扭起圈 → 合股方向反了，拆开 S/Z 互换重搓；③断口总在接头 → 先查搭头是否短于 10cm，再查两股续头是否同位（必须错开）；④湿后强度骤降 → 用了干草茎类纤维，换韧皮纤维。
    8. L1／L2／L3 证据：L1＝一段不上劲、不散头的绳；L2＝三档绳径各制 10m 并入档；L3＝两人以上能独立按档制绳，绳径与捻向一致。

    绳径—断裂载荷对照表（经验值，需现场标定；以椴皮/荨麻三股绳为基准）：

    绳径 静载断裂力（数量级） 用途
    3mm 30—60kgf 绑扎、缝线、弓钻弦（4—6mm更稳）
    6mm 80—150kgf 工具装柄、一般吊挂
    10mm 200—350kgf 搬运捆扎、三脚架
    16mm 500—800kgf 承重吊装（配滑组）

    标定方法（每批必做）：

    • 静载测试：绳悬吊，分级加载（已知重量的石块/水袋），每级保持1分钟，记录断裂级。断裂值除以5为该批绳使用载荷上限；吊人场合除以10。
    • 冲击测试：取断裂静载一半的重物，从1m高自由落体冲击张紧绳，10次不断为合格吊索。

    【卡 07-03 静载分级与标定】（八字段）

    1. 输入材料：待标定绳（整批取样）；已知重量石块或水袋（分级载荷）；固定吊点（横梁或树杈）与绳套。
    2. 所需工具：吊挂绳、水袋与石组（逐级配重）、木卡尺或标准杆（量绳径）、记录板。校准来源：载荷以已知重量的石／水袋为准（第 3 章衡重），不凭目估。
    3. 操作顺序与控制点：绳悬吊 → 分级加载 → 每级保持 1 分钟 → 记断裂级 → 除以安全系数得该批使用载荷 → 冲击测试（半断裂值、1m 自由落体、10 次）。控制点：每级必须保载 1 分钟（快加会误判）；吊人场合另按 ÷10 计。
    4. 经验参数与标定法：安全系数——工作载荷＝断裂值÷5，吊人 ÷10；冲击测试取断裂静载一半、1m 高、10 次不断为合格吊索；分级步长按绳径档经验断裂量级 30–60／80–150／200–350／500–800kgf，须现场实测覆盖。
    5. 过程观察记录项：记 批号／绳径／每级载荷与保载结果／断裂级／断裂位置（绳身、接头、结眼）／冲击次数与结果／标定人与日期。
    6. 合格／返工／报废判据：合格＝断裂级不低于该绳径档经验量级且冲击 10 次不断；返工＝断在接头，加长搭头错位重接后再标；报废＝同批试样断裂级相差悬殊（批内不均，整批不作承重用）。
    7. 常见失败与排查顺序：①同批断裂级忽高忽低 → 先查试样是否取自同一续接段，再查纤维批是否混料；②断裂总在结眼 → 先查该处结是否过了承重结三查，再查绳面是否起毛（起毛者降载 50%）；③加载中明显伸长不回弹 → 湿绳或过捻，晾干复测；④一次冲击即断 → 先查冲击重是否超了半断裂值，再查绳是否湿过又干（强度已损）。
    8. L1／L2／L3 证据：L1＝一批绳的分级加载记录；L2＝三档绳径各一份标定表并注明工作载荷；L3＝标定表用于实际吊装，每批绳有使用载荷上限记录，超限即拒用。

    基本绳结（功能导向）：

    结 功能 要点
    平结 等粗两绳连接 两头同步受力不滑
    接绳结 粗细两绳连接 细绳绕粗绳锁紧
    称人结 固定圈套，不滑不咬 受力后仍可解开
    双套结 快速绑扎杆件 越拉越紧，可单手
    十字编结 两杆交叉绑扎（脚手架、工具柄） 横—竖—横—竖各3道后加勒紧圈收死

    编织（平编、绞编）制席与篮，是第10章储粮容器过渡方案。

    7.5 木楔、榫接和机械连接¶

    木楔：

    • 料：硬木直纹（柞木、山楂），纹理平行于受力方向。
    • 楔面角8°—12°：太陡受震弹出，太缓把工件劈裂（经验值，需现场标定）。
    • 顶端留2—3mm钝棱，防止打入时打毛。
    • 干楔打入湿孔：孔干燥收缩后抱死楔体，越用越紧。

    榫接（无凿时代工艺）：

    • 榫眼制作两法：烧凿法——炭火局部烧透→石片刮去炭层→反复至深；钻扩法——弓钻（7.6）沿眼线连续排孔→打通→刮削修壁（第9章工装化后效率倍增）。
    • 规格：榫头宽＝柄宽的1/3—1/2，榫长为宽的2—3倍；湿榫眼配干榫头，过盈0.5—1mm（经验值，需现场标定），榫头穿出后打横纹楔涨死（穿楔锁紧）。
    • 防裂三则：孔位距木端≥孔径2倍；劈裂敏感方向不开孔；大孔先烧小孔再逐步扩。

    连接谱系（强度与可逆性）：

    级别 连接 特性
    1 绑扎（绳） 快、可拆、需定期重绑
    2 楔＋绑 半永久
    3 榫＋穿楔 永久、承弯
    4 焦油胶＋楔＋绑 最牢，依赖8.5

    验收：连接件加工作载荷1.5倍的静载并保载1分钟，位移<2mm、无开裂异响为合格（工作载荷按用途记录）。

    钻杆（取火用） 直径2—2.5cm软木，端圆头 见6.3
    火板 见6.3 —
    轴承帽 硬木块或带凹石块，凹内涂兽脂减阻 第5章工具加工

    钻孔工艺：

    • 木料：划十字定孔位（第3章基准）→钻尖定位浅窝→匀压慢转→每20—30秒提钻退屑。2cm厚硬木成孔约5—15分钟（经验值，需现场标定）。
    • 深孔防偏：从两面分头对钻，交汇偏差以角度板校正。
    • 骨、石料：换中空骨管/竹管钻头＋湿石英砂磨料——磨削而非切削，详见9.2。

    取火复用：换软木杆与火板即成6.3的弓钻升级版，成功率与效率数倍于手钻（经验值）。

    维护：弦松即重绑（绕圈数不变）；钻尖钝→压剥复修（第5章）；轴承帽凹坑磨深打滑→重开帽面。

    【卡 07-04 弓钻组件制作】（八字段）

    1. 输入材料：弓臂料（直纹弹性木，60–80cm）；弓弦（4–6mm 绳）；钻杆料（钻孔用圆直硬木，取火用软木）；石钻尖（第 5 章尖状器）；轴承帽（硬木块或带凹石块）；兽脂。
    2. 所需工具：石片刀、刮刀、石锛（成形，7.8）；磨石（修圆杆）；角度板（校钻杆与孔位）；刻线具。校准来源：各件长度按标准杆刻线量；钻杆圆直以滚动目检。
    3. 操作顺序与控制点：弓臂成形（绷弦后弧高约 5cm）→ 上弦（绕钻杆 1.5–2 圈）→ 钻杆削圆、端装石钻尖 → 轴承帽开凹涂兽脂 → 试转（空转看钻尖是否画圈）→ 钻孔作业。控制点：弦绕圈数与冲程不得随意改（一改转速即变）；轴承帽凹坑磨深打滑即重开帽面。
    4. 经验参数与标定法：弓臂 60–80cm、弧高约 5cm；弦 4–6mm、绕 1.5–2 圈；钻杆 20–25cm、径 2–2.5cm；冲程 25–35cm；50–70 来回/分；约 200–400 转/分；下压力 5–10kg（经验值，须按本地条件标定）；2cm 厚硬木成孔 5–15 分钟。
    5. 过程观察记录项：记 组件编号／弓臂长与弧高／弦径与绕圈数／钻杆径／每分钟来回数／每孔耗时／提钻清屑次数／轴承帽凹深。
    6. 合格／返工／报废判据：合格＝空转钻尖画圈、钻孔不偏、2cm 硬木孔在 5–15 分钟内成；返工＝弦松重绑（绕圈数不变）、钻尖钝压剥复修、帽凹磨深重开帽面；报废＝弓臂开裂或失去弹性，换料重制。
    7. 常见失败与排查顺序：①钻尖打滑不入木 → 先查钻尖是否钝（压剥复修），再查下压力是否不足（5–10kg 级），最后查木料是否过硬（换料或改砂磨钻孔）；②孔偏斜 → 先查起钻有无定位浅窝，再查压帽是否加了侧向力，最后查料面是否倾斜；③弦老松 → 先查绕圈数是否变了，再查弦径是否偏细（4–6mm）；④转速上不去、只冒烟不进尺 → 先查冲程是否过短（25–35cm），再查轴承帽是否缺脂。
    8. L1／L2／L3 证据：L1＝一套装成的弓钻并钻出 1 个孔；L2＝硬木上 5 个对位孔、两面钻透偏差 <2mm；L3＝弓臂／弦／钻杆／绕圈数入档，第二人照档复制作出同样转速的弓钻。

    7.7 杠杆、滑轮和简易搬运装置¶

    杠杆：三要素——支点、力点、重点。省力比＝支点到重点距离÷支点到力点距离。实操：撬动重石时，垫石作支点并尽量贴近重物，力臂越长越省力，但行程越大。

    滚杠：重物下垫等粗圆木，前方逐根续入。滚动摩擦系数约0.05—0.1，滑动约0.4—0.6（经验值），省力3—5倍。要点：路径平整；滚杠间距50—80cm；转弯时滚杠摆成扇形。

    斜面：坡比1:4的土坡，理论省力至1/4（忽略摩擦）。上坡用楔跟垫，防倒滑。

    绳滑轮（受限于无金属轴）：

    • 绕树杈或光滑圆木改向：效率<50%，绳磨损大，仅作改向。
    • 简易木滑车：硬木挖轮槽＋木销轴，效率约60%—70%（经验值，需现场标定）；单动滑轮省力近半，一定一动组合省力过半，但下降速度与行程加倍。
    • 三脚架吊装：三根等长硬木顶端绑扎（十字编结＋穿楔），悬挂滑组，用于装车、下坑、竖立构件。

    筏与橇：

    • 筏：浮力＝排水体积×水密度。评估：干木密度约0.5—0.7（经验值），圆木排水量减自重即毛载重，再打对折作安全载重。
    • 橇：雪地、泥地拖运，底部硬木滑板，载面捆扎用十字编结。

    所有搬运装置使用前做1.5倍静载验证（7.4方法）。

    7.8 如何制作可反复使用的木工工具¶

    第一批复合柄木工工具（装柄用7.5连接谱系级别2：楔＋绑；级别4待8.5胶）：

    工具 刃部 装柄角 用途
    石锛 磨制石刃（角岩/玄武岩）或厚石片 刃与柄约60°—75° 横向削平、剔槽
    石斧 双面打制或磨制 刃线垂直柄轴 砍伐、劈粗料
    木凿/刻刀 小石片绑短柄，刃角30°—50° 同轴 剔槽、修孔；只可切撬，禁锤击
    刮刀/平铲 厚石片端刃45°—60° 同轴或微斜 光面、去皮
    木槌 大径短段硬木，端面平整 整体 打楔、校形，不伤刃口

    辅助件：划线器（硬木尖＋炭条划线）；磨石组（粗、细砂岩板各一）；线坠与角度板（第3章）随工具箱携带。

    磨制工艺（锛、斧刃正路）：毛坯在粗砂岩板上加水研磨去余量→中磨成形→细砂＋皮革抛光。全程保持原刃角不变：磨痕方向一致、与刃缘平行是角度未变的证据。磨制一把石斧3—8小时（经验值，需现场标定）。

    维护制度：

    1. 用毕擦净、薄涂兽脂防潮。
    2. 刃钝即重磨，角度不变（对照磨痕）。
    3. 绑扎松动立即重绑——按标准绑扎图（7.4十字编结）执行，不做临时绕缠。
    4. 石刃件重磨3—5次后刃体过薄报废，刃坯回收重打（回5.5）。

    损耗账：每件工具登记制造日期、工时、重磨次数、报废日期。月汇总损耗率，为第9.5产能规划供数据。

    能力边界¶

    能做到：三种韧皮纤维的沤制-梳洗-分级；两股与三股反向捻合绳；绳径-载荷对照表实测建档；弓钻组件与-basic 木工件（榫卯绑扎）。 明确做不到：机械搓绳（绳车属升级项）；单纤维强度定量（以束强比较级替代）。 外部依赖：沤制水源与季节水温（对照表见 7.4 补块）。

    7.9 绳结图谱：十结与承重三查¶

    7.4 的五结覆盖"连接与绑扎"，本节补全十结图谱，并给出统一的松脱风险分级：低=受脉动载荷与震动仍自锁，可无人值守过夜；中=恒载自锁、脉动载荷下会退，须当日检查；高=只作临时定位或有人值守场合，用后即拆。

    结 打法一句话 用途 松脱风险
    双套结 绳在杆上绕两圈，第二圈压住第一圈的端头 杆件绑扎起点、三脚架顶结起始段 中（恒载稳、脉动载退，收尾加半扣）
    八字结 绳端绕绳身成"8"字后穿回 绳端止索防脱（穿孔前的保险端头） 低（越拉越紧；代价是受力后难解）
    卷结 短绳在主绳上朝受力侧贴紧绕三圈 在张紧绳上做临时加力抓手（紧绳作业） 中（装反即滑：绕结面必须朝受力方向）
    称人结 绳端上行穿出成环、绕主绳背面、下行回环 固定圈套：吊人、套桩、网片起编 低（不滑不咬可解；余端回穿成双称人收尾）
    接绳结 细绳端穿粗绳圈、绕圈底折回压住自身 粗细两绳相接 中（细端余端≥10cm；重要处打双圈）
    双渔人结 两绳端互绕对方绳身各两圈、对拉收紧 等粗细绳永久对接、环索闭合 低（自锁极强；受力后不可解，只作永久接）
    剪立结 两杆并排，绳连绕数圈后在两杆之间横向勒紧收口 A形架、剪式撑杆（夹角调好再收口） 中（收口受震后退，每日复紧）
    杠棒抬结 载物索圈套好后，杠棒端穿入圈、压住索根再回扣一圈 两人抬运：杠棒与载物圈的连接 低（垂直载荷越压越紧；放下重物后须重新收口）
    梯索结 短绳绕主绳一圈穿出自成抱紧套圈，两套圈之间横绑踏杆 绳梯踏档固定 中（空载可滑：登梯前逐档复紧）
    锚结 绳端绕环或桩两圈、加一道半扣收尾 绳与环、桩、锚的固定端 低（恒载自锁；粗硬绳改绕三圈）

    承重结三查（凡结要吃载荷，打完必查，缺一不用）：

    1. 查受力方向：绳结的锁紧面是否正对实际拉力方向。卷结、接绳结装反等于没打；称人结的受力边应为绳身而非绳端。
    2. 查收尾：余端≥10cm；该回穿的回了穿、该加半扣的加了；绳端预先打好的八字结不许临时拆除省事。
    3. 查磨损位：捏住结眼（折弯最紧处）捻看——起毛=外层纤维断；切断感=内芯将断。起毛者降载50%使用，切断者立即换位重打。

    ◎手感标记：收尾是否够紧，以"两指夹余端抽拉不动、指节敲结体发闷声"代替目测。练习法：每人用3mm绳把十结各打20遍（合计约2小时，经验值），再蒙眼各打5遍；此后每周任抽3结限时复打，成绩记入绳索台账。

    【卡 07-05 绳结图谱】（八字段）

    1. 输入材料：已标定绳（7.4，3–10mm 任一档，每结每次练习约 50cm）；木杆、环、桩（作打结对象）。

    3. 操作顺序与控制点：按图谱打结 → 执行承重结三查（查受力方向、查收尾、查磨损位）→ 逐条登记台账。控制点：三查中受力方向与收尾任一不合格，禁挂载。

    5. 过程观察记录项：记 结型／绳径／载荷级／滑移量（mm）／结眼纤维状态（起毛或切断感）／打结人与日期。
    6. 合格／返工／报废判据：合格＝工作载荷下位移 <5mm 且无滑脱；返工＝滑移后自锁（加半扣或改双圈重打）；报废＝滑脱——该结型在该用途报废，改结型。
    7. 常见失败与排查顺序：①滑脱 → 先查受力方向是否装反（卷结、接绳结装反等于没打），再查收尾是否缺半扣、余端是否 <10cm，最后查绳面是否过滑（新搓绳面毛糙不足，预磨毛再用）；②受力后解不开 → 该结只该作永久接（双渔人结类），改用可解结型；③结眼起毛 → 先查是否让折弯最紧处吃载荷（换结位），起毛者降载 50%；④同一结两次滑移量差很大 → 先查绳径是否同档，再查打法是否一致（按图谱逐步核）。

    7.10 网与席编织¶

    网片起编：先在撑杆上打一排基础套圈（称人结，圈距=一个目径），圈数即网宽目数。逐行编织：取绳在上一行每目的两根目柱上连打两道半扣收紧（交织结），行行相扣成片。

    逐行减目与增目：

    • 减目（网片收窄）：行端把上一行相邻两目并作一目，打一个结。
    • 增目（网片放宽）：在同一目柱上连打两个结。
    • 规律：每行减几目、增几目必须左右对称，否则网片收角（整片拧成梯形）。

    网目尺寸规（量板）：硬木板一块，宽=网目边长×2，厚3—5mm，棱边磨圆。起圈绕板打结，保证每目同宽；网目公差以"量板通插全列松紧一致"为判据。渔网目径30—50mm（按目标鱼体高的一半起算，现场捕捞一次即标定）；货网目径80—120mm（以货件不漏出为度）。

    ◎编织张力手感：交织结收紧以"目柱不扭转、量板抽插不涩"为度。练习法：先编10cm×10cm试片三块，第三块与第一块逐行目数一致即出师（经验值，需现场标定）；误判代偿：量板通插全列，插不过的行即过紧、一插到底的行即过松，凭手感记录与量板结果对照修正。

    货网 1.5m×1.5m，目径80—120mm，6mm绳 8—12 h 吊装捆载、储物悬挂
    草席（平纹） 1.8m×0.9m 3—5 h 睡席、垫底

    【卡 07-06 网片编织】（八字段）

    1. 输入材料：3–6mm 韧皮绳（湿强不降型：椴／构内皮）；撑杆一根；备料＝网面积×目密度估算另加 15% 损耗。
    2. 所需工具：量板（硬木板，宽＝目边×2、厚 3–5mm、棱边磨圆，自制）；割绳石片刀（第 5 章）。校准来源：目径＝量板宽÷2；湿涨以"不卡量板"为合格。
    3. 操作顺序与控制点：撑杆上打一排基础套圈（称人结，圈距＝一个目径）→ 逐行交织结（每目两根目柱连打两道半扣收紧）→ 按图减目／增目（必须左右对称）→ 收边回编三扣。控制点：每行完成即数目，数目不符当行拆编。

    5. 过程观察记录项：记 每行目数／目径（量板通插结果）／张力手感（◎目柱不扭转、量板抽插不涩）／绳料批号／湿水复测目径。

    7. 常见失败与排查顺序：①网片收角（拧成梯形）→ 先查减／增目是否单侧集中（须左右对称），再查交织结松紧不一，最后查量板是否磨损变窄；②目径忽大忽小 → 先查起圈是否都绕同一块量板，再查湿绳是否未复测（湿涨）；③行内漏结 → 数目当行补打，不许留到下一行；④编到中途绳料断 → 先查是否用了过沤料（换椴／构内皮），再查绳径是否低于 3mm。

    7.11 劈篾与藤竹加工¶

    刀位固定劈篾法：竹筒直立于地，端面预先开十字浅口，刀刃（石斧刃或厚背石片）卡入其中一道切口，随后刀位不再挪动，双手压刀背或以木槌击刀背，靠竹筒自重与击力下行，一劈到底。刀位固定是等宽篾条的关键：中途挪刀，篾条必宽窄不匀。

    劈分顺序：先十字劈分四块（过髓心）→每块再劈成条→刮净内节隔（节隔硬脆，不去则编织中途断篾）。

    篾的分级：

    级 部位 特性 用途
    青篾 带竹青的表层 强度高，约为黄篾2倍以上（经验比较级；标定法：同宽篾条两两吊重对比断裂级） 承力经条、筐底、受弯件
    黄篾 内层 强度低、质软 纬条缠绕、填充编壁

    篾宽规格：经篾6—8mm且篾面不得带劈伤（伤篾即未来断点）；纬篾3—5mm。干篾水润约10分钟再编，脆断率显著下降（经验值，需现场标定）。

    藤条加工：

    • 矫直：弯曲段近火烘烤至烫手（6章火矫直同法），压直后自然冷却；同一处两次为限——三次烘烤藤皮起焦即弃。
    • 丁字接：横杆端劈口夹住立杆，十字绑扎收口；用于架顶与工具架。
    • 编接（接长）：两藤端各劈开成三股，股股互相穿插编合，外缠细绳收口。接头强度约为母材的60%—70%（经验值，需现场标定：编接段与整藤段吊重对比断裂），重要承力处必须避开接头位。

    ◎劈篾下刀手感：以"刀背均匀下沉、声音连续不爆"为顺纹判据；爆声=遇节或逆纹，立即停手退出、重新开口。练习法：用废竹筒劈20刀，等宽篾率≥80%为出师（经验值）；误判代偿：篾条两两并排比对，宽度偏差>2mm的挑出重劈或降级作纬篾。

    7.12 绳桥与吊装¶

    双索吊桥（设计跨度上限10m，经验值，需现场标定）：

    • 结构：主索1根（10—16mm，静载标定合格）＋扶手索2根（6—10mm）＋踏板组。
    • 主索垂度：跨度的8%—12%（经验值，需现场标定）——太紧则锚固点载荷数倍于桥载，太松则踏步如陷阱。张紧后以"桥中点挂75kg再下垂<50cm"复核。
    • 锚固：主索绕活树干三圈＋锚结（7.9），或埋地桩（径≥15cm硬木，埋深≥1m，桩顶加横担杠）。扶手索两端锚固高度齐胸。
    • 踏板绑法：短木（长40—50cm、径6—8cm）以双套结挂主索，板距30—35cm，板端各加一道半扣防串动；每3—4档自扶手索引一根垂绳斜拉至主索，构成三角防摆。
    • 验证：载人前挂1.5倍额定载荷（水袋配重）静置10分钟，锚点位移<5cm为合格；此后每周巡查锚结与踏板半扣。

    三点吊装：

    • 重心判断：试吊即测量——绳套吊起后，物体自动转到重心正下方；偏斜即落回，挪动套圈位置再试，至提起平正为止。
    • 套圈布置：两点套圈＋顶部一点成三点。两索夹角<90°时每索载荷<0.75倍物重；夹角120°时每索载荷=物重；夹角>120°禁止起吊（经验判据，用第3章角度板现场量）。
    • 试吊流程：离地10cm停1分钟→观察倾斜与各结滑移→落回调整→二次试吊平正→正式提升。提升全程下方禁站人，起落动作按本章安全边界的喊令制执行。

    绳索过河架设（引线过河法）：

    1. 细引线（3mm绳）端系石块或浮木，抛掷过河，或单人泅渡携带。
    2. 引线拉直过河，对岸临时锚固。
    3. 引线拖中绳（6mm），中绳拖主索（10—16mm）——逐级放大，每级绳径比约1:3；任何一级拖不动即查卡滞，禁止直接抛掷主索。
    4. 主索按双索吊桥规范锚固张紧，先做1.5倍静载验证，再作渡桥或溜索使用。

    • 木材干燥周期长（数月），产能受储备制约；窑干待第12–13章建筑与窑炉。
    • 滑轮轴承为木销，磨损快，无润滑剂体系（兽脂仅够轴承帽）。

    安全边界¶

    • 劈分时楔弹出方向3m内禁站人；跟楔必须逐枚跟进，禁用单楔硬打。
    • 沤浸水体有腐败菌，处理纤维后洗手，伤口不接触沤水。
    • 弓钻弦缠绕手指是大伤害源：弦长与持弓法按7.6规范执行。
    • 三脚架、滑组、筏使用前必须1.5倍静载验证；载人筏载荷减半。
    • 石斧空挥确认背后无人后方可作业（喊令制，见9.5）。

    验收标准¶

    • L1 原理验证：完成一段反向捻合绳（不上劲、不散头）；弓钻成功取火一次；劈出一片径劈板。
    • L2 可重复制造：三档绳径各制10m并完成静载标定，标定值入档；弓钻在硬木上钻出5个对位孔（两面钻透偏差<2mm）；一把复合柄石锛完成削平任务并经1.5倍静载装柄测试；榫接样品通过保载测试。
    • L3 可持续生产：纤维原料两处以上来源并登记；绳索月产量与损耗率在账；木料气干储备>3个月用量；木工工具全部有重磨与重绑记录；两人以上能独立按档案制绳与制弓钻。
