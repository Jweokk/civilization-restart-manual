# 03 · Six Technology Lineages

> The six capability chains that run through the whole book. Each time you write or read a chapter, you should know where it sits on these six chains: what it consumes from upstream, and what it provides to downstream.

---

## Lineage 1: Materials

The upgrade chain from natural raw materials to industrial materials.

> Natural minerals → ore dressing → smelting → primary metals → forging → heat treatment → machine parts

By the same logic: clay → pottery → refractory materials; sand → glass → optical glass; fibers → yarn → fabric → industrial fabric. Every link corresponds to the complete chain of Iron Law 3: raw materials → collection → sorting → primary processing → purification/smelting → forming → inspection → use.

## Lineage 2: Tools

From simple tools to "tools for making tools".

> Stone flakes → stone hammers → woodworking tools → metal tools → measuring tools → precision machinery → machine tools

Criterion: a tool counts as "established" if and only if, once damaged, it can be repaired or remade (lineage self-sufficiency).

## Lineage 3: Energy

> Fire → charcoal → furnaces and kilns → water-powered machinery → steam engines → generators → electric motors

Each energy level determines the processing ceiling for the previous level's materials: without charcoal and blast there is no iron; without stable mechanical power there are no precision machine tools; without a continuous electricity supply there is no electrochemistry and no semiconductors.

## Lineage 4: Measurement

> Visual estimation → simple comparison → standard dimensions → gauges → precision mechanical measurement → optical measurement → electrical measurement → materials and device testing

This is the lineage most easily overlooked, and yet the most pervasive: from the bow drill (Chapter 7) to semiconductors (Chapter 34), the capability that truly runs from start to finish is **reliable measurement and repetition**. Every upgrade in measurement comes from the "more precise tools" manufactured by the previous level of measurement (bootstrapping).

## Lineage 5: Chemistry

> Combustion → lime → glass → basic acids, alkalis, and salts → metal purification → industrial reagents → material purification and surface treatment

Not every region can develop in this order, but every technology should state the chemical capability it requires. End-state awareness: the semiconductor route is, in essence, the comprehensive examination of "chemical purity capability".

## Lineage 6: Information

> Oral experience → graphical records → unified metrology → process records → technical drawings → standardization → production records → automatic control → electronic computation

Civilizational recovery depends not only on physical tools but also on knowledge that can be preserved, transmitted, and reproduced. This lineage reminds every settlement: **ledgers and archives are infrastructure, on the same level as kilns.**

---

## Feedback Loops: Civilization Is Not a Tree That Grows in One Direction

Reinforcing loops exist among the six lineages; the true engine of rebuilding is these loops, not the chains themselves:

- Precision instruments → improved materials research → better materials → more precise tools
- Better generators → support electrically driven machining → better machine tools → better generator parts
- Better measurement → higher-quality mechanical and electrical products → feeding back into the manufacture of measuring instruments
- Electronic control → higher automation of production equipment → acceleration of all manufacturing

**In the early phase (Parts 1 through 3), advance mainly along the chains; in the middle phase (Parts 4 and 5), build the feedback loops deliberately; in the late phase (Part 6), each loop should begin reinforcing itself.** Each chapter's "next-step dependencies" block should state which loop it feeds.
