# Appendix E · Master Table of Terminology and Units

> Unified conventions for the whole book (an expansion of the G02 terminology section). Wherever the body text conflicts with this table, the body text is to be revised to match this table.

## 1. Core Terms

| Term | Definition | First appears |
|---|---|---|
| 工艺卡／工位卡 (process card / workstation card) | Same object, two names: an eight-field worksheet numbered "chapter-sequence" (e.g., 20-01) | G02 |
| 八字段 (eight fields) | Input materials / required tools / operation sequence and control points / empirical parameters and field-calibration method / in-process observation record items / pass, rework, or scrap criteria / common failures and troubleshooting / L1–L3 evidence | G02 |
| 九块骨架 (nine-block framework) | Capability boundary / pre-start verification / materials / tools / steps / parameters / failure diagnosis / acceptance / work-hours and staffing | G02 |
| 固定块 (fixed blocks) | End of every chapter: failure modes and diagnostics / process card index / acceptance criteria / safety boundaries / next dependencies | G02 |
| 三档标准 (three-tier standard) | Tier 1: know of it / Tier 2: manage to make it once by trial / Tier 3: repeatable manufacture, diagnosable | G02 |
| L1/L2/L3 | Proof of principle / repeatable manufacture / sustainable production | G02 |
| 铁律 (Iron Law) | The seven constitutional rules of the whole book (no anachronism / precision must have a source / material chain / verifiability / line of retreat / evidence / labor) | G01 |
| 预告 (preview) | A forward declaration of the form "will be established in Chapter N"; preview items may NOT be counted as already existing | Chapter 4 |
| 沉默失败 (silent failure) | A failure that is not immediately visible when done wrong (annealing / vacuum / winding / cement-curing class) | G01 Iron Law 6 |
| 经验值，需现场标定 (empirical value, must be field-calibrated) | Default numbers: a value plus a field calibration method must both be given before they may be used for acceptance | G02 |
| 降档声明 (tier-down declaration) | An explicit statement at the start of a subsection when the process has not reached Tier 3 | G02 |
| ◎标记 (◎ marker) | Hand-feel (tacit-judgment) steps: must be accompanied by a practice method plus a measurable compensating criterion | G02 |
| 【背景/展望】 ([Background/Outlook]) | Marker for long-range passages kept separate from executable content | G02 |
| 三实检 (three live tests) | Scratch + bend + in-use test (steel/iron acceptance) | Chapter 19 |
| 整流比 (rectification ratio) | Ratio of forward to reverse current at the same voltage (selecting detector points) | Chapter 33 |
| 双液淬火 (interrupted quenching, water-then-oil) | Two-bath relay: water (rapid cooling through the mid-temperature range) → oil (slow cooling through the low-temperature range) | Chapter 19 |
| 渣棒法 (slag-rod method) | Judge furnace temperature by the length of wire drawn from a slag-coated iron rod | Chapter 18 |
| 四栏替代 (four-column alternatives) | Performance loss / resource cost / applicable boundaries / final bottleneck | Chapter 40 |

## 2. Units and Conversions (this book's conventions)

| Quantity | Unit | Notes |
|---|---|---|
| Length | mm / m; pace / cubit / finger (Chapter 3 local system) | dual-track annotation; the local system is for one person's own use only |
| Mass | g / kg | balance chain (Chapter 3) |
| Temperature | ℃ | before thermometers exist: fire-color tiers + slump-cone set (temperature cones) + anchor points (Chapter 12) |
| Pressure | atm / mmHg / water column | 1 atm≈760 mmHg≈10.3 m water column; use water column for low pressure |
| Power | W / horsepower | 1 horsepower≈735 W; sustained human output 50–100 W |
| Heat | kilocalorie; firewood equivalent = 1 kg dry pine firewood≈3500–4000 kcal | Chapter 38 |
| Rotation speed | revolutions/minute | tab-counting method |
| Concentration | parts by mass / volume %; floating-egg method tiers | Chapters 8/23 |
| Length (cloth) | finger / rod; weft density = wefts per finger-width | Chapter 15 |
| Character | character≈Chinese character (punctuation included), per the wc -m convention | word-count convention for this overview |
